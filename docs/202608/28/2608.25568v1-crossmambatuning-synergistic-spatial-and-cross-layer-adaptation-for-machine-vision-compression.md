## 摘要
为降低部署成本和再训练开销，将预训练的学习图像压缩（LIC）模型适配到下游机器视觉任务已受到越来越多的关注。然而，现有方法通常将微调模块独立地插入到冻结的骨干网络中，缺乏跨层协调的显式机制。为解决这一局限，我们提出了一种名为CrossMambaTuning的新框架，该框架将状态空间模型与跨层交互机制相结合，以实现参数高效的微调。具体而言，我们设计了一种高效Mamba适配器，配备任务特定提示和多尺度分支，以精确捕获局部特征和全局依赖关系。此外，我们引入了一种尺度不变的跨层适配器（SICA），利用参数共享策略融合不同尺度的任务信息并减少冗余。大量实验表明，CrossMambaTuning在多个机器视觉任务上达到了最先进的（SOTA）性能，与SOTA方法相比，参数开销减少了72%。代码可在 https://github.com/rsr1123/CrossMambaTuning 获取。

## Abstract
To reduce deployment cost and retraining overhead, adapting pretrained learned image compression (LIC) models to downstream machine vision tasks has attracted growing attention. However, existing methods typically insert fine-tuning modules independently into frozen backbones, lacking explicit mechanisms for cross-layer coordination. To address this limitation, we propose a novel framework named CrossMambaTuning, which integrates State Space Models with cross-layer interaction mechanisms for parameter-efficient fine-tuning. Specifically, we design an efficient Mamba adapter equipped with task-specific prompts and multi-scale branching to precisely capture both local features and global dependencies. Furthermore, we introduce a Scale-Invariant Cross-Layer Adapter (SICA) utilizing a parameter-sharing strategy to fuse task information across different scales and reduce redundancy. Extensive experiments demonstrate that CrossMambaTuning achieves state-of-the-art (SOTA) performance on multiple machine vision tasks, reducing parameter overhead by 72\% compared to SOTA methods. Code is available at https://github.com/rsr1123/CrossMambaTuning.

## 1. 核心问题与整体含义

本文聚焦于**将预训练的学习图像压缩（LIC）模型高效适配到下游机器视觉任务**的问题。在IoT等实际部署场景中，压缩系统常需同时支持人眼观看和机器视觉分析，若为每个任务单独训练完整编解码器则训练与存储开销过高。近年研究采用参数高效微调（PEFT）范式，仅在冻结的预训练码率上额外引入轻量模块。然而，现有方法存在两个关键局限：

- **长距离空间依赖建模不足**：如基于频率调制的SFMA等适配方法难以捕捉远距离区域间的全局依赖关系；而Transformer注意力虽有全局建模能力，但二次复杂度使其在高分辨率图像上难以应用。
- **缺乏显式跨层协调机制**：现有方法在各网络层独立插入微调模块，各层适配器可能学到重叠的特征模式，引入冗余，无法充分利用跨层的互补语义信息。

CrossMambaTuning由此提出，目标是在保持极少可训练参数的前提下，同时解决空间依赖建模与跨层信息融合两个问题，实现高效的机器视觉压缩适配。

## 2. 方法论

### 核心思想
将**状态空间模型（SSM/Mamba）**与**跨层交互机制**结合，构建参数高效的微调框架。整体流程为：冻结预训练编解码器，仅训练插入的两个轻量模块，并通过“冻结主干路径 + 旁路适配”的方式实现任务特化。

### 两大核心模块

**【模块一】Task-aware Mamba Adapter**（任务感知Mamba适配器），包含三个关键设计：

- **Affinity Pre-conditioner（APC）**：在适配器之前对输入特征进行预处理，通过可学习的缩放参数α、β融合归一化特征与原始特征，修正冻结主干输出与下游任务理想分布之间的偏移。公式：`x_APC = Norm(x) ⊙ α + x ⊙ β`，仅需4C个参数。
- **Local Information Extractor（LIE）**：采用多尺度深度可分离卷积分支（1×1、3×3、5×5核），替代原始3×3深度卷积，为SSM提供局部归纳偏置，增强对边缘、纹理等高频信息的捕捉。
- **Task-Specific Prompt Generator（TSPG）**：通过共享的任务嵌入 `E_task` 与层特定嵌入 `E_layer`，经轻量投影器生成逐层提示（prefix），拼接在输入序列前端，使SSM先处理任务提示以初始化隐藏状态，注入任务先验。

**【模块二】Scale-Invariant Cross-Layer Adapter（SICA）**（尺度不变的跨层适配器）：

- 建立跨层旁路连接：`z_in^{k+1} = F_k(z_adapt^k) + α_k · T(z_adapt^k; Θ)`，其中第一项为冻结路径，第二项为SICA旁路，α_k初始化为0的可学习门控。
- SICA采用**参数共享策略**，编码器与解码器分别共享一套参数Θ，变换算子T由**尺度对齐（Scale Alignment）**和**尺度不变投影器（SIP）**组成：编码器阶段用stride=2的深度卷积下采样，解码器阶段用2×双线性上采样后接stride=1的深度卷积；投影器为瓶颈MLP（降维→SiLU→升维）。
- 通过在训练中代入不同尺度的特征，SICA能学习与空间尺度无关的通用语义注入机制，实现跨层信息融合，减少重复学习冗余模式。

### 训练损失
采用率失真优化：`L = R + λ · D_task`，R为熵模型估计的码率，D_task为任务特定的感知损失（用预训练下游任务网络提取原始图与重建图的特征算MSE）。

## 6. 主要结论与发现

- CrossMambaTuning在分类、检测、分割三个任务上均取得**SOTA性能**。以TIC为基准时，Base变体在检测上BD-mAP达4.249，优于全量微调的3.755，而参数仅0.32M（全量微调的4.26%）。
- **Tiny变体仅用0.08M参数**即可超越Adapt-ICMH（0.29M参数）和SVD-LoRA（0.09M参数），参数开销较SOTA方法减少72%。
- 在CNN-based的ELIC骨干上同样一致超越基线，验证了架构无关性。
- 跨层共享策略避免重复学习、提升性能；Mamba的空间建模能力优于窗口注意力。
- APC有效缓解特征分布偏移（Wasserstein距离从0.0308降至0.0277，KL散度从0.0396降至0.0318）。
- SICA显著降低潜表示的空间相关性（从0.18降至0.05，接近全量微调的0.01），证实设计的旁路机制有效减少了压缩冗余。

## 7. 优点

- **极致的参数效率**：通过APC（仅4C个参数）、LIE的多尺度设计、SICA的全阶段参数共享，在极小参数量（0.08M起步）下达到SOTA甚至超越全量微调的性能。
- **跨层协同设计新颖**：有别于以往各层独立的适配方式，SICA以尺度不变的旁路显式构建跨层信息通路，从“冗余减少”的角度切入，并通过空间相关性分析提供了可解释的验证证据。
- **架构无关性与通用性**：方法同时适用于CNN和Transformer主干，在TIC（Transformer）与ELIC（CNN）两种不同编解码器、三个不同任务（分类/检测/分割）上验证，统一的框架设计具有较好的普适性。
- **消融实验与分析逻辑严密**：逐级加入模块验证各组件贡献，并通过分布距离、空间相关性、复杂度等多维度分析，提供了充分的机制层面解释。定性可视化也展示了实际检测/分割效果改善。
