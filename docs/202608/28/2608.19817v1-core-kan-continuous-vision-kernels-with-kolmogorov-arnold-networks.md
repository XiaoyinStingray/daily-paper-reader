## 摘要
传统的卷积核通常在固定的离散网格上定义，限制了其适应异质局部结构的能力。现有的自适应算子提高了灵活性，但往往将几何尺度变化与内容相关滤波耦合在一起，并且由于每个位置的核生成而带来高计算成本。为了将几何尺度适应与内容相关滤波解耦，同时避免昂贵的逐位置核生成，我们提出了连续相对尺度KAN（Core-KAN），一种相对尺度条件的连续卷积算子。Core-KAN将输入特征映射到紧凑的潜在基空间，并使用轻量级尺度控制器来预测相对于指数移动平均参考的局部尺度。基于KAN的生成器将深度卷积核基表示为连续坐标函数，使算子能够在任意分辨率下合成空间滤波器，而不是局限于固定网格。它不是在每个位置合成独立核，而是构建一个紧凑的尺度条件核响应库，并根据预测的局部尺度图进行插值。一个独立的混合控制器进一步根据局部内容组合插值后的基响应，明确地将几何尺度适应与内容相关滤波解耦。结合轻量级逐点投影，该设计形成了一种低秩动态卷积，其计算复杂度随核大小高效扩展，并能轻松集成到层级视觉骨干中。在三个代表性视觉任务上的实验表明，Core-KAN仅以微小的参数和计算开销即可持续优于强卷积和动态核基线，为连续、尺度自适应卷积提供了一种高效、通用的框架。

## Abstract
Conventional convolutional kernels are typically defined on fixed discrete grids, limiting their ability to accommodate heterogeneous local structures. Existing adaptive operators improve flexibility but often couple geometric scale variation with content-dependent filtering, while incurring high computational cost from per-location kernel generation. To decouple geometric scale adaptation from content-dependent filtering while avoiding expensive per-location kernel generation, we propose Continuous Relative-scale KAN (Core-KAN), a relative-scale-conditioned continuous convolution operator. Core-KAN maps input features into a compact latent basis space and uses a lightweight scale controller to predict local scales relative to an exponential moving average reference. A KAN-based generator represents depth-wise kernel bases as continuous coordinate functions, allowing the operator to synthesize spatial filters at arbitrary resolutions rather than being confined to a fixed lattice. Instead of synthesizing independent kernels at every location, it constructs a compact bank of scale-conditioned kernel responses and interpolates them according to the predicted local scale map. An independent mixing controller further combines the interpolated basis responses based on local content, explicitly decoupling geometric scale adaptation from content-dependent filtering. Together with lightweight pointwise projections, this design forms a low-rank dynamic convolution that scales efficiently with kernel size and integrates readily into hierarchical vision backbones. Experiments across three representative vision tasks show Core-KAN consistently outperforms strong convolutional and dynamic-kernel baselines with only marginal parameter and computational overhead, offering an efficient, general framework for continuous, scale-adaptive convolution.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：传统卷积核在固定离散网格上定义，无法根据局部结构（如纹理、边界、细长结构、同质区域）自适应地调整空间聚合模式。卷积的高效性与共享性，是以牺牲位置特定的空间推理能力为代价的。
- **现有方法的不足**：
  - **大核/多分支网络**：扩大或多样化感受野，但仍使用有限参数化的固定滤波器，适应性有限。
  - **条件/动态卷积（CondConv、DY-Conv、ODConv等）**：提高了内容自适应性，但通常将“几何尺度变化”与“内容相关滤波”耦合到同一个路由信号中，可解释性差；且逐位置生成核的计算和内存成本高昂。
  - **可变形卷积**：从采样侧适应，但权重仍附加在有限的位移点上，且采样网格本身发生变形，与卷积的实现结构有偏差。
  - **连续卷积表示（CKConv、Flex-Conv等）**：学习坐标到权重的函数，但核场通常是层级的或全局控制的，未实现密集的逐位置适应。
- **关键观察**：空间适应包含两个不同决策——**几何尺度/结构的选择**（核的锐度、宽度、形状）和**内容相关的潜在滤波模式组合**。现有机制常将二者绑定。
- **论文目标**：提出一种能够提供密集、逐位置空间自适应，同时保持卷积共享性和计算高效性的算子，并显式解耦几何尺度适应与内容相关滤波。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架
- **Core-KAN**（Continuous Relative-scale KAN）是一种相对尺度条件的连续卷积算子，包含三个核心组件：
  1. **尺度控制器（Scale Controller）**：预测密集局部尺度场，并经EMA参考校准为相对尺度。
  2. **KAN核生成器（KAN Kernel Generator）**：将连续坐标映射为N个深度核基（共享连续核场）。
  3. **混合控制器（Mixing Controller）**：根据局部内容独立组合基响应。
- 整体形成一个**低秩动态卷积**：通过1×1投影将输入压缩到紧凑的N维基空间，在基空间执行自适应深度卷积，再经1×1投影输出。

### 2.2 算子公式化（公式1-2）
- 输入投影到基空间：V = P_in(X)，V ∈ R^(B×N×H×W)。
- 输出：Y_b,c(p) = Σ_n W_out[c,n] · m_b(p,n) · R̃_b,n(p)，其中R̃为尺度适应后的基响应，m为内容混合权重。
- 两个互补控制：尺度分支改变基响应的空间轮廓，混合分支改变内容依赖的贡献。

### 2.3 解耦的尺度与混合控制器（公式3-6）
- **尺度预测**：C_α用两个3×3卷积+GroupNorm+ReLU块接1×1预测层，经sigmoid将预测值映射到[α_min, α_max]（默认[0.5, 2.0]）。
- **EMA参考**：每个Core-KAN层维护一个非可学习的EMA参考μ_α，按公式(4)更新（ρ=0.99，带stop-gradient和clip）。该参考在推理时固定。相对尺度s_b(p) = α_b(p) / μ_α，校准了不同层和训练阶段的绝对尺度漂移问题。
- **内容混合**：C_m预测N个基上的softmax分布，独立于尺度预测，实现几何尺度与内容组合的解耦。

### 2.4 KAN参数化的连续核场（公式7-13）
- **尺度支持点**：在预测区间内均匀放置M个绝对支持点α_j，经同一EMA参考转为相对支持点s_j，与局部相对尺度处于同一坐标系。
- **KAN核映射**：共享KAN Φ_θ: R² → R^N，接收归一化二维坐标，输出N个标量核值。对相对尺度s，在尺度变换坐标{s·q_r}处查询KAN，得到N个k×k核基。
- **标准化**：每个采样核沿空间维度标准化（减均值除标准差），再rescale到Kaiming兼容幅度√(2/k²)。
- **支持集采样**：仅在M个支持点处采样核，得到K = {K_j,n} ∈ R^(M×N×k×k)，这是同一个连续场的样本，而非独立存储的滤波器。

### 2.5 支持-插值读出（公式14-20）
- **响应库**：将M个支持核以深度卷积方式应用于基特征V，得到响应库R ∈ R^(B×M×N×Ho×Wo)。仅需M次共享深度卷积。
- **逐像素尺度插值**：对位置p，若s_j ≤ s(p) ≤ s_j+1，则插值系数λ = (s(p)-s_j)/(s_j+1-s_j)，线性组合相邻两个支持的响应：R̃ = (1-λ)R_j + λR_{j+1}。
- **等效性证明**：由于卷积对核权重是线性的，响应插值精确等价于应用逐位置插值核 K̃ = (1-λ)K_j + λK_{j+1}，无需物化逐位置核张量。相比直接逐位置查询核场（公式18），这是沿尺度条件核轨迹的可控分段线性近似；M增大可提高近似精度。

### 2.6 内容混合与低秩解释（公式21-22）
- 混合权重逐元素乘到插值基响应上：Z = m ⊙ R̃，经P_out输出。
- 有效逐位置核为：W_eff(δ) = Σ_n W_out[c,n] · m_b(p,n) · K̃_b,n,p(δ) · W_in[n,c']，其中s_b(p)控制空间轮廓，m_b(p,n)控制基组合，逐点投影跨位置共享通道混合因子，将空间自适应计算限制在紧凑的N维基空间。
