## 摘要
残差连接依赖于静态的残差通路，对于训练深度神经网络至关重要。超连接（HC）通过结合多个残差流和学习动态信息流来增加残差路由的表达性，而流形约束（mHC）变体通过双随机残差混合来稳定训练。然而，现有方法中仍存在一个生成器层面的瓶颈：它们使用稠密的、无结构的生成器进行分支前聚合、残差混合和分支后重分配，这导致参数数量随着流数量的增加而迅速增长。为了解决这个问题，我们提出了TEMPER（面向表达性残差路由的张量化高效流形约束参数化），它将这些生成器表示为输入流、特征和输出流模式上的多路张量，并使用张量网络对其进行参数化。这种结构化低秩公式被证明能够保留依赖于令牌的流形约束路由接口，同时大幅减少参数增长。它还促进了可解释性和直观性，因为：i）张量秩控制学习到的路由子空间的维度，全秩恢复稠密路由；而ii）生成器近似误差界定了路由逻辑值的差异，并因此界定了路由块输出的差异。综合实验表明，在语言建模和常识推理任务中，TEMPER匹配或优于现有方法，同时需要显著更少的额外参数。在八个残差流下，TEMPER在比mHC少使用约84%额外参数的情况下取得了最佳CORE分数，从而显示出更强的性能-参数效率权衡。

## Abstract
Residual connections rely on a static residual pathway, and are essential for training deep neural networks. Hyper-connections (HC) increase the expressivity of residual routing by incorporating multiple residual streams and learning dynamic information flow, while manifold-constrained (mHC) variants stabilize training through doubly stochastic residual mixing. However, a generator-level bottleneck remains in existing methods: they use dense, unstructured generators for pre-branch aggregation, residual mixing, and post-branch redistribution, which results in parameter count growing rapidly with the number of streams. To address this issue, we propose \underline{\textbf{T}}ensorized \underline{\textbf{E}}fficient \underline{\textbf{M}}anifold-constrained \underline{\textbf{P}}arameterization for \underline{\textbf{E}}xpressive Residual \underline{\textbf{R}}outing (\textbf{TEMPER}), which represents these generators as multi-way tensors over the input-stream, feature, and output-stream modes, and parameterizes them using tensor networks. Such a structured low-rank formulation is shown to preserve token-dependent manifold-constrained routing interface while substantially reducing parameter growth. It also promotes interpretability and intuition, as: i) tensor ranks control the dimensionality of the learned routing subspace, with full ranks recovering dense routing; while ii) the generator approximation errors bound differences in routing logits and, consequently, in the routed-block outputs. Comprehensive experiments show that TEMPER matches or outperforms existing methods across language modeling and commonsense reasoning tasks, while requiring substantially fewer additional parameters. At eight residual streams, TEMPER achieves the best CORE score while using about $84\%$ fewer additional parameters than mHC, thus showing a stronger performance-parameter efficiency trade-off.

- **残差连接的基础地位**：残差连接（Residual Connection）是训练深度神经网络（尤其是现代 Transformer）稳定性和可扩展性的核心组件。传统残差块将所有 token 经由同一固定路径进行信息更新，简单有效但路由模式静态、缺乏表达性。
- **超连接（Hyper-Connections, HC）的贡献**：HC 将残差路径扩展为多条残差流（residual streams），并通过学习 token 相关的动态路由，使不同 token 能以不同方式聚合、混合和重新分配信息，从而获得更丰富的残差拓扑和信息流模式。
- **流形约束超连接（mHC）的改进**：mHC 通过 Sinkhorn–Knopp（SK）迭代将残差混合矩阵 A_res 约束为双随机矩阵，以提高训练稳定性。后续变体如 mHC-lite（Birkhoff–von Neumann 混合）和 KromHC（Kronecker 乘积因子）进一步改进了 A_res 的参数化效率。
- **尚存的"生成器级瓶颈"（核心问题）**：尽管 A_res 的参数化已被优化，mHC 及变体中用于生成三个 token 相关路由投影（pre-branch 聚合、残差混合、post-branch 重分配）的生成器仍然是**稠密、非结构化**的权重矩阵。随着残差流数量 n 增大，生成器参数量呈 O(n³) 增长，严重限制了可扩展性。
- **研究问题**：能否用结构化、参数高效的替代方案替换 mHC 中的稠密非结构化路由生成器，同时保持甚至提升性能？
- **整体含义**：TEMPER 通过张量网络对路由生成器进行低秩结构化参数化，在保留 mHC 的流形约束路由接口（包括双随机残差混合）的前提下，将参数增长从 O(n³) 降至 O(n)，实现了更强的性能–参数效率权衡，是残差路由参数化的重要进展。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将 mHC 中密集生成器权重矩阵重新理解为**多路张量**：输入流模式（n）、特征模式（d）以及输出流模式（n 或 n×n），分别对应 W_pre ∈ R^{n×d×n}、W_res ∈ R^{n×d×n×n}、W_post ∈ R^{n×d×n}。
- 保持原有计算接口（张量收缩 + 激活 + SK 归一化）不变，仅将稠密生成器张量替换为**低秩张量网络分解**（CP 或 Tucker）。
- 通过张量分解引入跨模式（流–特征–输出）的**结构化参数共享**，降低参数量的同时保留表达力。

### 2.2 两种实例化方式

- **TEMPER-CP**：采用 CP 分解，将每个生成器张量分解为若干秩一张量外积之和。如 W_pre = Σ_{q=1}^{r} u_q^pre ∘ c_q^pre ∘ v_q^pre。分量索引 q 将各模式因子耦合，从而在流–特征–输出交互中引入共享结构。
- **TEMPER-Tucker**：采用 Tucker 分解，使用因子矩阵和一个小型核心张量。输入先被压缩为低维流–特征表示 T = U^T Ĥ C，再与核心张量及输出模式因子收缩得到路由 logits。Tucker 秩 (r_n, r_d, r_n) 控制路由依赖的子空间维度。

### 2.3 参数效率

- 生成器参数计数对比：
  - mHC：P = d(n³ + 2n²)
  - TEMPER-CP：P = 3dr + 7nr
  - TEMPER-Tucker：P = 7nr_n + 3dr_d + 2r_n²r_d + r_n³r_d
- 固定 d 和秩时，mHC 为 O(n³)，TEMPER 为 O(n)，显著改善随流数增长的可扩展性。

### 2.4 理论保证

- **定理 1（秩与零空间）**：当 U、C 满列秩时，Tucker 压缩映射 L(Ĥ) = UᵀĤC 的秩为 r_n·r_d，零空间维度为 nd − r_n·r_d。即秩控制路由可用的学习子空间维度。
- **引理 1（生成器到 logits 的误差界）**：路由 logits 的差异 ≤ ‖Ĥ‖_F · ‖W − W̃‖_F，即 logits 偏差由张量近似误差和输入范数共同界定。
- **定理 2（端到端路由块近似误差界）**：在 Lipschitz 等正则假设下，稠密与张量化路由块的输出差异由 pre/res/post 三个生成器的近似误差加权上界控制。
- **完全恢复性**：全秩 Tucker 可恢复稠密 mHC 生成器，因此张量秩在紧凑路由与稠密路由之间形成连续插值。
