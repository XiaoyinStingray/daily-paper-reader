## 摘要
近期图像和视频识别的大部分进展都以内存为代价：更大的模型、更高的分辨率和更长的时间上下文。一个不可避免的组成部分是内存和计算量基于图像分辨率的二次方（或更大）增长，这是卷积网络和视觉Transformer中使用的网格采样属性。在这项工作中，我们研究了残差网络，其卷积块反而具有对数平方增长，使它们能够快速处理超高清视频。关键见解是利用残差架构的残差流作为高分辨率缓冲区，卷积块仅通过对数极坐标图像扭曲操作对其进行读写。各层自适应地关注每秒帧的不同部分，仅在焦点附近具有非常高的分辨率。完整的全分辨率表示在残差流中构建，类似于生物视觉中眼跳形成完整图像，并提出了一个理论构造，消除了残差流分辨率的二次依赖性。实验表明，我们提出的HiResNets学习以类似于人类视觉的方式环绕场景，并在困难的自我中心视频识别任务中表现出优越的性能，尤其是具有小物体和细粒度识别的自我中心视频。

## Abstract
Much of the recent progress in image and video recognition has come at the cost of memory: larger models, increased resolution, and longer temporal contexts. An inevitable component is the quadratic (or larger) growth of memory and compute based on image resolution, which is a property of the grid sampling used in convolutional networks and vision transformers. In this work we study residual networks whose convolutional blocks have logarithmic-square growth instead, enabling them to process very high-resolution video quickly. The key insight is to use a residual architecture's residual stream as a high-resolution buffer, to which convolutional blocks only read and write via log-polar image warp operations. Layers adaptively focus on different parts of each frame, with very high resolution only near the focus point. A complete high-resolution representation is built up in the residual stream, analogous to eye saccades creating a complete picture in biological vision, and a theoretical construction is presented that eliminates the quadratic dependency of the residual stream resolution. Experiments demonstrate that our proposed HiResNets learn to foveate around scenes similarly to human vision, and have superior performance in difficult egocentric video recognition tasks, especially egocentric video with small objects and fine-grained recognition.

## 2. 方法论

### 核心思想

- **残差流作为高分辨率缓冲区**：利用残差网络（ResNet）的残差流（residual stream）保存全分辨率、完整的场景表示；卷积块不直接在全分辨率特征图上计算，而是通过对数极坐标变换（log-polar warp）读取一个"变焦视图"。
- **卷积块仅处理变换后的紧凑张量**：将对数极坐标变换后的低维张量送入卷积块计算，计算成本降至对数平方级别；输出再经逆变换（unwarp）写回残差流，逐步累积完整的高分辨率表示。
- **类似生物眼跳的过程**：各个残差块的焦点可以逐层移动，逐步在不同位置积累高分辨率信息，最终形成完整的场景理解。

### 架构细节

- **块更新公式**：实验证明如下更新方式可行：

```
x ← x + ψ_c^{-1}( f( ψ_c(x) ) )
```

其中 x 为残差流（全分辨率），ψ_c 为以焦点 c 为中心的对数极坐标变换，f 为卷积块序列，ψ_c^{-1} 为逆变换。

- **对数极坐标映射定义**：映射关系为：

```
(i, j) = c + ( exp(ρ)·cosθ, exp(ρ)·sinθ )
```

其中 (ρ, θ) 为对数极坐标，焦点附近分辨率高，距离越远压缩越强。

- **可微双线性采样**：变换与逆变换均采用双线性插值实现（PyTorch grid_sample），保证端到端可训练。

- **自适应焦点预测**：每一阶段（stage）有一个轻量级中心预测模块（center predictor），由两个 1×1 卷积 + ReLU 加 softargmax 组成，根据当前残差流状态预测焦点位置 c。

- **逆变换**：将极坐标张量映射回笛卡尔坐标时的反向映射：

```
(ρ, θ) = ( log||(i', j')||, atan2(j', i') ),  其中 (i', j') = (i,j) - c
```

同样使用双线性插值。

### 复杂度分析（关键贡献）

- **原始残差块**：对 H×W 分辨率特征图做 K×K 卷积，计算复杂度为 O(K²·H·W)，空间维度呈二次方增长。
- **HiResNet 残差块**：卷积仅作用于对数极坐标张量，其维度为 P × Θ，其中 P = O(log H)、Θ = O(log W)，因此计算复杂度为 **O(K²·log H·log W)**——对数平方增长。
- **残差流保持全分辨率**：残差流本身依然是 O(H·W)，但它只涉及廉价的内存拷贝与加法运算，而非卷积操作；反向传播内存可通过梯度检查点（gradient checkpointing）进一步压缩。
- **理论上消除二次依赖**：论文还构建了一个理论构造——通过定义直接的对数极坐标到对数极坐标的变换 W_{k→l}，使得块更新可重写为仅存储各步对数极坐标张量而从不实例化全分辨率残差流，从而消除残差流分辨率的二次依赖（代价是引入对深度的二次依赖）。

## 6. 主要结论与发现

1. **注视行为涌现**：HiResNets 学习到的焦点轨迹与数据集真实注视轨迹表现出较高的距离相关性，表明自适应注视行为是端到端训练的涌现属性，而非显式监督的结果。
2. **更优的缩放行为**：HiResNets 的延迟随分辨率近似线性增长（其余算子占主导），而基线（SqueezeTime、YOLOv11、FOVEA）呈明显的二次方增长。在 1K 分辨率下 HiResNets 仍保持高效。
3. **高分辨率下的性能提升**：在 EgoObjects 上，分辨率从 640 提升至 1200，HiResNets 精度提升约 10%；在 PACO 上，1400 分辨率比 640 分辨率提升约 5%，换取 1.5 倍延迟，显示高分辨率对细粒度任务有实质性帮助。
4. **小物体检测更优**：在小物体类别上，HiResNets 优于所有基线，尤其在小物体占比高的 EgoObjects 和 PACO 数据集上优势更明显。
5. **注视估计领先**：在 EGTEA 和 Ego4D 注视估计任务上，HiResNets 的 AP、AR、F1 均优于 GLC 与 SqueezeTime。
6. **与人类视觉的相似性**：HiResNets 的焦点分布具有解释性——在手部（操作中的物体附近）与远近交替区域具有更高关注度，与人类自我中心视觉注意分布相似。

## 7. 优点与亮点

- **从架构层面解决瓶颈**：不像以往方法在骨干外包装控制模块，HiResNets 重构了残差块内部的计算方式，从根本改变了分辨率缩放规律，是最本质的贡献。
- **理论扎实**：对于残差流的二次方依赖问题，提供了严密的理论构造来消除该依赖，使方法的可扩展性不仅在经验上可用，在理论上也有保证。
- **生物学启发自然、系统**：将中央凹与眼跳两类核心机制都融入了残差网络设计，且提供了可解释性证据（预测注视与人类注视一致）。
- **工程实现简洁**：利用 PyTorch 的 grid_sample 实现可微的对数极坐标变换，不引入复杂的新算子，易于复现和集成到现有 ResNet 变体。
- **实验视角全面**：从计算效率、检测精度、细粒度理解、注视估计等多个维度评估，且专门划分了小/中/大物体子集，分析方法边界。

## 8. 不足与局限

1. **残差流本身仍是全分辨率**：虽然卷积块的计算成本降为对数平方级，但残差流本身仍占用 O(H·W) 内存，需要额外手段（如梯度检查点）来缓解——论文的理论构造尚未在实验中进行完整验证。
2. **对数极坐标变换的开销可能成为瓶颈**：在非常高分辨率下，warp/unwarp 的逐元素操作开销会逐渐逼近甚至超过卷积块本身的成本，限制实际加速幅度。
3. **焦点估计的可靠性未充分验证**：焦点预测的学习机制依赖于任务与数据集中物体的分布；在更大、更复杂、多目标场景中，单一焦点可能不够，多焦点的扩展尚未验证。
