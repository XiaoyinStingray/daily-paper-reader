## 摘要
均匀INT8量化对于部署学习图像编码（LIC）很有吸引力，但其率失真（R-D）性能常常受到重尾张量和大的通道间变化的限制。现有方法主要通过混合精度或非均匀码本来调整量化器。我们提出哈达玛变换域量化（HaTQ），它在量化之前使用正交哈达玛重参数化，将原始域中的权重和激活响应在通道间重新分布。这种重参数化保留了每个线性算子的原始函数映射，同时使其权重和激活更适合均匀INT8量化。HaTQ提供了两种互补形式。双哈达玛量化同时变换输入激活和权重，而仅权重哈达玛量化只变换权重。这种区别很重要，因为常数哈达玛基可以在敏感层中相干地累积非零通道均值并扩大激活范围。我们通过离线分析识别这些敏感层，并为每层分配适当的形式，无需依赖于输入的分支。HaTQ支持训练后量化（PTQ）和量化感知训练（QAT），使用均匀INT8量化器，并兼容仅整数执行。在代表性LIC架构和数据集上的实验表明，在不同量化设置下均有一致的改进。由此产生的QAT模型进一步优于竞争的混合精度和非均匀量化方法。TensorRT部署结果展示了实用的INT8推理效率。源代码将公开发布。

## Abstract
Uniform INT8 quantization is attractive for deploying learned image coding (LIC), but its rate--distortion (R--D) performance is often limited by heavy-tailed tensors and large inter-channel variations. Existing methods mainly adapt the quantizer through mixed precision or non-uniform codebooks. We propose Hadamard-Transform-domain Quantization (HaTQ), which uses orthogonal Hadamard reparameterization before quantization to redistribute weight and activation responses in the original domain across channels. The reparameterization preserves the original function mapping of each linear operator, while making its weights and activations more amenable to uniform INT8 quantization. HaTQ provides two complementary forms. Double-Hadamard quantization transforms both the input activations and weights, whereas weight-only Hadamard quantization transforms only the weights. This distinction is important because the constant Hadamard basis can coherently accumulate a nonzero channel mean and enlarge the activation range in sensitive layers. We identify these sensitive layers through offline profiling and assign the appropriate form to each layer without input-dependent branching. HaTQ supports both post-training quantization (PTQ) and quantization-aware training (QAT), uses uniform INT8 quantizers, and is compatible with integer-only execution. Experiments on representative LIC architectures and datasets demonstrate consistent improvements across different quantization settings. The resulting QAT models further outperform competing mixed-precision and non-uniform quantization methods. TensorRT deployment results demonstrate practical INT8 inference efficiency. The source code will be publicly released.

## 1. 核心问题与整体含义

- **研究动机**：学习图像编码（LIC）模型在实际部署中需要高效、确定性的推理，模型量化（尤其均匀 INT8 量化）是减小存储、内存带宽和算力开销的关键手段。然而，LIC 模型的权重和激活张量具有**重尾分布**和**显著通道间幅度差异**，导致均匀 INT8 量化后率失真（R-D）性能严重下降。
- **现有方法局限**：已有量化方法依赖混合精度（mixed precision）或非均匀码本（non-uniform codebook）来适应张量分布，虽能改善 R-D 性能，但引入异构比特宽度或特殊数值表示，破坏了标准 INT8 推理引擎所要求的规则计算路径，增加了部署复杂度。
- **核心思想**：本文提出 **HaTQ（Hadamard-Transform-domain Quantization）**，将**变换编码**思想引入模型量化：在量化之前对权重和激活施加**正交 Hadamard 重参数化**，在保持原线性算子输入输出映射不变的前提下，将张量分布“整形”为更适合均匀 INT8 量化的形态，从而在不增加量化器灵活性的前提下提升量化性能，且与整数-only 执行兼容。
- **整体含义**：量化质量不仅取决于量化器设计，还取决于张量所处的坐标系统。通过在变换域中更好地利用均匀 INT8 网格，HaTQ 为 LIC 提供了一种兼顾 R-D 性能与硬件部署效率的实用方案。

## 2. 方法论

- **Hadamard 变换基础**：Hadamard 矩阵 H 为正交矩阵（HH^T = I），其每个元素为 ±1/√m 的归一化值。变换将原始向量投影到一组等幅符号组合的基上，能将通道局部的极端响应分散到各个变换分量，从而降低张量的重尾程度和通道间范围不平衡。
- **两种互补的重参数化形式**：
  - **Double-Hadamard（DH）**：对线性层 Y = XW^T 的输入激活 X 和权重 W 同时施加输入侧 Hadamard 变换 H_in，即量化 Q(X H_in) 和 Q(W H_in)。由于 H_in 正交，变换因子在乘积累加中相互抵消，无需输出侧变换。
  - **Weight-only Hadamard（WH）**：仅对权重沿输出通道维度施加变换 H_out，即量化 Q(X) 和 Q(H_out W)，输出累积后再通过 H_out 将结果映射回原输出基。该形式避免了对激活的变换，防止某些敏感层中激活均值在常数基上产生相干放大。
- **层自适应策略选择**：
  - 分析发现：在少数激活敏感层中，非零的通道均值会被 Hadamard 常数基**相干累积**，导致变换后激活的量化范围增大（图 5 中的“coherent spike”）。
  - 通过离线 profiling 计算每层激活经变换后范围扩大的概率 p_l = P(‖H_in(X_l)‖∞ > ‖X_l‖∞)，若 p_l > 0.8 则为该层选择 WH，否则选择 DH。该固定策略在 PTQ、QAT 和推理过程中保持不变，无输入相关分支。
- **整数-only 执行**：
  - 所有 Hadamard 变换的归一化因子被吸收进定点缩放中，变换本身仅需加减法。
  - 推导了层间整数基转换（DH↔WH）所需的正向/逆向变换和缩放倍数，支持 ReLU 等非负齐次激活函数直接传播尺度；对非齐次激活（SiLU、GELU、GDN 等）则需额外的定点非线性核（补料中有完整推导）。
  - 存储预计算的变换后权重，在线激活变换以固定 1×1 卷积实现，兼容 TensorRT 等不含自定义插件即可运行。
- **PTQ 与 QAT 流程**：
  - **PTQ**：采用网络级校准，优化目标 L = R + λD + ηL_reg（含自适应舍入正则），相比传统层级校准更好捕获端到端误差传播；PTQ 中激活使用动态仿射量化，权重用静态对称量化。
  - **QAT**：使用 R + λD 作为目标，激活 scale 通过带异常值保护的 EMA 更新（当瞬时 scale 超过前值 15 倍时不更新），冻结后用于静态推理。
- **Hadamard 构造与填充**：对于任意通道数 C，填充到最小合法 Hadamard 阶数 m(C)，阶数由 Sylvester、Paley 和 Kronecker 构造支持（需满足 ≥ ceil(C/4)*4）。

## 3. 实验设计

- **模型与操作点**：
  - 架构：GMM 和 ELIC 两种代表性 LIC 模型。
  - 每个架构评估 6 个固定码率点（GMM：λ ∈ {0.0018, 0.0035, 0.0067, 0.013, 0.025, 0.0483}；ELIC：λ ∈ {0.0004, 0.0008, 0.0016, 0.0032, 0.015, 0.045}）。
- **数据集**：
  - 训练/校准：QAT 用 MLIC-Train-100K；PTQ 用 DIV2K 的 512 张图像；profiling 用 1000 张图像。
  - 评测：Kodak（24 张）、Tecnick（100 张）、CLIC Professional validation（41 张 2K 分辨率）。
  - 指标：bpp、PSNR，以及相对于 FP32 的 BD-rate（越低越好，负值表示超越 FP32）。
- **对比方法**：
  - QAT 基线：Q-LIC、RAQ-QAT、DynaQuant、FPQ、FMPQ。
  - PTQ 基线：RDO-PTQ、SS-PTQ、RAQ-PTQ、MPPTQ、AWDB-PTQ。
  - 额外参考：LinearQuant、SmoothQuant。
  - 覆盖均匀、非均匀、混合精度，以及通道级/张量级激活量化等多种设置。
- **主要对比结果**：
  - GMM、通道级 QAT：HaTQ 平均 BD-rate 为 **-3.86%**，优于 FMPQ（+1.76%）和 DynaQuant（+1.82%）。
  - GMM、张量级 QAT：HaTQ 平均 +2.06%，显著优于 RAQ-QAT（+14.90%）。
  - GMM、张量级 PTQ：HaTQ 平均 +2.96%，而 AWDB-PTQ 为 +12.44%、MPPTQ 为 +8.07%。
  - GMM、通道级 PTQ：HaTQ 平均 +1.52%，优于 RDO-PTQ（+5.87%）和 SS-PTQ（+4.05%）。
  - ELIC、通道级 QAT：Kodak 上 +0.16%，优于 DynaQuant（+5.97%）；Tecnick 上 +6.33%，相对较弱。
- **消融实验**：
  - 去除所有 Hadamard 变换（四设置下均显著退化，如张量级 QAT 从 +4.29% 恶化到 +18.63%）。
  - 不使用层自适应选择（BD-rate 从 4.29% 升至 9.30%）。
  - 不同校准集大小：512 张后趋于饱和。
- **部署测试**：
  - 使用 TensorRT，任意 INT8 配置（张量级激活、通道级权重），报告不同分辨率下的推理延迟；HaTQ 在 768×512 输入下 13.39 ms/图，对比 INT8 基线 8.13 ms，FP32 24.80 ms；Hadamard 矩阵存储开销仅 1.5 MB。

## 6. 主要结论与发现

- **Hadamard 域重参数化有效**：将权重和激活变换到 Hadamard 域后，张量的超额峰度显著降低（图 2 中下降 95.5% 和 97.6%），SQNR 提升，R-D 性能在不同量化设置下均获得一致改善。
- **均匀 INT8 可胜过混合精度/非均匀量化**：在合适的变换域中使用统一 W8A8 量化，能够达到甚至超越混合精度（如 FMPQ、DynaQuant）和非均匀（如 SS-PTQ）方法，同时保持更简单的整数执行路径。
- **层自适应至关重要**：强制对所有层使用 DH 会因相干累积问题导致性能下降（BD-rate 从 4.29% 恶化至 9.30%），而基于离线 profiling 的 DH/WH 选择有效规避了该风险。
- **网络级 PTQ 校准更佳**：与逐层局部重建相比，端到端 R-D 目标驱动的校准能够更好地协调量化误差在编解码器中的累积效应。
- **部署可行**：TensorRT 实现无需自定义算子，INT8 推理相比 FP32 显著加速，为实际系统集成提供了路径。

- **对非 LIC 任务的可迁移性仅作推测**：论文在多处强调 Hadamard 重参数化的通用性，但实验仅覆盖图像压缩模型，未在检测、分割或生成模型上验证，实际推广价值有待证明。此外，Hadamard 阶数填充（padding）带来的内存和计算冗余在小通道数层中可能不可忽略，论文未量化此类开销。

## 9. 对后续研究的启示

- **量化坐标系统应纳入设计空间**：HaTQ 表明，均匀 INT8 的性能瓶颈并非完全在于量化器表达能力，而在于张量在原始坐标系中的分布形态。后续工作可探索除 Hadamard 外的其他正交变换（如 DCT、随机正交矩阵、学习型旋转矩阵），在保持整数友好性的前提下进一步改善量化友好性。
- **变换矩阵可与模型结构联合设计**：当前 Hadamard 矩阵是固定的，与网络权重无关。未来可将“量化友好变换”作为结构先验或可学习模块嵌入网络架构搜索，使模型在训练阶段即生成更利于量化表示的参数分布，从源头降低量化损失。
- **层自适应策略可扩展为动态选择**：论文采用固定离线策略，切换逻辑简单且部署友好，但其最优性依赖校准集。后续可研究轻量级在线判定法，在推理阶段根据激活统计自适应决定是否施加输入侧变换，或以可微方式将选择过程纳入 QAT 优化目标。
- **网络级校准目标值得深入**：本文以 R + λD 作为 PTQ/QAT 的全局目标获得良好效果，这启发后续研究将量化误差度量从 MSE/SQNR 转向更加任务相关的端到端损失，并探索高效的二阶或近似优化方法以降低校准开销。
- **极低比特下的变换域量化是开放问题**：W4A4 或 W6A6 场景下，变换域分布整形的收益是否会保持、Hadamard 域与更小比特网格的交互规律如何，均是值得探索的方向；此外，结合非均匀码本或混合精度的“变换域 + 灵活量化器”组合，或能进一步缩小与全精度模型之间的差距。
- **部署友好性应更早进入方法设计**：HaTQ 的工程实践表明，量化方法的实用性不仅取决于 R-D 指标，还取决于能否映射到现有推理引擎的规则计算路径。后续研究应在算法设计时将算子融合、无自定义内核、内存占用等条件纳入约束，避免“仿真性能高、实际无法落地”的困境。

## 10. 综合点评

HaTQ 是一篇将经典信号处理思想与深度学习模型量化相结合的高质量工作。其核心价值在于提供了一个简洁优雅且可落地的视角转换：与其升级量化器，不如重塑张量分布使其天然适配现有整数运算设施。论文在动机、设计、实验三方面均表现得较为扎实，尤其是离线层自适应策略和整数-only 执行细节，体现了作者对部署环节的深入思考。研究局限集中在架构覆盖不足、理论框架缺失以及部署效率尚未拉满等方面，但这些并不削弱方法本身的创新性与启发价值。总体而言，该文为学习图像编码乃至更广泛的生成式模型的量化研究提供了一个值得借鉴的坐标框架，也为后续探索“面向量化的表征空间设计”指明了方向。综合打分：**8.5 / 10**。
