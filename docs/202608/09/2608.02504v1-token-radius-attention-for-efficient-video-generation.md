## 摘要
视频扩散Transformer（VDiT）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的头级和块级稀疏方法在查询之间共享计算预算，忽略了令牌特定的注意力需求。我们观察到，保留密度因查询而异，但与注意力熵呈对数线性相关，而主要交互形成以查询为中心的邻域，其半径依赖于令牌。基于这些发现，我们提出了令牌半径注意力（TRA），一个无需训练的框架，将查询熵映射为解析令牌预算，并将其转换为随时间衰减的半径，而无需显式的键排序。融合熵提取、预热复用和块稀疏掩码构建进一步减少了开销。在七个Wan2.1、Wan2.2和HunyuanVideo T2V/I2V配置中，TRA仅保留9%到19%的注意力交互，并实现了1.56倍到2.05倍的加速，同时具有竞争力的生成质量。代码可在 https://github.com/IF-LAB-PKU/Token-Radius-Attention 获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 1. 论文的核心问题与整体含义（研究动机和背景）

视频扩散Transformer（Video Diffusion Transformers, VDiTs）已成为高保真视频生成的主流架构。然而，其核心的密集3D自注意力机制带来O(N²)的查询-键交互计算，其成本随视频时长和分辨率快速增加，注意力已成为模型推理和规模化部署的主要瓶颈。近年已有工作利用注意力的固有稀疏性来降低开销，并分为两类：**头级稀疏方法**（如SVG、Radial Attention）为每个注意力头分配结构化的空间/时间模式；**块级稀疏方法**（如SVG2、SpargeAttn）选择重要的查询-键块对。但二者的共同问题在于：**在头或查询块内部对所有查询共享单一的计算预算假设**。这违背了自注意力以查询行归一化的本质——不同查询的注意力集中程度差异巨大，集中的查询只需少量键，弥散的查询需要大量键。文中数据表明，保留密度在同一层/同头的查询间可相差数量级（图3）。因此，论文提出**Token Radius Attention (TRA)**，旨在查询令牌粒度上实现自适应稀疏分配，同时保留结构化、可高效执行的特征。

## 2. 论文提出的方法论（核心思想、关键技术与公式）

TRA提出了一个**“熵→预算→半径”**（entropy-to-budget-to-radius）的无需训练框架，由两大经验洞察驱动：

- **洞察I（令牌级注意力稀疏性）**：查询的保留密度Bᵢ（达到目标注意力质量τ所需的最少 top-k 键占比）与注意力熵近似呈**对数线性关系**（R²=0.940–0.966）。
- **洞察II（令牌半径注意力模式）**：高注意力键形成以查询为中心的**圆形邻域**，归一化注意力概率随二维空间距离近似**指数衰减**（R²=0.791），且圆半径因查询而异。

具体实现流程：

1. **熵到预算映射（Entropy-to-Budget Mapping）**：基于熵等效均匀支撑假设，推导解析公式：
   - K̂ᵢᵗ = ⌈τ·exp(Hᵢ)⌉（预估键数），B̂ᵢᵗ = τ·exp(Hᵢ)/N。无需逐查询键排序。
2. **预算到半径掩码构造（Budget-to-Radius Mask Construction）**：将预算转化为时空半径：
   - 时间衰减函数 ψ(δ)=exp(−γδ)，帧t的半径 rᵢ,ₜ = rᵢ·ψ(|t−fᵢ|)。
   - 连续域初始化半径 r̂ᵢ = √(K̂ᵢᵗ / (π·ΣF _t=1_ ψ²(|t−fᵢ|)))。
   - 自适应网格校准（离散计数查找表）求最小离散半径，构建掩码 Mᵢⱼ = I[dₛ(i,j) ≤ rᵢ·ψ(|fⱼ−fᵢ|)]。
3. **高效执行（Efficient Execution）**：
   - **Flash Radius Mask Kernel**：将每帧划分空间tiles并重排为tile-major顺序，使保留交互聚集成连续块；CUDA内融合距离计算、半径比较、块剪枝与令牌投票，输出块稀疏掩码供FlashInfer执行。
   - **融合注意力熵内核（Fused Attention Entropy Kernel）**：利用恒等式 Hᵢ=log Zᵢ−Σpᵢⱼsⱼ，在在线softmax中同步累积熵，无需显式物化完整注意力矩阵。仅在去噪前期（前25%）的密集预热步中计算熵，后续稀疏步骤直接复用预算/半径/掩码。

## 6. 论文的主要结论与发现

1. **注意力需求是令牌特异性的**：保留密度的对数与注意力熵线性相关，从经验上打破了均匀预算假设。
2. **注意力交互呈查询中心径向模式**：主导交互形成圆形邻域且半径因查询而异，为结构化稀疏提供几何基础。
3. **熵→预算→半径框架有效**：无需训练即可将令牌级自适应稀疏转换为规则执行结构。
4. **实际性能优异**：仅保留9%–19%注意力交互，实现1.56×–2.05×加速（HunyuanVideo-13B达2.05×），VBench总体分在7个配置中全部位列稀疏方法第一，近乎匹配密集注意力的质量。
5. **自定义内核大幅摊销开销**：Flash Radius Mask与Fused Attention Entropy分别较朴素实现提速10.35×和12.34×。

## 7. 优点（方法或实验设计亮点）

- **理念创新**：首次系统性地将注意力需求从“头/块级统一”推进到“令牌级自适应”，直接对齐softmax按行归一化的本质，实现真正细粒度的计算分配。
