## 摘要
深度路由残差架构允许Transformer层检索早期表示，而非仅继承紧邻的前一状态。然而，现有的块注意残差（Block Attention Residuals）使用单一的内容相关深度混合来构造查询、键和值的输入。这种设计耦合了两个功能上不同的决策：查询和键决定注意力在哪里匹配，而值决定检索到什么内容。因此，我们提出疑问：匹配与内容检索是否应被迫从相同深度读取。我们引入了角色解耦的注意力残差（Role-Decoupled Attention Residuals, RD-AttnRes），这是一种最小扩展，在查询和键之间共享一条深度路由，同时在相同的残差来源上学习独立的值路由。将两条路由查询完全绑定会恢复父架构，而解耦它们则每层仅增加一个模型宽度向量，且不引入额外的token到token注意力操作。我们使用冻结的配对预训练协议在FineWeb-Edu上评估RD-AttnRes，针对120M和343M参数模型，分别使用五个匹配的随机种子，训练预算为20亿token。RD-AttnRes在所有10次配对比较中都改善了验证负对数似然。平均下降分别为0.0301和0.0247，对应困惑度在120M和343M参数下分别降低2.97%和2.43%。早期预算控制表明，额外的参数数量、重复的路由执行或固定的值路由均无法重现这一改进。路由诊断进一步揭示了查询-键与值深度分布之间的持续分歧。这些结果表明，在所评估的训练机制内，注意力匹配与内容检索受益于对残差层级的不同读取。

## Abstract
Depth-routing residual architectures allow Transformer layers to retrieve earlier representations instead of inheriting only the immediately preceding state. Existing Block Attention Residuals, however, use a single content-dependent depth mixture to construct the inputs to queries, keys, and values. This design couples two functionally different decisions: queries and keys determine where attention matches, whereas values determine what content is retrieved. We therefore ask whether matching and content retrieval should be forced to read from the same depth. We introduce Role-Decoupled Attention Residuals (RD-AttnRes), a minimal extension that shares one depth route between queries and keys while learning an independent value route over the same residual sources. Tying the two routing queries exactly recovers the parent architecture, while decoupling them adds only one model-width vector per layer and introduces no additional token-to-token attention operation. We evaluate RD-AttnRes using a frozen, paired pretraining protocol on FineWeb-Edu with five matched seeds for both 120M- and 343M-parameter models and a 2.0B-token training budget. RD-AttnRes improves validation negative log-likelihood in all 10 matched comparisons. The mean reductions are 0.0301 and 0.0247, corresponding to perplexity reductions of 2.97 percent and 2.43 percent at 120M and 343M parameters, respectively. Early-budget controls indicate that neither the additional parameter count, duplicated routing execution, nor a fixed value route reproduces the improvement. Routing diagnostics further reveal persistent divergence between the query-key and value depth distributions. These results suggest that, within the evaluated training regime, attention matching and content retrieval benefit from distinct reads over the residual hierarchy.

## 二、论文提出的方法论

### 2.1 核心思想

作者提出 **Role-Decoupled Attention Residuals（RD-AttnRes）**，一个对 Block AttnRes 的**最小扩展**：
- **Q 和 K 共享一条深度路由（QK route）**
- **V 独立学习另一条深度路由（V route）**，基于完全相同的残差来源集合
- 两者均与 MLP 路由、残差源构造等其余部分解耦

### 2.2 关键技术细节

**父架构（Block AttnRes）的共享路由公式如下：**

给定残差源集合 Sℓ = {sᵢ}（包含嵌入状态、已完成的块输出、当前部分块状态），带学习的路由查询 qℓ ∈ Rᵈ，其深度分数和混合为：

```
eᵢ = qℓᵀ · RMSNorm(sᵢ) + bᵢ
αᵢ = softmax(eᵢ)
hℓ = Σᵢ αᵢ · sᵢ
```

然后单混合向量 hℓ 经 RMSNorm 后投影到三个注意力角色：

```
Q = W_Q · RMSNorm(hℓ)
K = W_K · RMSNorm(hℓ)
V = W_V · RMSNorm(hℓ)
```

**RD-AttnRes 将单一路由查询替换为两个**：qQK（用于 Q 和 K）和 qV（用于 V），各自在相同归一化源上做 softmax，得到两条独立的深度混合：

```
h_QK = Σᵢ α_QK,ᵢ · sᵢ        （其中 α_QK 由 qQK 计算）
h_V  = Σᵢ α_V,ᵢ · sᵢ        （其中 α_V 由 qV 计算）
```

随后：

```
Q = W_Q · RMSNorm(h_QK)
K = W_K · RMSNorm(h_QK)
V = W_V · RMSNorm(h_V)
```

### 2.3 关键技术特征

| 特性 | 说明 |
|---|---|
| **精确恢复性** | 若在每层令 qV = qQK，则 RD-AttnRes 完全退化为 Block AttnRes，说明它是对父架构的严格、可审计的扩展 |
| **参数开销极小** | 每层仅增加一个向量（qV ∈ Rᵈ）。120M 规模增加 9,216 个参数（0.0077%）；343M 规模增加 19,968 个参数（0.0058%） |
| **无额外二次注意力计算** | 不引入新的 O(T²d) token 到 token 注意力项，仅增加 O(BTK_d) 的混合计算 |
| **初始化** | 两个路由查询均零初始化，因此初始分布为均匀分布 |

## 六、论文的主要结论与发现

1. **角色解耦带来一致的收益**：RD-AttnRes 在 120M 与 343M 两规模、共 10 次配对比较中**全部优于** Block AttnRes。平均 NLL 降低 0.0301（S）与 0.0247（M），对应困惑度平均降低 **2.97%**（S）和 **2.43%**（M）。

2. **增益在观测期内持续存在但不断收窄**：0.25B → 2.0B 过程中，S 的差距从 −0.0645 收窄至 −0.0301，M 从 −0.0664 收窄至 −0.0247。

3. **排除替代解释**：Tied 控制精确恢复父模型表现；Average 控制说明“仅仅双路执行”没有收益；Frozen-V 控制说明“固定值路由”不够。只有真正的独立学习值路由带来改善。

4. **QK 和 V 深度路由确实分化**：端点 JS 散度均值约 0.218（S）和 0.215（M），且分布在所有非平凡层中，说明模型学习到了两套不同的深度偏好。

5. **结论有边界**：仅支持“在相同父架构约束、本训练条件下，共享 QKV 深度读取是一个有实质影响的限制”这一**狭窄结论**；不能推广为 universal scaling 或 SOTA 主张。
