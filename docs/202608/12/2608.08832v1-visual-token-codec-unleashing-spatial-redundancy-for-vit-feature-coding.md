## 摘要
大型视觉基础模型的分布式部署通常会将ViT骨干网络分区，并在计算节点之间交换中间令牌特征，这使得在带宽和计算约束下进行高效特征压缩变得至关重要。现有的ViT特征编解码器通常将异质的全局令牌和补丁令牌展平为L x C伪图像，导致熵模型主要捕获序列轴依赖关系，而忽略了原始的二维补丁网格结构。在本文中，我们表明ViT补丁令牌在原始网格上保持了很强的局部空间相关性。为了利用这一结构先验，我们提出了视觉令牌编解码器（VTC），一种双路径学习编解码器，将全局令牌和补丁令牌分离到专门的编码路径中。全局令牌使用轻量级分解先验进行压缩，而补丁令牌则在补丁令牌网格上使用空间-通道上下文熵模型进行编码。为了支持中间层压缩和实用的码率自适应，VTC进一步在后续ViT块之后引入了特征匹配监督，并在单个编解码器内集成了可变码率模块。在DINOv2和SAM3上的实验表明，VTC在分类、分割和检测任务上 consistently 优于代表性的ViT特征编码基线。在非压缩特征性能的90%水平下，VTC在这些任务上减少了15.7倍至37.4倍的比特率。我们还为面向传输和存储的实际部署场景提供了中间层码率-效用分析。

## Abstract
Distributed deployment of large vision foundation models often partitions a ViT backbone and exchanges intermediate token features between computing nodes, making efficient feature compression critical under bandwidth and computation constraints. Existing ViT feature codecs typically flatten heterogeneous global and patch tokens into an L x C pseudo image, causing entropy models to mainly capture sequence-axis dependencies while overlooking the native two-dimensional patch-grid structure. In this paper, we show that ViT patch tokens retain strong local spatial correlations on the original grid. To exploit this structural prior, we propose the Visual Token Codec (VTC), a dual-path learned codec that separates global and patch tokens into dedicated coding paths. Global tokens are compressed with a lightweight factorized prior, whereas patch tokens are encoded on the patch-token grid using a spatial-channel context entropy model. To support intermediate-layer compression and practical rate adaptation, VTC further incorporates feature-matching supervision after subsequent ViT blocks and variable-rate modules within a single codec. Experiments on DINOv2 and SAM3 show that VTC consistently outperforms representative ViT feature coding baselines on classification, segmentation, and detection tasks. At 90% of uncompressed-feature performance, VTC reduces bitrate by 15.7x-37.4x across these tasks. We further provide intermediate-layer rate-utility analyses for practical transmission- and storage-oriented deployment scenarios.

### 一、核心问题与研究动机
- **背景**：大型视觉基础模型（如 Vision Transformer, ViT）在各类视觉任务中取得突破，但其庞大的计算量限制了边缘设备部署。一种自然的解决方案是**分布式部署**，即将 ViT 骨干网络切分为前缀（prefix）与后缀（suffix），在发送端运行前缀，将中间层特征传给接收端完成后缀计算。
- **核心瓶颈**：这种切分引入了通信瓶颈——中间层特征（激活张量）的高维交换需要消耗大量带宽与存储资源，因此**高效压缩中间 ViT 特征**成为分布式推理与特征存储的关键前提。
- **现有方法的问题**：已有 ViT 特征编解码器（如 LaMoFC、DT-UFC、VQFC）通常将异质的全局令牌（如 `[CLS]`/`[REG]`）和补丁令牌（patch tokens）展平为 **L × C 的伪图像**，用熵模型仅捕获序列轴（length 维）的依赖性，而**忽视了补丁令牌在原始 2D 网格上固有的强局部空间相关性**（如滑动窗口 Pearson 相关系数所示）。这一结构先验的丢失限制了压缩效率。
- **研究目标**：设计一种更贴合 ViT 令牌固有结构的编解码器，在极低比特率下保持下游任务性能，并支持中间层压缩（不同部署场景）与可变码率自适应。

### 二、方法论：Visual Token Codec（VTC）
#### 2.1 核心思想
- 将 ViT 中间层特征 `t_n` 中的**全局令牌**（1D 序列，数量极少）与**补丁令牌**（2D 网格，数量占绝大多数）**分离到两条独立的编码路径**，分别匹配其统计特性。
- 补丁令牌在原始 **H × W 网格**上编码，显式利用其空间局部冗余；全局令牌用轻量级因子先验建模。

#### 2.2 关键流程与公式
- **整体变换**：给定特征 `t_n`，经过分析变换 `f_a`（若干可学习 ViT 块）获得潜在表示 `τ_n`，再分离为 1D 分支 `τ^(1d)_n` 与 2D 分支 `τ^(2d)_n`，各自压缩后合并，经合成变换 `f_s` 重建 `t̂_n`：
  `τ_n = f_a(t_n)`，`t̂_n = f_s(τ̂_n)`

- **全局令牌编码**：经 `g_a^(1d)` 映射为低维潜在 `e`，量化后由因子先验熵编码；分布建模采用可学习 CDF 的组合 `C = f_K ∘ ... ∘ f_1`，以得到量化后潜在的概率质量函数（PMF）。

- **补丁令牌编码**：经 `g_a^(2d)` 映射为潜在 `y`，采用 **SCCTX（Spatial-Channel Context）熵模型**（源自 ELIC [13]），包括：
  - 超先验（hyperprior）提供边信息；
  - 通道维度分为 K 块，逐块条件编码；
  - 空间维度采用**棋盘格划分**，非锚点位置利用已解码邻域作为空间上下文；
  - 空间、通道、超先验上下文拼接后由参数网络预测高斯分布参数 (μ, σ)。

- **失真度量**：传统的压缩层 MSE 无法约束量化噪声在后续 ViT 块中的传播，因此引入**特征匹配损失（feature-matching loss）**——将重建令牌送入后续 j 个冻结 ViT 块，在更深的层上计算 MSE：
  `L_D = ||t^(2d)_(n+j) - t̂^(2d)_(n+j)||² + ||t^(1d)_(n+j) - t̂^(1d)_(n+j)||²`

- **总目标**：`L = L_D + λ·(R(e) + R(z) + R(y))`，其中 λ 为拉格朗日乘子。1:1 的全局/补丁失真权重是为同时兼顾全局语义（分类）与局部结构（分割）的折中。

- **可变码率模块**：在单个码率模型内集成 QP 条件调制向量（q1~q4），对编解码特征做通道加权，支持多个码率点。

### 六、主要结论与发现
- **VTC 效率显著优于基线**：在任务特定协议下，达到 90% 未压缩特征性能所需的码率，相对 LaMoFC-VTM 降低 **15.7×–37.4×**（SAM3 检测 20.3×、SAM3 实例分割 15.7×、DINOv2 分类 28.4×、DINOv2 语义分割 37.4×）。
- **多任务兼容可行**：单个压缩位流可同时支撑分割与重建任务；Seg 任务性能远优于重建，说明任务导向特征可保留语义但会丢失像素级细节。
- **中间层选择依部署目标而定**：浅层压缩（如 Layer 0）发送端计算极低（0.6 GFLOPs）但接收端昂贵（87.5 GFLOPs）且 RD 损失大，适合传输导向；深层压缩（Layer 12）发送端代价高（88 GFLOPs）但后缀计算可忽略，适合存储导向；Layer 9 在测试配置中 RD 效率最优。
- **特征匹配监督层是关键设计维度**：相同输入层、不同监督层会显著改变 RD 曲线走向。
- **骨干规模选取需匹配任务与码率指标**：bpp 下 DINOv2-Base 优于 Large，推荐用 bpp 进行跨模型比较。
- **双路径设计（dual-path）优于单路径**：全 1D 最差，全 2D（补零）居中，双路径最优。

### 七、优点
1. **问题洞察精准**：明确指出先前工作忽视 patch token 的 2D 空间结构，并用滑动窗口相关系数定量佐证。
2. **方法设计巧妙**：双路径结构匹配令牌异质性，全局令牌保留语义，补丁令牌利用空间上下文；无需修改下游模型，即插即用型编解码器。
3. **特征匹配损失实用**：将量化失真约束到后续更深层特征，降低了误差传播对下游任务的负面影响。
4. **部署分析深入**：提供了 FLOPs 与 RD 联合视角的中间层分析，对实际系统设计（传输 vs. 存储）有直接价值。
5. **实验覆盖面广**：涉及检测、分割、分类、重建、骨干规模、单模型可变码率等，可信度较高；测试集规模也较稳健。

### 八、不足与局限
1. **算力与复杂度细节缺失**：未报告模型参数量、训练总时长、熵解码耗时等工程指标，影响落地评估。
2. **训练开销偏高**：需要为每个骨干模型单独训练编解码器（每模型 20 epoch，单 GPU），在更大模型上未必经济。
3. **重建任务效果有限**：多任务兼容下的主观重建仍与 Bypass 存在明显差距，任务导向压缩在像素域的可逆性不足。
4. **对比基线范围有限**：缺少与更多近期通用特征编码方案（如 DT-UFC、逐层可扩展编码）的完整对比，结论的普适性待进一步验证。
5. **变量控制有提升空间**：部分比较环节存在不对称设定（如 VQFC 不适用可变分辨率、VTM 编解码时间巨大），可能引入一定程度的偏差。
6. **模型泛化范围有限**：仅验证 DINOv2 与 SAM3，未覆盖更多 ViT 家族（如 SigLIP、LLaMA-3 视觉编码器等），尽管这些模型在相关工作中也是重要目标。
