## 摘要
近期多模态大语言模型（MLLMs），如Qwen2.5-VL和InternVL3，为高分辨率输入生成大量视觉标记，导致显著的计算成本。现有视觉标记剪枝方法要么依赖跨模态注意力，在预填充阶段之前无法剪枝，要么依赖高计算开销的多样性估计。我们观察到来自视觉和文本标记的注意力分数在模态分隔符标记处达到峰值，表明这些分隔符桥接了两个模态。基于这一观察，我们提出SepPrune，一种高效、免训练、即插即用的剪枝方法，使用分隔符标记作为统一查询来排序和选择信息丰富的视觉标记。SepPrune重用LLM内置的投影参数，无需架构更改。在Qwen2.5-VL-7B上的实验表明，SepPrune实现了最先进的性能，在移除80.2%的视觉标记的同时保留了96.3%的原始准确率。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

- **核心突破口**：论文在分析Qwen2.5-VL-7B的注意力分布时，发现**模态分隔符token（modality separator tokens）上出现了显著的注意力峰值**——在浅层网络中，视觉和文本token的注意力都集中汇聚到分隔符位置，且随网络加深逐渐减弱。移除分隔符token造成的性能损失比移除相同数量的视觉或文本token更大。这一现象表明分隔符不仅仅是边界标记，更是**跨模态桥梁（cross-modal bridge）**，在早期帮助对齐和融合视觉与语言表征。
- **整体意义**：基于这一发现，论文提出了一种高效、免训练、即插即用的视觉token剪枝方案，无需改动LLM架构，即可与FlashAttention等加速框架兼容，显著降低推理开销。

## 二、论文提出的方法论

### 1. 核心思想
利用模态分隔符token作为**统一查询（unified query）**，对所有视觉token进行全局重要性评估，然后根据分数保留top-k个信息量最丰富的视觉token，丢弃其余token。

### 2. 关键技术细节
- **输入序列结构**：
  X_input = [T_sys, S_left, V, S_right, T_usr]
  其中T_sys为系统提示token，S_left和S_right为视觉token前后的模态分隔符，V为视觉token序列，T_usr为用户文本token。

- **选择S_right作为查询的原因**：由于因果注意力掩码的限制，只有位于视觉token**之后**的分隔符S_right才能访问完整的图像信息。

- **两个关键简化和设计**：
  1. **分隔符作为统一查询（Separator as Unified Query）**：仅计算分隔符查询向量（Q_sep）与所有视觉token的键向量（K_visual）之间的注意力分数，避免了完整的N×N注意力矩阵计算，将复杂度从O(N²)降至O(N)。
  2. **去除位置编码以消除位置偏差（Removing Positional Encoding for Bias Elimination）**：在计算剪枝分数时有意省略RoPE（旋转位置编码）。因为RoPE会给相邻视觉token分配更高注意力分数，导致剪枝算法偏向保留图像底部的token、误删图像上方的token。去掉位置编码后，评估仅基于token内容本身的重要性，与位置无关。

- **评分公式**：
  Score_prune = softmax(Q_sep · K_visualᵀ / √d_k)
  其中Q_sep是分隔符的查询向量，K_visual是所有视觉token的键矩阵，d_k为查询/键向量的维度。

- **整体流程**：
  获得分数向量 → 保留top-k高分token → 将筛选后的视觉token与分隔符、文本token拼接 → 送入LLM进行后续推理。

### 3. 方法优势
- 所有剪枝计算在LLM主干之前完成，不打断计算流，可与FlashAttention无缝兼容。
- 复用LLM自身的投影参数（q_proj、k_proj），无需额外训练或引入新参数。
- 无需依赖[CLS]等特定视觉骨干架构标记，适用范围更广。

## 六、论文的主要结论与发现

1. **揭示分隔符的跨模态桥梁作用**：这是首次通过注意力分析和消融实验系统证明模态分隔符token在MLLM早期层中扮演跨模态交互的核心枢纽角色。
2. **SepPrune方法有效性强**：在Qwen2.5-VL-7B上，剪掉80.2%视觉token时仍保持96.3%的相对性能；剪掉60.5%时保持99.0%的原始性能，显著优于所有对比方法。在InternVL3-8B上以80%剪枝率取得93.1%相对分数，验证了跨架构泛化性。
3. **计算效率显著提升**：算法复杂度为O(N·D²)（线性），远优于对比方法的O(N²·D)；在NVIDIA H20上端到端延迟从760.4s降至591.4s，优于DivPrune（598.7s）和CDPruner（639.9s）。
4. **设计选择得到验证**：使用后置分隔符（S_right）作为查询优于使用最后token或前置分隔符（S_left）；去除RoPE位置编码可显著提升剪枝后性能（MME提升82分，TextVQA提升7.2分）。

## 七、优点

- **思路新颖**：从注意力分布异常现象出发，首次识别并利用分隔符token的桥梁功能来指导剪枝，提供了理解MLLM跨模态融合机制的新视角。
- **方法简洁高效**：免训练、即插即用、无架构改动，计算复杂度从O(N²)降为O(N)，理论优雅且工程可落地性强。
- **设计严谨有据**：每个关键技术决策都有对应的动机分析和消融验证（分隔符选择的因果掩码依据、去除RoPE的偏差分析），逻辑链完整。

- **泛化性好**：在两种不同的MLLM架构上均取得领先结果，且在信息密集的OCR/图表任务上表现稳定。
