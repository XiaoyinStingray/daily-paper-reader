## 摘要
视觉-语言-动作（VLA）模型已展现出在具身智能中的强大潜力，但其在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）虽然提高了效率，但将VLA模型视为全精度工作负载，留下了大量内存和计算冗余未被充分利用。本文提出VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态来加速VLA推理。我们首先引入MotionVQ，一种运动感知向量量化方案，根据机器人的执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。随后，我们提出一种基于质心合并的向量化GEMM范式，该范式在码本索引表示上运行，通过空间聚合和时间质心复用来消除冗余乘法。为实现这些优化，我们设计了一种加速器，有效支持动态精度选择和质心复用计算。实验结果表明，与A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM相比，VQVLA分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度下降可忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型是具身智能的关键使能技术，能够将感知、推理与动作控制相结合，使机器人完成物体操作、空间导航等复杂任务。然而，VLA 模型在 GPU 上的推理延迟过高，严重制约了其在资源受限的边缘设备、有限功耗预算和高控制频率要求下的实时部署。
- **现状瓶颈**：通过对 OpenVLA、OpenVLA-OFT、RDT 三种 VLA 模型的推理延迟分解分析，作者发现 **Transformer 主干网络（如 LLaMA2-7B，参数约 14GB）平均占推理总耗时的 80.6%**，是绝对的性能瓶颈。其问题体现在两方面：
  - **高片外内存带宽压力**：14GB 参数需频繁访问片外内存；
  - **高计算强度**：每层 Transformer 包含多个形状为 N×4096×4096 及 N×N×4096 的 GEMM 运算。
- **现有方案不足**：已有加速器（如 Dadu-Corki）通过预测多条未来动作来降低 VLA 调用频率，但将 VLA 模型视为"全精度黑盒"，**未利用模型内部的权重相似性和执行动态冗余**。传统量化方法（如 MX 量化、逐元素异常值量化）在相同压缩率下精度不如向量量化（VQ），但现有 VQ 方法采用静态精度策略，忽略了机器人不同执行阶段对量化的敏感性差异。
- **核心洞察**：作者发现**机器人执行动作的幅度（motion magnitude）与其对量化扰动的敏感度强相关**——靠近目标物体时（执行态，execution state）动作幅度小、需要精细调节，对量化高度敏感；在位置间转移时（过渡态，transition state）动作幅度大、约束少，对扰动更容忍。此外，VQ 量化后码本索引访问呈现明显的**"热质心"集中现象**（图 6 显示最热质心访问频率 234 次 vs 最冷质心仅 10 次），为计算复用提供了机会。

### 2. 方法论：核心思想、关键技术细节

论文提出 **VQVLA**，一个算法-硬件协同设计框架，包含三大核心组件：

#### 2.1 MotionVQ（运动感知向量量化）
- **状态预测（State Prediction）**：基于上一次 VLA 推理输出的 3D 动作，计算运动幅度 D = √(Ax² + Ay² + Az²)，将 D 与预定义阈值 Td 比较：
  - D ≤ Td（Td = 0.8）→ **执行态（execution state）**，靠近目标物体，需高精度；
  - D > Td → **过渡态（transition state）**，粗粒度运动，可容忍低精度。
- **精度自适应（Precision Adaptation）**：离线准备两套 VQ 精度配置：
  - **高精度集**：VQ[256, 2, 256]，256 个质心、8bit 索引，平均位宽 4.125 bits；
  - **低精度集**：VQ[128, 2, 64]，64 个质心、4bit 索引，平均位宽 3.125 bits。
  - 运行时根据预测状态动态选择对应码本和索引矩阵，在保持任务成功率的同时降低内存占用。

#### 2.2 Merged-Centroid Vectorized GEMM（质心合并向量化 GEMM）
- **空间合并（Spatial Merging）**：利用**同一列内**重复的质心索引，根据乘法分配律，先将映射到相同质心的多个输入累加，再做一次乘法：∑(Iᵢ × Centroid) → ∑(Iᵢ) × Centroid。通过构建"空间质心位置表"记录质心 ID 与权重向量 ID 的映射，丢弃仅有一个或零个权重向量映射的条目，实现输入预聚合消除冗余乘法。
- **时间复用（Temporal Reusing）**：利用**跨列间**重复的质心索引。离线用 Top-k 选择最频繁访问的热质心，运行时用（质心 ID, 权重向量 ID）元组作为标签在结果缓存中查找，若命中则直接复用先前计算好的质心-激活乘积，跳过冗余乘法；未命中则正常计算。
- 该方法**完全跳过反量化步骤**，直接在压缩域（码本-索引表示）上执行 GEMM。

#### 2.3 定制硬件加速器架构
- **状态预测器**：轻量级运动幅度计算单元（3 个乘法器 + 1 个加法器）+ 阈值比较器。
- **索引处理引擎**：多个索引处理单元（IPU）并行遍历索引矩阵列，构建空间质心位置表（Cnt > 1 的条目）和时间质心位置表（Cnt = 1 的条目）。
- **矩阵乘法引擎**：
  - **空间合并 PE 阵列**（24×256 PEs + 24×128 三级流水线加法树）：三级流水线加法树支持 3 个周期内完成 1 个 8 输入归约、2 个 4 输入归约、4 个 2 输入归约，共产生 7 个部分和；每个 PE 配备约 3 个乘法器与加法器以保持流水化吞吐。
  - **时间复用 PE 阵列**（24×256 PEs + 1.5MB 结果缓存）：缓存初始化单元预计算热质心乘积，查询命中走加法路径（hit buffer），未命中走乘法路径（miss buffer），最终合并两者结果。
- **数据流**：① MotionVQ 状态预测并获取码本/索引 → ② 索引处理引擎构建质心位置表 → ③ 空间合并与时间复用并行流水执行。

- **洞察新颖且实用**：首次将机器人执行状态（运动幅度）与 VQ 量化精度动态关联，利用"过渡态高容忍、执行态高敏感"的物理直觉指导精度选择，切入点巧妙且有实验验证（噪声注入实验证实过渡态对扰动更鲁棒）。
- **算法-硬件深度协同**：MotionVQ（内存优化）与质心复用 GEMM（计算优化）在算法层面互补，硬件架构针对性地支持空间聚合（加法树）与时间复用（结果缓存），形成完整的协同设计闭环。

### 8. 局限性与潜在批评点

- **VQVLA 算法在 GPU 上不直接受益**：论文披露在 A100 上运行 VQVLA 算法（GPU-VQVLA）时出现 45.2% 的性能损失。原因是码本索引的稀疏访存无法利用 GPU 的稠密 SIMT 架构，且动态精度切换带来 kernel launch 开销。该结果表明其收益高度依赖专用硬件，算法本身不具备跨平台迁移性，在实际部署中会面临生态壁垒。
- **VQ 精度配置未完全自适应**：虽然精度在“执行态/过渡态”间动态切换，但两套码本仍是静态离线训练的，并未根据具体任务、具体场景或模型个体差异进行在线自适应更新。若测试环境与训练分布偏移较大，码本表示能力可能下降。
- **运动幅度的单一阈值 Td 依赖经验标定**：Td=0.8 虽通过 10% 数据校准获得，但该启发式规则本质上依赖动作空间尺度（不同机器人、不同任务的动作向量范围可能差异很大），对跨平台/跨形态的通用性提出疑问。
- **热质心时间复用存在失效场景**：时间复用仅对“Top-k 热质心”有效，若任务切换频繁导致权重分布变化，热质心集合可能漂移，缓存命中率下降。此外，1.5MB 结果缓存对长时间连续任务可能面临缓存污染问题。
- **泛化评估集中于仿真环境**：所有实验均在 LIBERO 和 ManiSkill 仿真基准上进行，未涉及真实机器人物理平台验证。仿真中的动作分布、噪声模型与真实世界存在差异，硬件实际部署效果仍需进一步验证。
- **缺少模型训练阶段的联合优化**：VQVLA 仅在推理侧做后训练量化与加速，码本本身未参与端到端梯度微调，理论精度上限受限于离线码本质量，未探索“量化感知微调（QAT）”进一步提升精度与压缩率的空间。
- **对比公平性细节有待加强**：论文未详细报告 A100 基线所使用 batch 大小、模型并发度、CUDA 优化细节；与 Dadu-Corki 对比时也未给出其具体时延分解数据，可能影响结果的置信度。

### 9. 个人评价与影响力判断

VQVLA 是一篇典型的**算法-架构协同设计（algorithm-architecture co-design）**高质量工作，其价值体现在三个层面：

1. **问题选择精准**：VLA 模型在具身机器人边缘部署中的延迟瓶颈确实是当前实际痛点，且作者通过延迟分解实验给出了定量证据（Transformer 主干占 80.6% 时延），问题定义清晰且有说服力。
2. **洞察具有领域启发性**：将机器人执行状态与量化敏感度关联，是少数从“机器人任务特性”出发而非纯粹从“模型结构”出发的量化加速方案，这一思路可能启发后续工作探索更多任务级动态性（如抓取成功率、碰撞检测等）与硬件加速的结合。
3. **工程贡献完整**：从算法设计、硬件微架构、RTL 综合到系统级仿真评估形成了完整闭环，且所有设计参数均经过扫描优化，实验可信度较高。

若该工作后续能：开放硬件源代码、补充真实机器人平台验证、引入 QAT 联合训练码本，其影响力有望从学术研究延伸至实际具身智能产品部署。总体属于**领域内一流会议/期刊水平的代表性工作**。

### 10. 总结要点（一句话）

VQVLA 通过运动感知的自适应向量量化与质心合并 GEMM 协同设计，在平均任务成功率仅下降 2.5% 的前提下，实现了较 A100 6.5× 的推理加速与 75.5× 的能效提升，为边缘端实时 VLA 推理提供了一套完整的算法-硬件协同方案。
