## 摘要
近期的高分辨率多模态大语言模型（MLLMs）每个输入会生成数千个视觉令牌，导致视觉令牌爆炸，带来严重的延迟瓶颈。虽然令牌剪枝可以缓解这一问题，但最先进的子集优化方法通常依赖迭代子集构建来同时捕获视觉多样性和指令相关性。随着视觉令牌数量的增加，这种顺序依赖引入了显著的选择开销，严重限制了理论FLOPs减少向实际加速的转化。为解决这一限制，我们提出了单次前向剪枝器（SFPruner），这是一种视觉令牌剪枝的结构性重构，将冗余控制直接嵌入评分空间，无需迭代组合优化。我们的非迭代框架通过两种互补机制，在单次前向传播中实现冗余感知的重要性选择。首先，为了在协方差级别减弱冗余，我们引入了一种语义引导的岭杠杆方案。通过整合指令相关性和视觉显著性，该机制抑制主导协方差方向并缓解表示偏差。其次，基于排序的方向性掩码通过非对称相似性竞争解决剩余重叠，其中得分较高的令牌通过并行张量操作显式抑制冗余的低分替代令牌。大量评估表明，我们的方法保持稳定的选择成本，在Qwen2.5-VL中，令牌选择过程从112.4毫秒降至仅2.5毫秒（512个令牌），减少了高达110毫秒。这种结构性效率成功地将理论令牌减少转化为实际的推理加速，同时在激进压缩下保持了与最先进技术相当的高度竞争性性能。

## Abstract
Recent high-resolution Multimodal Large Language Models (MLLMs) generate thousands of visual tokens per input, leading to a visual token explosion that introduces severe latency bottlenecks. While token pruning mitigates this issue, state-of-the-art subset-optimization methods typically rely on iterative subset construction to jointly capture visual diversity and instruction relevance. As visual token counts scale, this sequential dependency introduces significant selection overhead, severely limiting the translation of theoretical FLOPs reductions into actual wall-clock speedups. To address this limitation, we propose Single-Forward Pruner (SFPruner), a structural reformulation of visual token pruning that embeds redundancy control directly into the scoring space, bypassing the need for iterative combinatorial optimization. Our non-iterative framework achieves redundancy-aware importance selection in a single forward pass through two complementary mechanisms. First, to attenuate redundancy at the covariance level, we introduce a semantics-guided ridge leverage scheme. By integrating instruction relevance and visual saliency, this mechanism suppresses dominant covariance directions and mitigates representation bias. Second, ranking-based directional masking resolves residual overlap through asymmetric similarity competition, where higher-scoring tokens explicitly suppress redundant lower-scoring alternatives via parallel tensor operations. Extensive evaluations demonstrate that our approach maintains stable selection costs, reducing the token selection process by up to 110 ms, from 112.4 ms to just 2.5 ms at 512 tokens in Qwen2.5-VL. This structural efficiency successfully translates theoretical token reductions into tangible inference speedups while preserving highly competitive performance against state-of-the-art techniques under aggressive compression.

## 2. 方法论：SFPruner

### 核心思想
SFPruner（Single-Forward Pruner）是一种非迭代式剪枝框架，将冗余控制分解为两个互补的并行机制：(1) 协方差级别的全局冗余衰减；(2) 配对级别的局部重叠抑制。整个流程无需任何针对 K 的迭代循环，可一次性完成 Top-K 选择。

### 技术细节（三步流程）

**Step 1：语义引导（Semantic Guidance）**
- **文本相关性**（Textual Relevance）：计算每个视觉令牌与文本嵌入之间的温度缩放余弦相似度，归一化为相关性分数 S_rel,i。
- **视觉显著性**（Visual Saliency）：从视觉编码器的自注意力中提取全局令牌（如 CLS）到各视觉令牌的注意力权重 S_attn,i；若无 CLS（如 Qwen2.5-VL），则通过聚合所有空间令牌的自注意力权重构造代理显著性。
- **融合与归一化**：线性融合 S_guide,i = α·S_rel,i + (1-α)·S_attn,i，再经 Min-Max 归一化得到 S̃_guide,i，作为基础重要性分数。对于没有文本编码器的架构则仅使用视觉显著性。

**Step 2：语义引导的岭杠杆评分（SG-RLS，协方差级冗余衰减）**
- 定义特征协方差矩阵 C = VᵀV（D×D）。
- 计算每个令牌的岭杠杆分数 ℓᵢ = vᵢ(C + λI_D)⁻¹vᵢᵀ。该分数通过 (C + λI_D)⁻¹ 抑制特征空间中的主导特征方向，使与高能量子空间对齐的冗余令牌获得较低分数，而结构上独特的令牌获得较高分数。
- 最终协方差级分数：S_SG-RLS,i = ℓᵢ · S̃_guide,i。乘法形式作为"软与门"，要求令牌既结构独特又语义相关。
- **关键工程优化**：利用 Woodbury 矩阵恒等式在 N×N Gram 矩阵与 D×D 特征协方差之间建立等价关系，在 N > D 的高分辨率场景中仅需对较小的 D×D 矩阵求逆（配合 Cholesky 分解），将计算复杂度降至 O(ND²)，避免了 O(N³) 的高额开销。

**Step 3：基于排序的方向性掩码（Ranking-Based Directional Masking）**
- 构建余弦相似度矩阵 C_sim = VVᵀ（N×N）。
- 根据 SG-RLS 分数构造方向性掩码矩阵 M_ij = I(S_SG-RLS,j > S_SG-RLS,i)，即只允许分数更高的令牌抑制分数更低的令牌，形成非对称竞争。
- 对令牌 i 的抑制惩罚：Pᵢ = 1 − max_j(M_ij · C_sim,ij)。若不存在更强令牌与它高度相似，Pᵢ 保持接近 1；否则按最大重叠程度按比例降低。
- 最终分数：S_final,i = S_SG-RLS,i · Pᵢ，然后单次 Top-K 选择。

整个过程由并行张量操作组成（矩阵乘法、逐元素比较、行归约），避免了迭代子集更新的顺序瓶颈。

## 6. 主要结论与发现

1. **非迭代剪枝可行且高效**：SFPruner 在保持冗余感知能力的同时消除了迭代依赖，选择延迟恒定且极低——在 Qwen2.5-VL 的 512 令牌设置下将选择时间从 CDPruner 的 112.4 ms 降至 2.5 ms（减少约 110 ms）。
2. **性能保持竞争力**：在 LLaVA-NeXT 上，640 令牌保留时达到 100.0% 相对性能；320 令牌时 98.2%；160 令牌时 96.4%，与优化式方法相当或更优。Qwen2.5-VL 上 40% 保留时 99.0%，20% 保留时 96.5%，优于学习式的 VisionSelector。
3. **视频场景泛化良好**：512 令牌/帧时达到 94.9% 相对性能，为所有对比方法中最高；延迟仅 3.1 ms。
4. **极端规模下优势显著**：9,216 令牌时剪枝耗时仅 28 ms（对比 DivPrune 458 ms、CDPruner 576 ms），预填充延迟从 1,813 ms 降至 1,114 ms，总推理时间从 6,101 秒降至 3,601 秒，FLOPs 节省切实转化为墙钟加速。
5. **消融验证结构有效性**：SG-RLS + 方向性掩码的组合最优（98.3% 相对性能，2.3 ms），两者互补地解决全局与局部冗余；方向性掩码性能接近顺序搜索（97.9% vs 98.0%）但延迟低一个数量级以上（0.8 ms vs 18.6 ms）。

## 7. 优点

- **方法创新性强**：将视觉令牌剪枝从"迭代选择"重新构建为"评分空间中的结构化冗余控制"，概念上简洁优雅，是通过算法结构而非更重模型解决效率问题的一个良好范例。
- **可扩展性设计严谨**：利用 Woodbury 恒等式在 Gram 矩阵与协方差矩阵之间切换，让复杂度适配输入规模，避免了大矩阵求逆，降低了数值不稳定性。
- **计算开销稳定有界**：剪枝延迟与保留令牌数 K 无关（2.5 ms 在 40% 和 20% 保留率下均保持一致），这是与所有迭代式方法的关键结构差异。
- **无需训练、即插即用**：适用于多种 MLLM 架构（LLaVA-NeXT、Qwen2.5-VL、LLaVA-Video），部署成本低。
- **实验验证充分**：覆盖图像/视频、多模型、多压缩率及极端压力测试，且对比方法均为近两年最新工作（CVPR/ICCV/NeurIPS/AAAI 等）。
