## 摘要
本文研究了当实际更新受到持久且状态依赖的偏差影响时随机梯度下降（SGD）的收敛性，其中期望的更新按分量乘以响应函数。我们的第一个贡献是证明在此设置下，SGD隐式地优化了一个惩罚问题，其最小化器与真实最小化器不一致。为了缓解这种收敛失败，我们将原始任务重新表述为等价的双层优化问题，并提出了一种基于梯度的算法，称为残差学习。理论分析表明，尽管存在硬件缺陷，残差学习仍能找到原始无偏优化问题的解。除了精确收敛外，我们还通过硬件条件数量化了响应函数对收敛复杂度的影响，并通过构造一个困难实例表明，对硬件条件数的多项式依赖在一般情况下是不可避免的。数值模拟支持了理论结果，并展示了所提出算法的有效性。

## Abstract
This paper studies the convergence of stochastic gradient descent (SGD) when the implemented updates are subject to a persistent and state-dependent bias, in which the desired update is scaled by response functions component-wise. Our first contribution is to demonstrate that SGD in this setting implicitly optimizes a penalized problem whose minimizer does not coincide with the true minimizer. To mitigate this convergence failure, we reformulate the original task as an equivalent bilevel optimization problem and propose a gradient-based algorithm, termed Residual Learning. Theoretical analysis shows that Residual Learning finds a solution to the original, unbiased optimization problem despite the hardware imperfections. Beyond exact convergence, we quantify how the response functions affect convergence complexity via the hardware condition number and show that a polynomial dependence on it is unavoidable in general, via a construction of a hard instance. The theoretical results are supported by numerical simulations that demonstrate the effectiveness of the proposed algorithm.

- **核心问题**：在模拟硬件上执行SGD时，期望的更新 ∆z 会被状态依赖的响应函数 q+(·) 或 q-(·) 逐分量缩放（由更新符号决定），导致更新不对称。这种持久状态依赖偏差使得标准SGD**不再收敛到原优化问题的真实最优解**，而是收敛到一个隐式惩罚问题的解。
- **整体含义**：本文首次系统研究此类硬件偏差对梯度优化算法的影响，提出了一种理论上有保证的算法（Residual Learning），并量化了硬件条件数对收敛复杂度的影响。这项工作为模拟硬件上的深度学习训练提供了理论基础和实践算法，对弥合模拟计算与数字计算之间的优化性能差距具有重要意义。

## 2. 论文提出的方法论

### 2.1 核心思想
- 解释为何SGD在持久状态依赖偏差下收敛失败：通过构造偏差项（由响应函数不对称性 G(·) 与随机梯度一阶矩 Σ 组成），证明SGD隐式优化问题 IP（惩罚问题），其极小值点与真实最优值点不一致。
- **关键解决思路**：将原问题重构为等价的双层优化问题，构造一个辅助变量（残差），使其在最优解处与对称点重合，从而让隐式惩罚不再将优化方向拉离真实解。

### 2.2 模型与公式
- **硬件更新模型**：模拟更新算子

  A(∆z; z) = ∆z·q+(z)（∆z ≥ 0）或 A(∆z; z) = ∆z·q-(z)（∆z < 0）

  分解为 F(z) = (q-(z)+q+(z))/2 和 G(z) = (q-(z)-q+(z))/2，得到

  Z_{k+1} = Z_k + ∆Z_k ⊙ F(Z_k) - |∆Z_k| ⊙ G(Z_k)

- **隐式惩罚问题（IP）**：

  min f_Σ(W) = f(W) + ⟨Σ, Rc(W)⟩

  其中 Σ = E[|∇f(W*;ξ)|]（梯度噪声的一阶矩），Rc 是不对称比的积分。惩罚项将迭代点拉向对称点 W⋄，偏离真实解 W*。

- **双层重构（BP）**：

  min_W (γ²/2)‖P*(W) - W⋄‖²,
  s.t. P*(W) = argmin_P f(W + γ(P - W⋄))

  其中 P*(W) 表示残差（即 W 与 W* 之间的差距）。该问题求解得到 W*。

### 2.3 Residual Learning 算法流程
- **内层（P更新，估计残差）**：
  P_{k+1} = P_k - α∇f(W̄_k; ξ_k) ⊙ F(P_k) - α|∇f(W̄_k; ξ_k)| ⊙ G(P_k)
  其中 W̄_k = W_k + γ(P_k - W⋄) 为平移后的权重。

- **外层（W更新，最小化残差）**：
  W_{k+1} = W_k + βγ(P_{k+1} - W⋄) ⊙ F(W_k) - βγ|P_{k+1} - W⋄| ⊙ G(W_k)

- **核心特点**：两层更新都受硬件偏差影响，但由于上层的梯度（残差）在最优处恰好与对称点重合，隐式惩罚不再造成偏差，整体算法仍收敛到原问题的解。

### 2.4 理论贡献
- **定理1**：刻画了Analog SGD隐式优化惩罚问题 IP，惩罚强度与噪声水平 Σ 成正比。
- **定理2/3**：证明 BP 与 IBP 均与原问题 P 等价，即双层重构不会丢失原问题解。
- **定理4**：Residual Learning 的收敛率上界为 Õ(κ₁κ₄²σ²/μK)，其中 κ₁ 是目标条件数，κ₂ = q_max/q_min 是硬件条件数。
- **定理5**：通过构造硬实例，证明任何算法对 κ₂ 至少产生 Ω̃(κ₂²σ²/μK) 的下界依赖，即对硬件条件数的多项式依赖不可避免。

1. **Analog SGD 收敛失败**：在持久状态依赖偏差下，Analog SGD 不收敛于 f 的真实最优解，而是隐式优化惩罚问题 f + φ(W)，收敛点偏向硬件对称点 W⋄，偏差程度随梯度噪声水平增大而增大。
