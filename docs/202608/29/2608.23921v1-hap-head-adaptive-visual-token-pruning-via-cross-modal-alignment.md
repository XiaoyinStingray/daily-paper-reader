## 摘要
近期视觉-语言模型将高分辨率图像编码为长视觉令牌序列，导致高昂的预填充成本。为压缩这些令牌，现有方法通过将所有头部的文本-视觉注意力均匀平均来为每个视觉令牌打分，这假设每个头部都与查询匹配。然而，我们的实证分析表明，错位的头部主导了平均值，放大了背景令牌并淹没了细粒度线索。为解决此问题，我们提出PAQ（提示-接地注意力质量），一种量化每个头部如何将提示与图像区域对齐的度量。基于PAQ，我们的剪枝分三个阶段进行。给定目标FLOPs预算，我们首先将Transformer层划分为组，并为每组分配视觉令牌预算。在每个组内，我们通过PAQ加权softmax将每个头部的注意力图聚合为组级矩阵。最后，我们根据该矩阵的幅度对视觉令牌打分，并保留每组分配的预算。通过使用PAQ加权头部，我们的方法根据更真实反映提示相关性的注意力信号对令牌打分，而不是通过均匀平均稀释它们。在18个基准测试中，我们的方法实现了最先进的权衡。具体而言，在LLaVA-1.5-7B（9个任务）上，仅保留\textbf{5.6\%}的令牌即可保持\textbf{99.1\%}的原始性能，超过最强基线AutoPrune 4.2个百分点。代码可在https://github.com/baokou-fw2/HAP获取。

## Abstract
Recent Vision-Language Models encode high-resolution images into long visual token sequences, incurring prohibitive prefill costs. To compress them, existing methods score each visual token by averaging text-to-visual attention uniformly across all heads, which assumes every head matches the query. However, our empirical analysis shows that misaligned heads dominate the average, amplifying background tokens and drowning out fine-grained cues.   To address this, we propose PAQ (Prompt-Grounded Attention Quality), a metric quantifying how well each head aligns the prompt with image regions. Built on PAQ, our pruning proceeds in three stages. Given a target FLOPs budget, we first partition the transformer layers into groups and allocate a visual token budget to each. Within each group, we then aggregate per-head attention maps via PAQ-weighted softmax into a group-level matrix. Finally, we score visual tokens by this matrix's magnitude and retain the allocated budget per group. By weighting heads with PAQ, our method scores tokens by attention signals that more faithfully reflect prompt relevance, rather than diluting them through uniform averaging.   Across 18 benchmarks, our method delivers state-of-the-art trade-offs. Specifically, on LLaVA-1.5-7B (9 tasks), retaining only \textbf{5.6\%} tokens preserves \textbf{99.1\%} of the original performance, surpassing the strongest baseline AutoPrune by 4.2 points. Code is available in https://github.com/baokou-fw2/HAP.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：现代视觉-语言模型（VLMs，如 LLaVA、InternVL、Qwen-VL 等）为捕捉细粒度细节，采用高分辨率视觉编码器，将一张图像编码为数百至数千个视觉 token。这导致自回归预填充（prefill）阶段的计算和内存开销呈爆炸式增长，成为实时部署与资源受限环境中的关键瓶颈。
- **现有方法缺陷**：已有的视觉 token 剪枝方法（如 SparseVLM、PDrop、AutoPrune 等）虽利用跨模态注意力统计来排序和剪枝，但都隐含一个关键简化假设——所有注意力头对提示相关区域的关注程度相同，因此对所有头的注意力分数做**无差别均匀平均**。
- **核心发现**：论文通过实证分析揭示，注意力头存在三种截然不同的跨模态模式（图 1）：
  - **Sink heads（汇聚头）**：无论文本提示如何变化，固定关注某些区域；
  - **Dispersed heads（分散头）**：注意力广泛分散，与提示无清晰对应；
  - **Optimal heads（最优头）**：注意力集中在随查询变化的任务相关区域。
- **均匀平均的危害**：错位的头（sink/dispersed）在平均过程中占主导地位，放大背景 token 并淹没细粒度线索。图 2 表明，使用均匀头平均选出的 token 在任务准确率和空间定位（IoU）上均 consistently 落后于使用单一最优头选出的 token。

### 2. 方法论

#### 2.1 PAQ（Prompt-Grounded Attention Quality，提示接地注意力质量）

- **核心思想**：基于不确定性系数（Theil's uncertainty coefficient）定义 PAQ 分数，纯粹从 post-softmax 内在注意力统计中计算，无需额外参数：

  \[PAQ = \frac{I(V; T)}{H(V)}\]

  其中 \(I(V; T)\) 度量视觉分布被文本查询驱动的程度，\(H(V)\) 度量总视觉不确定性。该比值介于 0–1 之间，表征视觉分布中被查询解释的比例。
- **计算方式**：将交叉注意力权重 \(\alpha_{ji}\) 视为软相关性分配 \(\hat{p}(v_i|t_j)\)，采用均匀文本先验，构造联合分布后代入公式计算。
- **失效模式对应**：sink 头与 dispersed 头的注意力权重对文本 token 不变，导致 \(I(V;T)=0\)，PAQ 接近零；只有 optimal 头产生随查询变化的条件分布尖峰，获得高 PAQ。因此 PAQ 能在这三者中唯一区分出 optimal 头。

#### 2.2 HAP 剪枝框架

HAP 采用三阶段流程，唯一用户输入是目标 FLOPs 预算：

1. **分组与预算分配**：将 L 个 transformer 层划分为 M 个连续组，每组 L/M 层。按几何金字塔结构分配视觉 token 预算：第 g 组预算为 \(N_v^{(g)} = V/(1+g)^2\)。组数 M 通过闭式成本函数 \(F_{pruned}(m)\)（式 10）从 FLOPs 预算直接推导，无需逐任务调参。
2. **PAQ 加权聚合**：在每个层内，对所有 H 个头的注意力图计算 PAQ，通过中心化 softmax（式 5–6）获得加权系数，融合得到层注意力图；再以同样的 PAQ-softmax 过程将组内 L/M 个层的注意力图融合为组级注意力矩阵。
3. **Token 评分与剪枝**：对每个视觉 token，按组级注意力矩阵在所有文本位置上的均值（式 8）作为重要性分数，保留每组预算对应的 top-K token。

- **关键创新**：用 PAQ 引导的 softmax 聚合替代均匀头平均，高 PAQ 头获得更大权重，低 PAQ 头被软性抑制，使 token 评分更忠实反映提示相关性。

#### 2.3 效率与兼容性

- PAQ 计算直接复用前向传播中的注意力矩阵，总开销为 \(O(HN_tVL/m)\)，严格小于未剪枝注意力成本，属于低阶项。
- 扩展 FlashAttention 的 dual-flash 策略，通过分块累积统计量，无需物化完整的 \(O(N^2)\) 注意力图，避免了 FlashAttention 内存优势的丧失。
- 剪枝后总 FLOPs 可用闭式函数（式 10）精确刻画，是组数 m 的确定性函数。

### 7. 优点

- **问题洞察深刻**：首次系统揭示 VLM 中存在 sink/dispersed/optimal 三种头部注意力模式，并定量证明均匀头平均的缺陷（图 2 的层间波动与头部间差距）。
- **方法设计优雅**：PAQ 分数基于信息论的不确定性系数，数学动机清晰，且能统一区分三种失败模式；无需训练、无需逐任务调参，唯一输入是 FLOPs 预算。
- **闭式可推导**：FLOPs 成本有解析表达式（式 10），可直接从预算反推组数，工程实用性高。
- **FlashAttention 兼容**：通过扩展 dual-flash 策略避免物化完整注意力矩阵，保持了内存效率。
- **实验严谨全面**：18 个基准、5 个架构、多种消融和鲁棒性验证，10 次重复实验报告标准差，统计显著性得到确认。
- **开源**：代码已公开。

### 8. 不足与局限

- **剪枝范围有限**：仅在 prefill 阶段操作，解码阶段的视觉 KV cache 未被触碰。论文虽提供了长序列下的增益分析（S∗ 约 6.5 万–21.7 万 token），但超出该长度后 FLOPs 节省趋于饱和。
- **PAQ 是代理指标**：基于交叉注意力统计而非因果验证。论文仅提供相关性证据（PAQ 与 IoU 的 Pearson 相关 0.67/0.71），缺乏反事实 token 干预的因果验证（作者在 Limitations 中坦诚承认）。
- **评估局限**：聚焦静态图像和短视频；流式/超长多模态场景中的头部对齐模式尚待研究。
- **单卡、单次运行**：主要结果在单张 RTX 3090 上报告（附录 F 补充了 10 次重复实验），但未报告多卡环境或生产级部署的吞吐数据。
- **部分基准上标准偏差未覆盖全部配置**：表 8 只报告了 80%/60%/40%/20% 四个保留率，且仅三个架构；更细粒度的 sweep 缺失。
- **潜在偏差**：PAQ 依赖文本查询的存在；对于无配对文本查询的场景（纯视觉任务）不适用。另外，论文承认使用了 AI 辅助写作工具进行语言润色。
