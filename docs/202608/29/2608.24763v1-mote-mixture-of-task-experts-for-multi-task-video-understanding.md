## 摘要
程序性视频语言模型必须从相同的视觉证据中解决异构任务，包括动作识别、预测和过程预测。密集Transformer解码器在所有任务间共享相同的前馈网络，这可能使任务行为纠缠在一起，并使受控的能力扩展变得困难。稀疏专家混合（MoE）解码器提供条件计算，但词元级的学习路由并不天然与任务级程序目标对齐。我们提出了MoTE（任务专家混合体），一种解码器架构，将大语言模型的前馈网络转换为任务特定专家，同时保持多模态主干网络共享。每个样本遵循一条样本级任务路由，因此活动任务专家的计算与存储的任务专家数量无关。我们将此设计实现为VideoLLM-MoTE，并使用显式任务路由在五个COIN基准上对其进行评估。五专家模型每个样本激活约20亿个LLM参数，比近期VideoLLM基线实现了更高的平均top-1准确率。在相同的专家拓扑下，它优于密集的全专家激活和学习的稀疏路由控制方法。这些结果表明，任务结构化路由为多任务视频语言学习提供了一种可解释且计算高效的解码器替代方案。

## Abstract
Procedural video-language models must solve heterogeneous tasks from the same visual evidence, including action recognition, forecasting, and procedure prediction. Dense transformer decoders share the same feed-forward networks across tasks, which can entangle task behavior and make controlled capability expansion difficult. Sparse Mixture-of-Experts (MoE) decoders provide conditional computation, but token-level learned routing is not naturally aligned with task-level procedural objectives. We propose MoTE (Mixture of Task Experts), a decoder architecture that converts large language model feed-forward networks into task-specific experts while keeping the multimodal backbone shared. Each example follows one sample-level task route, so active task-expert computation remains independent of the number of stored task experts. We instantiate this design as VideoLLM-MoTE and evaluate it on five COIN benchmarks using explicit task routes. The five-expert model activates ~2B LLM parameters per sample and achieves higher average top-1 accuracy than recent VideoLLM baselines. Under the same expert topology, it improves over dense all-expert activation and learned sparse-routing controls. These results show that task-structured routing provides an interpretable and compute-efficient decoder alternative for multi-task video-language learning.

# 论文深度总结：MoTE (Mixture of Task Experts for Multi-Task Video Understanding)

## 1. 核心问题与研究动机

- **背景**：程序性（Procedural）视频语言模型需要从同一段视觉证据中同时解决多种异构任务，包括动作识别（Step Recognition）、下一步预测（Next-Step Forecasting）、任务识别（Task Recognition）、过程预测（Procedure Forecasting）等。多任务指令微调虽有助泛化，但异构任务共享同一解码器参数会造成 **负迁移（negative transfer）** 和 **任务行为纠缠**。
- **核心矛盾**：
  - 密集 Transformer 解码器：所有任务共享相同的前馈网络（FFN），任务特化变换只能隐式编码，难以受控扩展。
  - 经典 Sparse MoE：token 级或 patch 级学习路由虽然可扩展容量，但路由粒度与“用户面对的任务边界”天然不对齐，缺乏可解释性。
- **核心问题**：能否设计一种解码器架构，在保持共享视觉-语言主干的同时，让任务级计算路径显式、可控、且计算量不随专家数量增长？

## 2. 方法论：MoTE 架构

- **总体思想**：将大语言模型每个解码器层中的 FFN 替换为 **1 个共享专家 + M 个任务专家**，每个样本按任务身份路由到唯一一个任务专家，实现“样本级任务路由”。
- **关键技术细节**：
  - **共享主干**：视觉编码器（SigLIP 2 ViT-L/16-384）、MLP 投影器、注意力路径、token 嵌入层完全共享。
  - **MoTE 解码器块**：给定任务路由 r，隐藏状态更新公式为：
    \[
    H_{l+1} = \tilde{H}_l + \lambda_{sh}F_{sh}^l(LN(\tilde{H}_l)) + \lambda_{task}F_r^l(LN(\tilde{H}_l))
    \]
    其中 \(\tilde{H}_l = H_l + GQA_l(LN(H_l))\)，\(F_{sh}\) 始终激活，\(F_r\) 按任务选择。
  - **专家初始化**：所有任务专家和共享专家均由预训练密集 FFN **复制初始化**（借鉴 Sparse Upcycling 原理），使共享路径和任务路径在训练中自然分岔。
  - **任务路由机制**：
    - 训练时：使用任务标签 t 直接作为路由（显式监督），无需学习门控或负载均衡损失。
    - 推理时：使用 **prompt 条件专家选择** —— 用冻结文本编码器（MiniLM-L6-v2）对 prompt 与各专家自然语言描述计算余弦相似度，取 top-1。
  - **模块化专家适配**：可动态添加新专家（仅新专家可训练，旧路由冻结）或移除不需要的专家，支持能力合规性撤回。
- **训练目标**：带两条监督信号的交叉熵损失——语言建模损失（预测回复 token）和流式沉默损失（预测 EOS 以保持安静）；离线 COIN 任务只保留语言建模损失。

## 6. 主要结论与发现

- **任务路由优于学习路由**：在相同专家拓扑下，MoTE（显式任务索引路由，62.9%）显著优于 dense 全激活（61.5%）、token 级学习路由（61.4%）和 sample 级无监督学习路由（62.1%），增益在过程导向任务（Proc.+ 提升 +2.7）上尤其突出。
- **计算高效**：激活约 2B 参数即可超过激活 8B 参数的 VideoLLM 基线，验证了“小激活参数 + 任务结构”的性价比优势。
- **专家模块性成立**：专家交换导致对应任务精度骤降而无关任务不变，证明路由专家确实编码了任务特化变换；冻结式专家添加保持旧任务性能不变，但联合训练精度更高（62.9% vs 61.0%），呈稳定性-塑性权衡。
- **跨域可迁移**：将 MoTE 转换应用于 GLM-OCR，新增 KIE 路由使 CORD Micro-F1 从 20.07% 提升至 95.79%，同时原始 OCR 性能在 OmniDocBench 上完全保留（94.62 分不变），验证了“不遗忘的模块化扩展”。

## 7. 优点与亮点

- **可解释性**：路由以任务身份为显式变量，专家语义由自然语言描述注册，解码路径完全可审计。
- **计算-容量解耦**：存储专家数量线性增长，但活跃计算保持恒定，支持任务集扩展而无需扩大推理成本。
- **模块化能力管理**：支持专家动态添加、移除、交换，为持续学习、遗忘、合规性能力撤回提供了结构化的架构基础。
- **数据采样策略**：设计了“分桶对齐采样”（bucket rank-aligned sampling），既保留任务规模偏差又避免小桶过度暴露，减少数据分布失衡风险。
- **跨域验证意识强**：将同一架构原则成功迁移到非视频（文档 KIE/OCR）任务，增强结论的普适性。

## 8. 不足与局限

- **路由选择器覆盖窄**：prompt 条件选择仅验证了预定义 5 个 COIN 意图的生成式 prompt 变体（100% F1），未覆盖模糊、重叠、组合式 prompt 请求，实际部署鲁棒性存疑。
- **冻结式扩展的塑性代价**：增量专家添加冻结旧路由，虽保旧能力但峰值多任务精度低于联合训练（61.0% vs 62.9%），在任务强相关的场景下可能不足。
- **模型规模受限**：主实验仅用 1B 解码器，未验证 MoTE 在 7B/8B 或更大模型上的行为，可能与更大模型的涌现式任务泛化存在差异。
- **跨数据扩展略有性能损失**：Ego4D+COIN 单模型中 Ego4D PPL/TimeDiff 略差于单任务训练模型，说明任务路由不能完全消除跨域干扰。
- **比较公平性存疑**：与公开 7B/8B 基线比较存在规模、视觉编码器、训练方案多重差异，作者已承认并作保守处理，但严格的“等规模公平对比”仍需补充。
