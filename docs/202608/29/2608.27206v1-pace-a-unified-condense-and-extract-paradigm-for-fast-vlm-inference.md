## 摘要
视觉-语言模型（VLM）展示了卓越的视觉推理能力，然而其推理成本随着视觉令牌的激增而迅速上升。现有的视觉令牌剪枝方法存在两个根本性局限。首先，大多数方法仅在视觉编码器之后操作，导致视觉编码阶段的大量延迟未被优化。其次，在严格的令牌预算下，这些方法往往无法同时保留整体视觉上下文和细粒度细节，导致性能下降。为解决这些瓶颈，我们提出了PACE（像素自适应压缩与提取），一种无需训练的推理框架，通过统一的压缩与提取范式加速视觉编码器和大语言模型（LLM）。在压缩阶段，自适应像素压缩器（APC）在编码前评估视觉信息密度，自适应地下采样冗余输入，减少编码器计算量，同时保留全局上下文和关键视觉线索。在提取阶段，动态双注意力提取器（DDAE）通过融合来自编码器的内部视觉信号和来自LLM的语义信号，选择性保留视觉令牌，确保任务关键细节不丢失。将PACE集成到Qwen2.5-VL-7B中，模型在仅使用10%视觉令牌的情况下保留了93.8%的原始性能，同时实现了3.1倍的首令牌时间（TTFT）加速。我们的代码可在https://github.com/jjL357/PACE获取。

## Abstract
Vision-Language Models (VLMs) demonstrate exceptional visual reasoning capabilities, yet their inference costs escalate rapidly with the proliferation of visual tokens. Existing visual token pruning methods exhibit two fundamental limitations. First, most approaches operate exclusively post-vision encoder, leaving the substantial latency of the visual encoding phase unoptimized. Second, under strict token budgets, these methods often fail to jointly preserve holistic visual contexts and fine-grained details, leading to performance degradation. To address these bottlenecks, we propose PACE (Pixel-Adaptive Condense and Extract), a training-free inference framework that accelerates both the vision encoder and the Large Language Model (LLM) via a unified Condense-and-Extract paradigm. During the Condense stage, an Adaptive Pixel Compressor (APC) evaluates visual information density prior to encoding, adaptively downsampling redundant inputs, curtailing encoder computation while preserving global context and essential visual cues. In the Extract stage, a Dynamic Dual-Attention Extractor (DDAE) selectively retains visual tokens via a fusion of internal visual signals from the encoder and semantic signals from the LLM, safeguarding task-critical details. By integrating PACE into Qwen2.5-VL-7B, the model retains 93.8% of its original performance while utilizing only 10% of the visual tokens, yielding a 3.1x speedup in time to first token (TTFT). Our code is available at https://github.com/jjL357/PACE.

为此，论文提出 **PACE（Pixel-Adaptive Condense and Extract）**，一种无需训练（training-free）的推理加速框架，统一实现“压缩（Condense）”和“提取（Extract）”两大功能，同时降低视觉编码器和 LLM 的计算成本，并在低 token 预算下保持较高的整体与细粒度视觉理解性能。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

PACE 由两个主要阶段组成：

### 2.1 Condense 阶段：自适应像素压缩器（APC）

**目标**：在视觉编码器之前减少输入像素数量，压缩冗余区域的同时保留关键视觉线索。

**核心步骤**：

- **浅层特征预览（Shallow Feature Preview）**：使用 ViT 的第一个 block（K=1）计算轻量特征预览，对每个 patch token 做 L2 归一化，得到 token 集合 \(T_v = \{T_i^v\}_{i=1}^N \in \mathbb{R}^{N \times D}\)。相比 RGB 统计、熵、边缘密度、Laplacian 等手工特征，该语义预览更可靠（附录 B.2 消融验证）。
- **全局信息密度（\(\rho_g\)）**：计算所有视觉 token 的平均两两余弦相似度 \(\phi\)，然后定义：
  \[
  \rho_g = 1.0 - \phi
  \]
  \(\phi\) 越大表示图像冗余越高（如大面积均匀背景），全局信息密度越低。
- **局部细节对比度（\(\rho_d\)）**：计算所有 token 的平均向量作为全局背景基线 \(\hat{c}\)，然后计算每个 token 到该基线的欧氏距离 \(d_i\)。取距离最大的 top 10% token 的平均距离 \(\bar{d}_{top}\)，并线性缩放为局部保留分数：
  \[
  \rho_d = \min\left(\frac{\bar{d}_{top}}{\gamma}, 1.0\right)
  \]
  其中 \(\gamma\) 为尺度调节因子。高 \(\rho_d\) 表示存在明显的局部细节（如小文字、细线），需要更高的分辨率来保留。
- **自适应压缩**：综合全局与局部得分：
  \[
  \rho = \alpha \rho_g + (1-\alpha)\rho_d
  \]
  其中 \(\alpha\) 为平衡权重（默认 0.6）。最终保留比例 \(r = \rho\)，图像按比例缩放（宽度和高度均乘 \(\sqrt{r}\)）。若系统内存或 token 预算有硬性上限，则强制调整为不超过该上限的分辨率。

### 2.2 Extract 阶段：动态双注意力提取器（DDAE）

**目标**：在视觉编码后、LLM Prefill 前，筛选出既语义相关又信息丰富的视觉 token。

**核心步骤**：

- **语义注意力图（\(S_{llm}\)）**：从指定 LLM 层（提取深度 \(L_{ext}\)，默认第 2 层）提取交叉注意力分数，进行 min-max 归一化到 [0,1]。
- **视觉密度图（\(S_{vis}\)）**：从 ViT 末端层提取自注意力图，同样归一化到 [0,1]。
- **置信度加权融合**：使用归一化注意力分布的标准差 \(\sigma_{llm}\) 和 \(\sigma_{vis}\) 作为无监督置信度指标，通过 softmax 动态分配融合权重：
  \[
  \alpha_{weight}, \beta_{weight} = \text{Softmax}\left(\frac{[\sigma_{llm}, \sigma_{vis}]}{\tau}\right)
  \]
  其中 \(\tau\) 为温度参数（默认 0.5）。最终 saliency 分数：
  \[
  S_{final} = \alpha_{weight} S_{llm} + \beta_{weight} S_{vis}
  \]
- **Top-K 选择**：按 \(S_{final}\) 对视觉 token 排序，保留 Top-K 作为 LLM 的输入上下文。

**整体流程**：先由 APC 在编码前降低输入分辨率，减少 ViT 计算量；再由 DDAE 在编码后稀疏化视觉 token，减少 LLM Prefill 计算量。两者协同构成统一的 Condense-and-Extract 范式。

## 6. 论文的主要结论与发现

- **PACE 在固定分辨率、10% token 预算下**，在 Qwen2.5-VL-7B 上保留 93.8% 的原始性能，显著优于所有基线（平均性能超过 VisionZip 12.7 个百分点，超过 FastV 13.9 个百分点）。
- **在细节敏感任务（OCRBench、DocVQA、ChartQA）上**，PACE 相比基线有显著优势，说明 APC 的编码前压缩和 DDAE 的双注意力提取能够有效保留细粒度视觉证据。
- **效率提升**：PACE 将视觉编码器延迟从 148.84 ms 降至 49.47 ms（3.01× 加速），LLM Prefill 从 217.05 ms 降至 32.69 ms（6.64× 加速），TTFT 从 365.89 ms 降至 116.79 ms（3.13× 加速）。即使考虑 APC 开销，整体 TTFT 依然大幅降低。
- **自适应分辨率优于静态分辨率**：APC 的动态像素分配在跨领域任务上取得更平衡的性能，而静态缩放容易过拟合特定领域。
- **DDAE 动态融合优于单一注意力或固定融合**：单纯依赖 LLM 注意力会丢失关键视觉上下文，单纯依赖 ViT 注意力则任务对齐不足；动态置信度加权融合最稳健。
- **APC 可与现有 post-encoder 剪枝方法正交组合**，提升 VisionZip 和 MMTok 在细节敏感任务上的表现，证明其通用性。

## 7. 优点

- **问题洞察深刻**：明确指出 VLM 推理存在“视觉编码 + LLM Prefill”双瓶颈，突破了以往只优化 LLM 侧的局限。
- **方法设计巧妙**：Condense-and-Extract 范式两阶段协同，编码前压缩降低了 ViT 计算量，编码后提取降低了 LLM 计算量；且完全无需训练，即插即用。
- **自适应性强**：APC 根据全局冗余和局部细节动态调整输入分辨率，优于固定缩放；DDAE 根据注意力分布标准差动态融合视觉与语义信息，比固定权重或单一注意力源更稳健。
- **实验全面**：覆盖 9 个基准、2 个 Qwen 模型规模、1 个跨架构模型、两种分辨率设置、多个 token 预算，并包含丰富的消融研究与效率分析。
- **正交兼容**：APC 可以嵌入到现有剪枝方法中进一步提升性能，扩展了其实用价值。
- **性能显著**：在极低 token 预算下（5%）仍能保持较高水平，远超基线，且 TTFT 加速明显。

## 8. 不足与局限

- **编码器加速依赖架构**：APC 只在输入分辨率降低确实减少 ViT 输入 token 数量时才有收益。对于固定网格（fixed-grid）的 VLM，APC 无法带来编码器加速，DDAE 只能减少 LLM Prefill 成本。
- **一次性、查询无关的压缩**：APC 是 query-agnostic 的，无法根据具体问题动态恢复被降采样消除的微小细节（如极小字符、图表标签、细线、低对比度物体）。一旦信息在编码前丢失，DDAE 无法重建。
- **预览开销因架构而异**：浅层特征预览和重采样的开销与模型结构和分辨率相关，论文报告的 Qwen2.5-VL 速度提升不一定能直接迁移到其他 backbone 上。
- **DocVQA 仍有明显性能差距**：在 10% token 预算下，PACE 的 DocVQA 得分（69.55）比 Vanilla（94.74）低了约 25 个百分点，说明微观字符和版面关系的重建仍具有挑战性。
- **超参数敏感性未全面评估**：α 的敏感性仅在 MMStar 上分析，其他任务上的全局表现未逐一展示；温度 τ 和 γ 的敏感性分析也未在正文给出。
- **安全性/应用限制**：高精度、高风险应用可能需要更高的保留预算、更保守的压缩或更小的 α 来强调局部细节，否则存在关键证据丢失风险。
