## 摘要

## Abstract
Joint-Embedding Predictive Architectures (JEPAs) for world modeling typically employ fixed-size Vision Transformer encoders that are over-provisioned for simple tasks and under-provisioned for complex ones, with significant redundancy across attention heads. We propose Successive Capacity Growth (SCG), a method that starts from a minimal encoder (1 head, 2 layers, 283K parameters) and grows incrementally in width (adding attention heads for low-level semantic capacity) or depth (adding transformer blocks for higher-order semantic abstraction), driven by a task-agnostic test-and-verify mechanism that exploits function-preserving expansion to safely trial architectural changes and roll back if they do not improve prediction loss. The Sketched Isotropic Gaussian Regularizer (SIGReg) ensures that all learned semantic dimensions remain statistically independent and aligned with the predictive objective, preventing collapse even as the architecture grows. On a 60-dimensional multi-object dynamics task, SCG naturally triggers depth expansion, improving prediction loss by 20.3% over the fixed small baseline with 56 times greater parameter efficiency than scaling to the fixed large model; on a 2D navigation task, a single width expansion yields even an 23% improvement over the fixed large model. Across all three tested environments of increasing complexity, the adaptive encoder matches or exceeds the fixed small baseline, with zero false-positive expansions and bit-exact function preservation (ratio = 1.0, absolute difference = 0.0). The take-away is that JEPA world model encoders need not be pre-allocated at maximum capacity - they can grow successively as the task demands, achieving significant compute and data efficiency while maintaining representation quality.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：JEPA（联合嵌入预测架构）世界模型是模型化强化学习的重要范式。最近提出的 LeWorldModel (LeWM) 展示了仅用两项损失（下一嵌入预测损失 + SIGReg 正则化）即可从原始像素端到端稳定训练 JEPA 模型，且推理速度显著优于基于基础模型的世界模型。
- **核心问题**：LeWM 使用固定大小的 ViT-Tiny 编码器（12 层、3 头、隐藏维度 192、约 5M 参数），存在两类结构性缺陷：
  - **简单任务上过度配置**：三个注意力头的注意力图两两余弦相似度≈1e-4，近乎完全冗余；第 3–12 层残差贡献递减（残差比从 0.9 降至 0.15），大量深度层执行近乎恒等变换。一个 2D 导航任务与一个 60 维状态的任务共用同一个 5M 参数编码器，导致计算浪费。
  - **复杂任务上可能配置不足**：固定小编码器（仅 28.3 万参数）在 60 维多目标任务上表现欠佳。
- **根本症结**：编码器容量是先验选定的，而非由任务本身决定。作者提出替代范式——**逐级容量增长（SCG）**——编码器从最小的规模出发，仅在任务需要时逐步增长。
- **主要差距（现有工作局限）**：
  - 渐进式增长（Progressive Growing）用于 GAN，但使用预定义调度且不保持函数。
  - bert2BERT 采用函数保持扩展但依赖预定义增长调度。
  - Net2Net 提供了宽度/深度扩展的理论基础，但缺乏何时扩展的触发策略。
  - LiGO 学习最优增长模式，但需要单独的成长阶段。
  - 递归 ViT 做动态深度/宽度调整，但属于调整已有架构而非函数保持式扩展。
  - **没有现有工作**同时具备：(1) 函数保持式架构扩展 + (2) 任务无关、无需调参的触发机制 + (3) 应用于 JEPA 世界模型 + (4) SIGReg 保证增长后语义维度独立对齐。

### 2. 方法论：核心思想、关键技术细节

#### 2.1 核心思想

SCG 从最小架构（1 头、2 层、d_model=64，28.3 万参数）出发，在训练过程中监控预测损失，检测到平台期时尝试架构扩展：

- **宽度扩展**：增加注意力头（d_model 增加 64），增加低层语义容量（更多独立表示维度）。
- **深度扩展**：增加一个恒等初始化的 Transformer 块，增加高阶语义抽象能力（层次化变换）。

扩展通过**测试-验证机制**驱动：每次扩展先"试运行"，若预测损失未改善则回滚，模型恢复扩展前状态。

#### 2.2 关键公式与算法流程

**训练目标**（沿用 LeWM，含 4 帧 + 动作块，5-skip）：

```
L_total = (1/3) Σ_{i=0}^{2} MSE(ẑ_{i+1}, z_{i+1})  ← L_pred
        + λ · L_SIGReg(Z)，其中 λ = 0.1
```

关键点：不使用 stop-gradient，梯度同时流经预测和目标两侧，靠 SIGReg 防止坍塌。

**SCG 算法流程**（每个有效 epoch 结束时）：
1. 若预测损失 `L_pred` 出现平台期（最近 2 个 epoch 的中位数相比前 2 个 epoch 改善 ≤2%）：
   - 保存模型和优化器状态（深拷贝），记为 `M_saved, ω_saved`
   - **先尝试宽度扩展**：函数保持地加一个头 → 训练 2 个 epoch → 检查损失
     - 若 `L_post < 0.98 × L_pre`（改善 >2%），保留扩展，设置 2 个 epoch 冷却期
     - 否则回滚到 `M_saved, ω_saved`
   - **再尝试深度扩展**：函数保持地加一个恒等块 → 训练 2 个 epoch → 同样判断
     - 若改善则保留；否则回滚，并标记为"已收敛"，停止所有后续扩展尝试

#### 2.3 函数保持的扩展设计

**宽度扩展**（Net2Net 式复制）：
- 新头的 QKV 权重 = 头 0 的 QKV 权重复制
- **新头的输出投影初始化为零** → 新头初始不贡献任何输出
- 补丁嵌入、CLS token、位置嵌入：拼接前 64 维的副本
- MLP：复制前 64 维作为新输入/输出维度
- 投影器：输入权重重零填充（新维度初始被忽略）
- 形式化：`W' = [[W, 0], [C_w, 0]]` 保证 `f_{W'}(x) = f_W(x)`

**深度扩展**：
- 新 Transformer 块作为恒等映射初始化：输出投影权重=0、偏置=0；MLP W2 权重=0、偏置=0；LayerNorm 权重=1、偏置=0
- 由函数复合的结合律，块输出 `g(y) = y`，插入计算图不改变全局映射

这保证了**位精确的函数保持**（bit-exact function preservation），扩展不会破坏损失景观。

#### 2.4 瓶颈分解理论

预测损失平台期可源于两类容量瓶颈：
- **表征瓶颈（representational bottleneck）**：任务状态空间的内在维度超过编码器表征维度 d_model → 需宽度扩展
- **计算瓶颈（computational bottleneck）**：任务需要建模已可分因子间的高阶非线性交互，浅层编码器缺乏组合深度 → 需深度扩展

测试-验证机制无需显式诊断瓶颈类型，直接顺序检验两种假设。

#### 2.5 优化轨迹安全性

函数保持保证了扩展后立即损失不变；深拷贝保存完整优化器状态（含 Adam 动量），失败回滚后优化轨迹严格连续。

### 6. 主要结论与发现

1. **任务复杂度驱动的增长确实发生**：
   - Two-Room（2D）：seed 42 触发单次宽度扩展（d_model 64→128），预测损失较 Fixed Small 改善 49%（0.000279 vs. 0.000547，均值），较 Fixed Large 改善约 23%
   - Push-T（5D）：所有种子正确收敛，无误扩展（5D 状态适合 d_model=64）
   - 30-Object（60D）：seeds 3072 和 123 触发深度扩展（2→3 层），平均改善 20.3%；seed 42 因未到达平台期未扩展

2. **位精确函数保持**：宽度和深度扩展的 fp_ratio=1.0，绝对差异=0.0，所有内部表示和最终损失均无差异。扩展后新容量立即可用。

3. **参数效率**：30-Object 任务上，SCG 用 5 万额外参数实现 0.0017 的损失下降，而 Fixed Large 需 540 万额外参数实现 0.0033 的下降——SCG 参数效率约为 Fixed Large 的 **56 倍**。

4. **过度配置惩罚（over-provisioning penalty）**：Two-Room 任务上 SCG（seed 42）超越了 Fixed Large（0.000176 vs. 0.000362），尽管参数仅为后者的 11%。容量远超任务复杂度时，冗余参数捕获噪声而非信号，损害泛化。

5. **预测损失（非总损失）是可靠触发信号**：用总损失（含 SIGReg）检测平台期会产生假阳性扩展；仅用 L_pred 时 0/9 次运行无误报。

6. **有效秩不可靠作容量信号**：2D 和 60D 任务的有效秩均≈3，神经网络压缩表征导致秩与任务复杂度无关。

### 7. 方法与实验设计的优点

1. **函数保持的精确性**：零初始化输出投影 + QKV 复制的宽度扩展设计巧妙；恒等初始化的深度扩展通过函数复合的结合律保证全局不变。文中给出位精确验证（6 次运行 × 2 类型扩展均零差异），排除实现误差。

2. **任务无关的触发机制**：2% 阈值用于两个方向（平台期检测和验证改进），无需按数据集调参；测试 epoch 不计入有效 epoch 预算，保证公平性；冷却期让优化器适应新参数。

3. **优化轨迹安全性**：深拷贝完整优化器状态 + 回滚机制，失败的试扩展"如同从未发生"，消除了动态架构变化常见的训练不稳定风险。

4. **SIGReg 的巧妙结合**：与 LeWM 的稳定训练框架结合，SIGReg 确保增长后的语义维度保持统计独立，从根本防止冗余复制问题。

5. **消融实验针对性**：比较 L_pred vs. L_total 作为触发信号、有效秩 vs. 损失信号，直接服务于设计决策验证。

6. **诚实报告种子差异**：表 3 明确展示三个种子的不同扩展行为，而非仅报平均改善，增加了结果可信度。尤其是 30-Object seed 42 未触发扩展的情况被如实记录。

7. **过度配置惩罚的实证**：SCG 超越 Fixed Large 的发现挑战了"模型越大越好"的常规，是一个具有广泛意义的观察。

### 8. 不足与局限性

1. **合成环境局限**：所有实验均为合成环境（2D 网格、T 型块推动、多物体动力学），缺乏真实世界数据（真实视频、机器人传感器数据）的验证。图像视觉复杂度远低于真实场景。

2. **缺少规划指标**：LeWM 的下游应用是 CEM 规划。论文仅评估预测损失，未评估规划成功率——后者才是世界模型的终极指标。预测损失的改善并不必然转化为规划性能的改善。

3. **单 GPU / 小规模验证**：
   - 最大模型 5.7M 参数，未测试 ViT-Base（86M）规模。
   - 单 GPU（A6000）环境下，未验证多 GPU 训练或更大批量下的扩展行为。

4. **统计强度有限**：每 (task, seed) 仅 3 个配置各 1 次运行，3 个种子共 3 次重复。seed 42 在 30-Object 上未触发扩展（1/3 种子），使"SCG 在 60D 任务上倾向深度扩展"的结论仅有 2/3 的种子支持。

5. **未与强基线对比**：未与 LiGO、递归 ViT、bert2BERT 等既有自适应/渐进式方法做直接对比；未报告 SCG 与直接从头训练一个同等大小架构（而非扩展而来）的性能差异。

6. **训练时长与计算成本不透明**：未报告扩展尝试（测试 epoch）消耗的额外计算成本，也未给出总 GPU 小时数。测试窗口最多为每个平台期增加 4 个额外 epoch，但文中未量化实际增长比例。

7. **未讨论数据规模效应**：固定 200 episodes 的小数据规模下，SCG 的扩展行为可能在大数据下不同。SCG 在更大数据量下的扩展触发频率和规模是否合理，未经验证。

8. **触发机制的敏感性未知**：2% 阈值、2 epoch 测试窗口、2 epoch 冷却期这些超参数虽然被表述为"非超参数"，但未做敏感性分析；不同值可能改变扩展决策。

9. **缺少推理效率评估**：虽然 SCG 在训练上更高效，但未报告推理时的 FLOPs 或延迟对比。自适应模型在训练后的大小差异如何影响部署效率，未量化。

10. **版本状态**：论文为 arXiv 预印本（v1，2026 年 8 月），未经同行评审，结论需谨慎看待。参考文献 [5] 的 URL 有格式破损（"closingtheperformancegaptothefixedlargebaselinewithupto56$\times$greaterparameterefficiency"），显示编辑不完整。

### 总体评价

SCG 提出一个清晰、可实现的自适应编码器架构增长方案，在合成环境上证明了"容量随任务需求逐级增长"范式的可行性。核心贡献——函数保持的宽度

深度扩展方法（零初始化、函数复合结合律保证恒等）与 LeWM/JEPA 训练框架无缝衔接，配合 SIGReg 的语义维度独立性约束，形成了一套从触发、验证、回滚到容量增长的完整闭环。该方法在简单任务上主动避免过度配置，在复杂任务上以远超固定大模型的参数效率逼近其性能，实证了"架构容量应随任务复杂度演化"这一范式的价值。尽管存在合成环境局限、统计强度有限、缺乏规划指标等不足，论文的触发机制设计（预测损失平台期 + 测试-验证回滚）和函数保持的工程实现具有清晰的可迁移性，为自适应世界模型和动态架构搜索提供了扎实的基线参考。

### 9. 潜在应用与扩展方向

1. **大规模 JEPA 世界模型的自动化设计**：SCG 可嵌入模型化 RL 训练管线，替代人工试错确定编码器结构；在机器人操作、自动驾驶等需要从高维观测学习状态表征的场景中，模型可随数据积累自然增长，无需重新从头训练。

2. **异构任务共享骨架的持续学习**：在同一编码器上依序学习多个任务时，SCG 可在新任务进入平台期时触发深度/宽度扩展，作为灾难性遗忘的缓解手段——扩展出的新容量吸收新任务知识，旧容量维持旧任务功能（函数保持保证扩展瞬间不破坏旧能力）。

3. **资源受限设备上的渐进部署**：从最小模型开始训练的 SCG，在训练早期即可部署到边缘设备；随着云端训练不断扩展，设备端可通过增量权重更新同步升级，而非整体替换。

4. **与剪枝/蒸馏结合的双向容量管理**：SCG 做自底向上的增长，与自顶向下的剪枝结合，可形成"先增长、后压缩"的动态容量生命周期管理，进一步逼近任务最优参数复杂度。

5. **多环境/多任务的通用触发机制研究**：当前的损失平台期触发与任务无关，可进一步研究在多任务联合训练中如何区分"某任务需要容量"vs."全局需要容量"，或将 SCG 扩展至 MoE 风格的按需稀疏激活。

### 10. 对相关领域的启示

- **对 JEPA 世界模型社区**：论文表明 LeWM 使用的固定 ViT-Tiny 编码器在简单视觉任务上严重冗余；未来 JEPA 工作应报告编码器有效秩、注意力头冗余度等容量利用率指标，而非仅报告参数量与损失。

- **对自适应计算（Adaptive Computation）社区**：SCG 将"何时扩展"从预定义调度或人工干预中解放出来，用损失平台期作为任务复杂度的隐式信号，为 Net2Net 类方法补齐了缺失的触发机制环节。

- **对强化学习**：在样本效率敏感的场景中，SCG 用极少的额外参数（数万而非数百万）逼近性能上界，凸显了"容量分配效率"作为 RL 训练效率的一个被忽视维度。

- **对表示学习理论**：有效秩与任务复杂度解耦的发现（2D 与 60D 任务有效秩均≈3）提示：表征的线性维度不能反映任务的内在非线性结构复杂度——瓶颈更多体现在深度（组合容量）而非宽度（线性维度），这对架构选择的经验法则（"先宽后深"还是"先深后宽"）具有指导意义。

### 11. 未来工作建议（基于论文自身缺口）

1. **即时优先级**：在 30-Object 任务上增加更多种子（≥10）验证深度扩展倾向性；补充规划成功率（CEM 规划下）对比，将预测损失改善映射到下游决策性能。

2. **短期可做**：
   - 在真实视频数据集（如 DMC、Atari 像素、机器人操作视频）上复现 SCG 流程，验证合成环境结论的迁移性；
   - 对 2%/2-epoch 触发超参做网格敏感性分析，绘制扩展决策边界图；
   - 与 LiGO、递归 ViT 在相同环境和预算下做直接基准对比。

3. **中期方向**：
   - 将 SCG 扩展至其他模态（语言、音频）的 JEPA 模型；
   - 在更大的初始架构（如 ViT-Small 起步）和更大的最终容量上限（如 ViT-Base）下验证 SCG 的可扩展性；
   - 将扩展机制与 curriculum learning 结合，让任务难度上升时自动触发容量增长。

4. **长期愿景**：将 SCG 发展为一个"自生长世界模型"框架——编码器、世界模型头、规划器全部按需自适应增长，最终形成与任务复杂度匹配的紧凑 agent 架构，从根本上消除人工选择模型容量的负担。

---

**一句话总结**：本文提出逐级容量增长（SCG）范式，以预测损失平台期为任务无关触发信号、函数保持扩展+测试回滚为安全机制，在 JEPA 世界模型的合成环境上实证了"以小始、按需长"的架构自适应策略，在简单任务上避免过度配置、在复杂任务上以 56× 参数效率逼近强基线，为动态架构与模型化 RL 的交汇提供了开创性基线。
