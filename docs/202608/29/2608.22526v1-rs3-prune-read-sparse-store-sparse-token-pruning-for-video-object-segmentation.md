## 摘要
我们提出了RS$^3$-Prune，一种无需训练的令牌剪枝方案，它以一组推理时钩子（hooks）的形式直接应用于现有视频对象分割（VOS）网络之上。现代VOS模型已收敛到一种常见且昂贵的设计：图像编码器为每一帧生成密集的令牌网格，而记忆库（memory bank）则跨所有先前帧累积这些令牌，以调节未来的预测。随着视频变长，由此产生的令牌预算同时控制着每帧延迟和峰值GPU内存。因此，这些模型在长视频或内存受限加速器上的实时部署等使用场景中会遇到瓶颈。在这项工作中，我们认为在记忆库VOS中压缩的正确轴正是令牌预算本身。RS$^3$-Prune在任意记忆库VOS流水线中两个精确的位置处操作：在图像编码器与记忆注意力读取（memory-attention readout）之间的边界处，我们将参与跨帧注意力的查询限制为仅一个小的、基于几何信息的子集；在记忆编码器与记忆库之间的边界处，我们仅允许那些位于对象空间范围内的令牌进入记忆库。在各种既有基准测试上，RS$^3$-Prune相比未修改的VOS网络，可提供高达38.8%的FPS加速，并减少13.1%的峰值内存使用，同时保持有竞争力的$\mathcal{J}$&$\mathcal{F}$分数。

## Abstract
We introduce RS$^3$-Prune, a training-free token-pruning recipe that instantiates as a small set of inference time hooks atop existing video object segmentation (VOS) networks. Modern VOS models have converged on a common, expensive design: an image encoder produces a dense token grid for every frame, and a memory bank accumulates these tokens across all previously processed frames to condition future predictions. As a video grows longer, the resulting token budget governs both per-frame latency and peak GPU memory. Hence these models break on use cases such as --- long-form video or real-time deployment on memory-bounded accelerators. In this work we argue that the right axis along which to compress memory-bank VOS is the token budget itself. RS$^3$-Prune operates in two precise locations within an arbitrary memory-bank VOS pipeline: at the boundary between the image encoder and the memory-attention readout, where we restrict the queries that participate in the cross-frame attention to only a small, geometrically informed subset; and at the boundary between the memory encoder and the memory bank, where we restrict which tokens are ever permitted to enter the bank to those that lie within the object's spatial extent. Over various established benchmarks, RS$^3$-Prune delivers up to $38.8\%$ FPS speedup and reduces $13.1\%$ peak memory usage, while preserving a competitive $\mathcal{J}$&$\mathcal{F}$ compared to the unmodified VOS networks.

- **核心瓶颈**：现代记忆库式 VOS 模型具有共同的结构性设计——图像编码器为每帧产生密集令牌网格，记忆编码器将每帧的特征写入不断增长的记忆库，跨帧注意力则读取该记忆库。这一设计导致**令牌预算随视频长度线性增长**，同时推高每帧延迟和峰值 GPU 内存，使得长视频推理和实时部署成为难题。
- **核心论点**：记忆库 VOS 的真正部署天花板不是算法能力差距，而是**令牌预算本身的无界增长**。因此，正确的压缩轴应当是令牌预算，而非网络架构或算法。
- **整体含义**：论文提出一种**无需训练**的通用令牌剪枝方案，可在不改变任何已发布权重的前提下，将令牌预算从"架构常数"转变为"可调旋钮"，为 VOS 系统在长视频和资源受限场景下的部署开辟了路径。

## 2. 论文提出的方法论

### 2.1 核心思想

RS³-Prune 在任意记忆库 VOS 流水线的**两个结构性位置**插入剪枝算子：

- **读侧剪枝（Read-side Prune，速度杠杆）**：在图像编码器与记忆注意力之间，限制当前帧中参与跨帧注意力的查询令牌，仅保留几何先验内的高视觉能量令牌。
- **写侧剪枝（Write-side Prune，内存杠杆）**：在记忆编码器与记忆库之间，仅允许位于对象空间范围内的令牌进入记忆库，从源头控制记忆库增长。

### 2.2 关键技术细节

**（1）读侧剪枝**

- **空间先验的建立**：利用第 0 帧的种子掩码（半监督协议）或文本提示（SAM2 协议）生成每对象紧致边界框，下采样到编码器令牌网格后膨胀 r_s 个格点，取并集作为空间先验 P⁽ᵗ⁾。
- **时间传播**：从第 1 帧起，用模型自身上一帧的预测掩码重建先验，无需额外监督。
- **视觉能量筛选**：在空间先验内部，按令牌 ℓ2 范数排名，仅保留 top-ρ·mn 个令牌作为查询集 Kᵣ。Cauchy–Schwarz 不等式（式 3）提供了理论依据：令牌对注意力读出的贡献受其范数上界约束，高范数令牌对应纹理丰富的对象区域。
- **消失恢复机制**：对连续丢失的对象（预测掩码为空），维护"连续消失帧计数器"Δ_o，按式 5 以逐渐增大的膨胀半径（上限为 r_s+c）搜索缓存的历史边界框，防止对象重新出现时先验为空。
- **稀疏注意力执行**：通过 index-gather 将查询收集到保留位置，执行注意力后 scatter 回原始网格（零填充），保持与密集流水线完全相同的张量形状。
- **RoPE 修正**：对旋转位置编码的频率表执行与查询同步的 index-gather，确保稀疏子集上的位置编码正确（式 7）。

**（2）写侧剪枝**

- 对每个对象取其首次出现帧 τ_o 的掩码，下采样到编码器网格并膨胀 D_w 格点，取并集作为写侧保留集 K_w（式 8）。
- **K_w 仅计算一次并全程固定**，保证记忆库的合并/淘汰逻辑（假设恒定每帧步长）无需修改即可正常工作。
- 当 D_w ≥ r_s + c 时，读侧先验 P⁽ᵗ⁾ ⊆ K_w，保证读侧永远不会查询未被写入的位置，读写两侧互不冲突。

**（3）形态学闭运算**

- 对每个对象的预测二值掩码应用 9×9 方形结构元素的形态学闭运算，填补稀疏读出在对象内部造成的盐椒状空洞。

**（4）算法流程**（Algorithm 1）

第 0 帧：从种子掩码建立边界框、空间先验 P⁽⁰⁾、写侧保留集 K_w，并初始化记忆库。每帧 t ≥ 1：编码 → 逐对象更新先验（正常/消失恢复）→ 能量排名选 top-ρ 查询 → 稀疏记忆注意力 → 解码 + 形态学闭运算 → 更新对象状态（边界框/消失计数器）→ 稀疏写入记忆库。

## 6. 论文的主要结论与发现

1. **效率显著提升**：在全部 5 个模型、5 个数据集上，平均实现 **38.8% FPS 加速**和 **13.1% 峰值内存降低**，且无需重新训练或修改任何已发布权重。
2. **架构级正增益**：分架构看，STM +58% FPS/−32% VRAM，XMem +26%/−16%，Cutie +60%/−7%，SAM2 +28%/−4%，SAM3.1 +22%/−6%，收益均为正。
3. **读侧=速度杠杆，写侧=内存杠杆**：消融实验（表 3）清楚表明两个剪枝作用于不同资源且收益可叠加。
4. **剪枝有时反而提升精度**：在 SA-V、YouTube-VOS、MOSE 上，SAM2 的 J&F 不降反升，原因在于剔除背景上下文相当于一种"去噪"操作。
5. **现有图像域令牌剪枝方法不适用于 VOS**：SparseViT、DynamicViT、VLTP 因缺乏视频/对象先验，会保留背景而丢弃前景令牌，导致 J&F 大幅下降（如表 2 所示，部分方法 J&F 跌至 0.04–0.35）。

## 7. 优点

- **无需训练、即插即用**：以推理时钩子形式作用于冻结检查点，无新参数、无微调、无训练开销，部署成本极低。
- **定位精准、理论有据**：精准定位记忆库 VOS 的两个结构性瓶颈位置，并以 Cauchy–Schwarz 不等式（式 3）为几何先验提供理论支撑，论证充分。
- **双杠杆设计优雅**：读侧管速度、写侧管内存，分工明确、收益可叠加，提供了清晰的"心理模型"。
- **跨架构可移植性强**：适用于任何暴露两个编码器边界的记忆库 VOS 网络，涵盖专用模型（STM、XMem、Cutie）和基础模型（SAM2、SAM3.1）。
- **工程细节完备**：RoPE 位置编码修正（式 7）保证 ρ→1 时数值等价于密集注意力；消失恢复机制和 K_w ⊆ P⁽ᵗ⁾ 保证读写一致；形态学闭运算处理稀疏读出的空洞。
- **实验设计较客观**：在同一检查点上公平对比，不引入任何人机交互提示（VOS 中常见的隐性优势来源），并明确"绿色数字=提升"的标记方式，透明度高。

## 8. 不足与局限

- **写侧保留集缺乏适应性**：K_w 在种子帧固定后不再变化，若对象运动远超膨胀足迹，则出现过覆盖（损失 FPS）或欠覆盖（损失 J&F）的两难。论文承认在 LVOS-v2 长视频上，STM 和 SAM2 的 J&F 出现较大下降（如 STM 从 0.360 降至 0.250），说明该方法在极端长视频情景下仍有失效风险。
- **严重依赖先验质量**：读侧先验从上一帧预测传播，一旦发生灾难性预测丢失，虽然消失恢复机制能兜底，但恢复窗口内的精度仍可能损失。
- **超参数较多且未自适应**：ρ、r_s、c、D_w、闭运算核大小等超参数需要人工设定；论文以固定默认值（ρ=0.3、D_w=24）报告主结果，未提供自适应策略。
