## 摘要
超高清（UHD）图像恢复必须在空间上重复出现的退化线索的聚合与局部图像结构的保留之间取得平衡。紧凑聚合可以减少冗余处理，但可能会削弱边缘、纹理和其他精细结构。现有方法通过下采样、窗口划分或基于聚类的标记减少来管理UHD恢复成本；然而，其中许多方法并未显式保留那些难以用共享聚合表示的信息。在本研究中，我们提出了一种用于UHD恢复的上下文-细节解耦状态空间模型（CoDe-SSM），该模型在分离的路径中处理聚合上下文和聚类残差。上下文建模路径由全局聚类扫描模块（GCSM）实现，将特征聚合为$K$个依赖于输入的聚类中心，并对生成的固定顺序序列应用选择性SSM推理，从而实现跨区域上下文共享，同时将计算成本与空间分辨率解耦。细节恢复路径由局部高频模块（LHFM）实现，使用源自输入的高频掩码和稀疏混合卷积专家处理聚类残差。在五个UHD基准和五种退化类型上的大量实验表明，我们显式的上下文-细节解耦策略在恢复质量上带来了显著提升，同时保持了理想的效率。

## Abstract
Ultra-high-definition (UHD) image restoration must balance the aggregation of spatially recurring degradation cues with the preservation of localized image structures. Compact aggregation can reduce redundant processing but may attenuate edges, textures, and other fine structures. Existing approaches manage UHD restoration cost through downsampling, window partitioning, or cluster-based token reduction; yet many of them do not explicitly retain information that is poorly represented by shared aggregation. In this study, we propose a Context-Detail Decoupled State Space Model (CoDe-SSM) for UHD restoration, which processes aggregated context and clustering residuals in separate pathways. The context modeling pathway, implemented by the Global Cluster Scan Module (GCSM), aggregates features into $K$ input-dependent cluster centers and applies selective SSM reasoning over the resulting fixed-order sequence, enabling cross-region context sharing while decoupling computational cost from spatial resolution. The detail recovery pathway, implemented by the Local High-Frequency Module (LHFM), processes the clustering residual with an input-derived high-frequency mask and a sparse mixture of convolutional experts. Extensive experiments on five UHD benchmarks and five degradation types demonstrate that our explicit context-detail decoupling strategy yields substantial gains in restoration quality while maintaining desirable efficiency.

## 1. 论文的核心问题与整体含义

- **背景与问题**：超高清（UHD, 3840×2160）图像恢复需要在消除复杂退化的同时保留局部细节，而UHD分辨率下的像素数量使恢复质量和计算成本都面临巨大挑战。现有方法主要从计算成本角度处理UHD恢复问题（如通过下采样、窗口划分、频率分解或聚类令牌减少），但这类“紧凑聚合”策略倾向于削弱边缘、纹理等局部结构，且缺乏对难以用共享聚合表示的信息的显式建模。论文将这一矛盾概括为“上下文-细节权衡”：可共享的退化模式适合聚合处理，而不可共享的局部细节对压缩敏感。
- **核心思路**：将UHD恢复任务解耦为两条互补的处理路径——负责全局共享上下文聚合建模的路径与负责局部细节恢复的路径，分别处理聚合上下文和聚类残差，兼顾全局一致性恢复与局部结构保持。

## 2. 论文提出的方法论

- **总体框架**：CoDe-SSM采用非对称U-Net架构。输入图像经3×3卷积投影至C通道，编码器逐级下采样（2×2步长卷积）并扩大通道数，解码器用pixel shuffling上采样并配合跳跃连接。网络通过可学习的残差门控预测恢复结果：$x̂ = X + σ(α) · f_θ(X)$。
- **CoDeBlock核心流程**：每个U-Net层包含若干CoDeBlock。输入令牌经LayerNorm和线性投影后，分为特征分支F和门控分支G；对特征分支进行原型聚类：
  - 通过1×1卷积计算值特征V，与K个可学习原型锚点P做ℓ2归一化后计算软分配 $A_{ik} = softmax(⟨v̄_i, p̄_k⟩/τ)$；
  - 聚合得到输入相关的聚类中心 $m_k$；
  - 由聚类中心重建 $v̂_i$，并计算聚类残差 $R_i = v_i − v̂_i$。
- **GCSM（上下文路径）**：将K个聚类中心组织为紧凑序列，施加选择性SSM推理，得到精炼后的中心 $\{m'_k\}$，再通过软分配矩阵将精炼结果映射回像素空间，得到 $F_{global}$。由于K ≪ N，计算成本与空间分辨率解耦。
- **LHFM（细节路径）**：聚类残差R中混合了真实高频信号与重建伪影。LHFM先通过**HFE滤波器**（由Laplacian与Sobel算子构成、基于灰度参考图计算的高频能量图，经soft mask门控）隔离真实高频成分；再通过稀疏混合专家模块（4个不同感受野的深度可分离卷积专家，top-2路由）自适应恢复多样化的细节纹理，输出 $F_{local}$。
- **融合**：$F_{out} = F_{global} + F_{local}$，并与门控分支做调制：$F'_{out} = LN(F_{out}) ⊙ SiLU(G)$，最后经线性投影加回原输入，再经GDFN处理。
- **损失函数**：ℓ1损失 + FFT损失 + 面向专家负载均衡的辅助损失 $L_{bal}$（防止专家崩溃）。
