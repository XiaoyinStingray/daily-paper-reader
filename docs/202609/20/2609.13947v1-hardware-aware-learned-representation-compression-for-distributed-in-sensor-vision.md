## 摘要
传感器内计算通过在传感器附近执行早期处理，降低了传输高分辨率图像数据的成本。然而，与 CMOS 图像传感器（CIS）集成的逻辑芯片在计算和内存方面受到严格限制，制约了传统深度神经网络的划分。我们提出 OASIS，一种分布式传感器内视觉框架，利用轻量级编码器在片外传输前生成紧凑且与任务相关的表征。编码器使用任务、熵和重建目标进行端到端训练，而解码器仅在训练期间使用。OASIS 支持两条互补的部署路径。第一条应用 4 比特量化与 Huffman 编码，同时保留分类和密集预测任务所需的空间结构。第二条使用基于 Sobol 的超维计算（HDC）将编码器潜在表示转换为固定维度的二值超向量，用于关联记忆分类。对于基于 SwinViT 的 VWW 模型，将 3×3×8 的潜在表示映射为 64 维超向量，相较于 128 维配置，额外带来 1.77 倍的通信量降低，且精度损失不到一个百分点，与原始 8 位图像传输相比总体实现了 18,816 倍的缩减。我们在 AMD Xilinx Zynq UltraScale+ FPGA 上实现了数字近传感器流水线，并使用直接板级功耗测量和 Vivado 实现后分析，结合电路仿真的 CIS 模型和 7 nm ASIC 预测来对其进行表征。在视觉唤醒词分类、手部追踪和眼动追踪任务中，OASIS 在保持有竞争力的精度的同时，将系统总能耗降低约 2 倍至 4.5 倍，展示了面向通信高效传感器内视觉的实用硬件-算法协同设计路径。

## Abstract
In-sensor computing reduces the cost of transmitting high-resolution image data by performing early-stage processing near the sensor. However, the logic chip integrated with a CMOS image sensor (CIS) is tightly constrained in compute and memory, limiting conventional deep neural network partitioning. We present OASIS, a distributed in-sensor vision framework that uses a lightweight encoder to generate compact, task-relevant representations before off-chip transmission. The encoder is trained end-to-end using task, entropy, and reconstruction objectives, while the decoder is used only during training. OASIS supports two complementary deployment paths. The first applies 4-bit quantization and Huffman coding while preserving the spatial structure required by classification and dense-prediction tasks. The second uses Sobol-based hyperdimensional computing (HDC) to transform the encoder latent into a fixed-dimensional binary hypervector for associative-memory classification. For the SwinViT-based VWW model, mapping a $3\times3\times8$ latent to a 64-dimensional hypervector provides an additional $1.77\times$ communication reduction with less than one percentage point of accuracy loss relative to the 128-dimensional configuration, yielding an overall $18{,}816\times$ reduction compared with raw 8-bit image transmission. We implement the digital near-sensor pipeline on an AMD Xilinx Zynq UltraScale+ FPGA and characterize it using direct board-level power measurements and Vivado post-implementation analysis, together with circuit-simulated CIS models and a 7-nm ASIC projection. Across visual wake-word classification, hand tracking, and eye tracking, OASIS reduces total system energy by approximately $2\times$-$4.5\times$ while maintaining competitive accuracy, demonstrating a practical hardware-algorithm co-design path for communication-efficient in-sensor vision.

- **技术脉络**：既有工作沿"计算向光电二极管推进"的光谱展开——近传感器（near-sensor，加速器与 CIS 同板或 3D 堆叠）、传感器内（in-sensor，计算嵌入 CIS 外围）、像素内（in-pixel，计算在像素阵列内部）。
- **核心痛点（三条）**：
  - **任务与分辨率规模受限**：SCAMP、MR-PIPA、Senputing、DPCE、PiPSim 等多在 MNIST 或低分辨率 CIFAR-10 上验证，网络浅，激活压缩能力有限，无法代表高分辨率多通道实际负载。
  - **计算域与可重构性受限**：许多高效设计依赖模拟/混合信号与新兴非易失器件，只能完成固定的早期操作（常为单个卷积，如 P²M 仅做第一个卷积块），网络主体仍留在片外，按 Amdahl 定律仍主导系统能耗。
  - **评估方法失真**：大量效率数字来自解析式 per-MAC 估算，忽略控制逻辑、存储分块、流水线停顿与互连开销，跨设计比较困难且偏乐观。
- **本文立场**：核心设计问题不是"把已有 DNN 的多少层搬到逻辑芯片"，而是**让传感器侧网络被显式设计为产出一个空间与通道维度都足够小、且计算/存储可容纳于片上资源包络的表征**。据此提出 OASIS——把传感器侧处理建模为**学习式表征压缩**问题：编码器不独立求解任务，只生成紧凑潜在表示，任务特定处理留在片外。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构（双分支自编码器）
- 三个可学习组件：片上轻量编码器 **E**（运行于与 CIS 集成的逻辑芯片）、仅训练期存在的重建解码器 **D**、片外任务相关处理分支。
- 推理时 **D 完全移除**，其算力不进入部署流水线；压缩前端与目标模型**联合学习**（区别于 JPEG 面向人眼感知保真，也区别于"在常规压缩码流上直接推理"）。

### 2.2 训练目标
- 总损失：`L = MSE(X, X̂) + β·L_entropy + γ·L_task`
  - 重建项保留输入信息；任务项保留判别性特征；熵项作用于量化后潜表示。
- 熵损失：`L_entropy = max( E_{Z_quant~P}[−log₂P(Z_quant)] − H_ref , 0 )`，用直方图统计估计离散分布，当期望编码熵超过目标 `H_ref`（实验取 0.7）时，促使输出向少量高频符号集中，便于熵编码。
- 量化感知训练（QAT）+ 直通估计器（STE）近似不可导的取整；采用对称均匀量化，量化范围用动量法在线更新：
  `Z_dequant = Z_quant · q_scale`，`q_scale = 2·max / (2^n − 1)`。

### 2.3 编解码器结构
- **ResNet 编码器**：精简残差结构（3 层、每层 2 个残差块），首层 7×7、stride 4 做激进下采样，通道配置 `[128, 256, d]`，逐层 2× 空间降采样。
- **SwinViT 编码器**：分层 Swin 结构，patch 由 4 增大到 8 以减少 token 数，窗口 7，4 个 stage（每 stage 2 个 block），通道 `[64,128,160,d]`，head 数 `[2,4,5,4]`；早期通道扩张受限、输出端更激进收缩。
- **解码器 D**：expand–contract–expand（ECE）结构，先扩张恢复细粒度信息、再收缩抑制非本质变化、最后扩张回到原图尺寸；输入前加入**模拟高斯噪声**，使编解码器对有限精度扰动更鲁棒。

### 2.4 路径一：量化 + Huffman 编码（通用路径）
- 保留编码器输出的**空间结构**，支持分类与密集预测；4-bit 量化后符号分布高度集中（非均匀），Huffman 树给高频符号短码。
- 实测有效码长 1.57 bit/符号，Huffman 为**无损**变换，不引入量化之外的新精度损失。
- 明确说明 **Huffman 不用于 HDC 超向量**：二值源只有两个符号，Huffman 恒为 1 bit/符号，无压缩收益；且 Sobol 级超向量本身趋于位分布均匀。

### 2.5 路径二：Sobol 超维计算（HDC，仅分类）
- 将扁平化潜向量 `z ∈ R^m` 映射到 `D` 维超向量空间，**D 与 m 解耦**，因此跨接口的数据量由 D 而非潜表示形状决定。
- 流程（Algorithm 1）：归一化 → 每维量化到层级索引 `k = ⌊z̃_m(L−1)⌋` → 取预生成的 Sobol 低差异序列级超向量 `L_k` → 通过 binding（双极逐元素乘 / 二值 XOR）与 bundling（累加后取 sign）合并为样本超向量 `h = sign(Σ v_m)`。
- 训练为**免梯度单遍训练**：把样本超向量累加到真实类原型累加器，再取 sign 得到类原型；推理用相似度（余弦）检索关联记忆，取最高分类别。
- **原型重训练（RT）**：用误分类样本调整类原型（拉近正确、推远错误），最多 30 epoch、batch 512。
- 优点：整个分类路径避免多比特 MAC，仅用 permute/bind/bundle/compare 原语；分布式表示自带位翻转与硬件噪声容忍性；Sobol 替代 LFSR 伪随机提升准正交性。

### 2.6 硬件实现要点
- **APS**：列并行读出，列级共享 ADC（SAR、multi-ramp 为候选），数字化后经 μTSV 直送逻辑层，无需先走常规 ISP 全流程。
- **数字近传感器加速器**：权重固定（weight-stationary），权重常驻片上 BRAM，编码器推理期间无需访问外部 DRAM；SwinViT 逐窗口处理，注意力存储随窗口而非整图扩展；ResNet 复用少量 scratch buffer；卷积核循环完全展开、输入通道累加展开 4 倍、权重数组沿输入通道分区以避免端口竞争；BN/激活/残差加法与注意力、投影、量化、Huffman 查表均以 II=1 流水；Huffman LUT 全部分区到寄存器，64-bit 移位寄存器打包输出 32-bit 字。

### 2.7 能耗建模
- `E_total = E_APS + E_TSV + E_Inf + E_Enc + E_Back`；基线系统无 E_TSV，但 E_Inf 显著更大并主导总能耗。
- 关键常数：APS 读出+ADC ≈ **63.6 pJ/像素**（22nm GF FDSOI 自研电路仿真）；TSV **6.25 pJ/byte**；MIPI/外部接口 **100 pJ/byte**；Huffman 编码 **0.96 pJ/byte**、解码 **1.15 pJ/byte**。
- FPGA→ASIC 投影：`E_ASIC ≈ E_FPGA / α`，取 `α ≈ 20`（可编程布线+LUT 开销约 7–10×、16nm→7nm 约 2–3×、通用 BRAM vs 定制存储宏约 1.5–2×）。
