## 摘要
近期研究表明，Vision Transformer 会稳定进入局部相似的计算阶段，这意味着存在一定程度的深度方向计算冗余。然而，现有利用这种冗余的方法要么无法降低推理计算量，要么严重损害模型表达能力。在这项工作中，我们形式化了一个关于块冗余的统一视角，将几何结构与特定的替代干预解耦。随后我们提出 Transformer-Within-Transformer（TWT），一种事后方法，它将连续的冗余层组融合为单个学习到的替代层。TWT 减少了参数量和推理计算量，同时在自然图像上仅用一半深度仍能与原始模型竞争，并且在若干下游组织病理学设置中，TWT 与原始基线相当甚至有所提升。

## Abstract
Recent findings indicate that Vision Transformers settle into locally similar computational phases, implying a level of depthwise computational redundancy. However, existing methods to exploit this redundancy either fail to reduce inference compute or severely degrade model expressivity. In this work, we formalise a unified view of block redundancy that decouples the geometry from specific surrogate interventions. We then introduce Transformer-Within-Transformer (TWT), a post-hoc method that fuses contiguous groups of redundant layers into a single learned surrogate layer. TWT reduces parameter count and inference compute while remaining competitive with original models using half the depth on natural images, and in several downstream histopathology settings, TWT matches or even improves on the original baseline.

# 论文总结：A Smaller Transformer in Your Transformer（TWT）

## 1. 核心问题与研究背景

- **现象**：近年研究发现 Vision Transformer（ViT）在深度方向上会稳定进入局部相似的"计算阶段"，相邻层之间存在高度功能相似性，即**块冗余（block redundancy）**。论文通过 ImageNet-1k 上各层输出之间的两两余弦相似度矩阵，展示了 DeiT-III、DINOv2、DINOv3 等模型普遍存在清晰的块对角结构。
- **已有方法的困境**：
  - **Block Recurrent Hypothesis (BRH / Raptor)**：用共享权重的单层循环展开替代冗余块，虽降低参数量，但**推理时仍需执行全部 k_j 次变换，计算量不变**。
  - **非混合近似（TOAST、NOSE）**：用闭式线性映射或纯 FFN 替换整段层，虽降低计算量，但**丧失 attention 的动态 token 混合能力，严重损害表达能力**。
- **核心问题**：如何在真正降低推理计算量的同时，不牺牲模型表达能力地利用 ViT 的深度冗余？
- **整体含义**：论文提出一个**统一视角**，把"循环近似"和"线性近似"看作同一几何现象（局部平坦流形上的冗余阶段）的两种代理选择，并主张该现象的本质是几何冗余而非严格的计算必要性。

## 2. 方法论

### 2.1 核心思想

- 将 ViT 的 L 层分解为 m 个连续块：`F_Θ = F_Θm ∘ ... ∘ F_Θ1`，其中每个块对应一个"理想计算阶段"。
- **关键假设**：块内的中间表示 `h_{s_j}(x), ..., h_{e_j-1}(x)` 并非必要，而是局部平坦流形上的过渡微步；因此可用**单个非循环代理层** `f_φj` 直接完成该阶段：`h_{e_j}(x) ≈ f_φj(h_{s_j-1}(x))`。
- 为保证表达能力，代理层 `f_φj` **严格限制为 ViT 标准层结构（多头注意力 + FFN）**，从而保留动态 token 混合能力，这是与 TOAST/NOSE 的本质区别。

### 2.2 关键技术流程（三步）

1. **动态块发现（Max-Min Dynamic Programming）**
   - 计算层间差异矩阵 `S_{a,b} = E_x[d(f_θa(h_{a-1}(x)), f_θb(h_{b-1}(x)))]`，实际用余弦距离。
   - 将块划分建模为覆盖整个网络的**分区问题**，约束块内最大差异 `S_{s_j,e_j} ≤ ε`。
   - 优化目标：`min_P (m, max_j S_{s_j,e_j})`，即先最小化块数 m（最大化压缩），再在并列解中最小化最坏块差异，用动态规划求解。

2. **宏步初始化（Auditioning）**
   - 对每个块 `B_j`，构建候选池 `C_j = {f_θℓ : ℓ ∈ B_j} ∪ {f̄_j}`，包含块内每层及权重平均得到的平均算子。
   - 在小校准批次上选择局部映射误差最小的候选：`f*_φj = argmin_{f∈C_j} E_x[‖f(h_{s_j-1}(x)) − h_{e_j}(x)‖²₂]`，避免随机初始化带来的不稳定。

3. **深度监督蒸馏**
   - 将 K 个代理块拼接为统一学生模型 `F_Φ`，端到端优化。
   - 采用**交错余弦调度** `ω_j(τ)` 逐步激活更深层的监督项，损失为各块输出与教师对应块端点输出以及最终 backbone 特征的 MSE 加权和：`L = Σ_j ω_j(τ)·MSE(h_j; Φ, h_{e_j}; Θ) + ω_{K+1}(τ)·MSE(F_Φ(x), F_Θ(x))`。
   - 使用 AdamW 联合优化；对存在后层范数爆炸的模型（如图 4 所示 DINOv3 后层输出范数增长 63 倍）额外引入**可学习 LayerScale**（初始化为恒等）以稳定收敛。

## 6. 主要结论与发现

- **效率**：TWT 在自然图像上以约一半深度和约一半 FLOPs 保持竞争力；6 层 TWT 在 DINOv2 B/14 上全面优于 6 层 Raptor，而 FLOPs 仅 11.71G vs 23.42G。
- **组织病理学增益**：在 H0-mini 和 Hibou-B 上，TWT 参数减少超过一半，PANDA 上持平，TCGA-PRAD 上提升（如 TransMIL 下 +5.87 QWK），CAMELYON 系列基本持平或提升，外部 CAMELYON16 泛化良好。
- **几何证据**：折叠后的学生在组织病理学中**沿教师的粗粒度 ID 轨迹**，但 ID 更低、增强扰动下方差降低 37.8%–49.6%，说明冗余中间层累积了任务无关的噪声。
- **领域差异**：自然图像上无方法超过 baseline（冗余阶段已被良好调优），而病理模型中骨干相对预训练分布外，中间迭代累积域无关噪声，块折叠反而起到去噪/正则化作用。
- **密集预测敏感性**：ADE20k 分割对块折叠更敏感，TWT 相比 Raptor 额外损失 1.3–1.7 mIoU，提示 patch 级任务需要更保守的折叠或任务感知蒸馏。

## 7. 优点

- **理论视角统一**：将循环近似与线性近似统一为同一几何冗余现象的不同代理选择，形式化了"ε-功能冗余"与代理映射的定义，解耦了几何与干预手段。
- **方法设计巧妙**：代理层保留 attention + FFN 结构，兼顾 token 混合表达力与推理效率；Max-Min DP 的块发现兼顾压缩率与最坏误差；Auditioning 利用教师已有参数初始化，显著稳定训练；交错余弦深度监督逐步引入深层损失。
- **实用性强**：完全事后（post-hoc），无需重新预训练，可直接应用于已有 backbone；代码开源。
- **跨领域验证**：同时在自然图像与组织病理学上验证，且首次展示块折叠在特定下游任务中可**超过原始模型**。
- **几何分析补充**：用 ID 与增强方差分析为"中间层累积噪声"提供可解释证据，而不只是报告精度数字。

## 8. 不足与局限

- **性能提升不具普适性**：作者明确指出，超过 baseline 的现象仅出现在特定设置（本文的组织病理学），不应预期在一般情况下获得提升；自然图像上所有方法均无法超越 baseline。
