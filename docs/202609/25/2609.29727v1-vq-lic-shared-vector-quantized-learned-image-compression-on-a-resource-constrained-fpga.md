## 摘要
学习型图像压缩（LIC）难以部署在资源极度受限的FPGA上，因为其实际运行速度不仅取决于算术运算次数，还取决于内存流量、不同操作之间的不均衡，以及硬件如何对其工作进行批处理。我们提出VQ-LIC，一种非对称边云编解码器：紧凑的INT8深度（DW）-逐点（PW）分析变换和多码本矢量量化（VQ）在边缘端的一对可复用DW/PW引擎上运行，而重建则由更大的云端解码器处理。由于VQ码字匹配可表示为点积，因此它被直接映射到同一PW引擎上，从而无需单独的VQ计算阵列；据我们所知，这在FPGA LIC中尚属首次。一种新颖的延迟模型基于FPGA的读取、DW、PW和写入开销的确定性RTL周期计数推导而来，可预测分析变换的每块延迟；由于VQ共享相同的PW数据通路，该模型也适用于VQ。该模型直接在实际芯片上验证，对部署后的分析变换和VQ延迟的预测误差分别在0.26%和0.05%以内，并指导选择三模块16-48-64变换。训练后码本缩减则将VQ的算术量和码本存储减少为原来的1/4，并缩小固定宽度的潜在表示。在具有220个DSP的Zynq-7020上，VQ-LIC的中等码率预设在CLIC 2017上以28.69 dB PSNR和13.06 dB MS-SSIM达到0.1398比特/像素，优于规模相近的神经编码器，并达到与规模大三个数量级的编解码器相当的率失真范围。完整的0.1945-kMAC/像素分析-VQ流水线在芯片上以47.98帧/秒和每帧42.84 mJ运行，相比同类FPGA LIC加速器少用了一个数量级的DSP，同时在适度牺牲PSNR的情况下实现了更低的比特率、更高的吞吐量和更低的每帧能耗。

## Abstract
Learned image compression (LIC) is hard to deploy on severely resource-constrained FPGAs, since how fast it actually runs depends not just on arithmetic count, but also on memory traffic, imbalance between different operations, and how the hardware batches its work. We present VQ-LIC, an asymmetric edge-cloud codec in which a compact INT8 depthwise (DW)-pointwise (PW) analysis transform and multi-codebook vector quantization (VQ) run at the edge on a reusable DW/PW engine pair, while reconstruction is handled by a larger cloud decoder. Since VQ codeword matching is expressible as a dot product, it is mapped directly onto the same PW engine, removing the need for a separate VQ compute array, to our knowledge a first for FPGA LIC. A novel latency model, derived from deterministic RTL cycle counts of an FPGA's read, DW, PW, and write costs, predicts an analysis transform's per-block latency; since VQ shares the same PW datapath, the model applies to VQ as well. Validated directly against silicon, the model predicts deployed analysis and VQ latency within 0.26\% and 0.05\%, and guides the selection of a three-block $16$-$48$-$64$ transform. Post-training codebook reduction then cuts VQ arithmetic and codebook storage by $4\times$ and shrinks the fixed-width latent representation. On a 220-DSP Zynq-7020, VQ-LIC's mid-rate preset reaches 0.1398 bits per pixel at 28.69 dB PSNR and 13.06 dB MS-SSIM on CLIC~2017, outperforming a similarly sized neural encoder and reaching a rate-distortion range comparable to a codec three orders of magnitude larger. The complete 0.1945-kMAC/pixel analysis-VQ pipeline runs at 47.98 frames per second and 42.84 mJ per frame on silicon, using an order of magnitude fewer DSPs than comparable FPGA LIC accelerators while achieving lower bitrate, higher throughput, and lower energy per frame at a modest PSNR tradeoff.

## 1. 核心问题与研究背景

- **部署鸿沟**：学习型图像压缩（LIC）的增益越来越依赖更大的变换网络、超先验、自回归上下文模型和注意力机制，其算术量、存储、激活流量和熵模型开销使其难以部署到低成本的嵌入式/边缘设备，即便经过数值量化。
- **现有 FPGA 加速器的局限**：DPU 映射、细粒度流水、参数化架构、算法-架构协同优化、流式重构等工作（FPX-NIC、F-LIC、StreamLIC、X-LIC、Sun et al.）大多面向资源宽裕的平台（数千 DSP、KU115/VCU118/ZCU102 级别）。在极度受限平台上，简单缩小规模并不够用。
- **关键洞察**：在有限乘法器预算和窄外部存储接口下，**MAC 数量并不能可靠预测实际延迟**——访存流量、DW（深度）与 PW（逐点）算子间的不均衡、有限输出批处理都可能成为瓶颈。
- **核心研究问题**：能否让潜在表示（latent）的选择使得**编码与量化共享同一稀缺计算硬件**？
- **整体含义**：论文提出 VQ-LIC——一种非对称边云编解码器，边缘只做压缩（紧凑 INT8 DW/PW 分析变换 + 多码本 VQ），重建交给云端大模型；通过让 VQ 码字匹配复用 PW 引擎的乘法阵列，在 220-DSP 的 Zynq-7020 上实现实时边缘编码。

## 2. 方法论

### 2.1 总体架构（Fig. 1）
- **边缘端（PL + PS）**：3 块 stride-2 的 3×3 深度卷积 + 1×1 逐点卷积（通道 16–48–64），720p 输入 → 90×160×64 潜在表示；4,491 个卷积权重、194.5 MAC/像素；BN 折叠进前级卷积；中间激活重新量化为 INT8，最终 latent 以无符号 INT8 存储。
- **量化端**：多码本 VQ（D=64，M=4 个子向量，Dm=16），在 PL 内执行。
- **熵编码**：在 Cortex-A9（PS）上用 rANS，使用**预共享的固定条件概率表**，避免边缘上的超先验/自回归熵模型推理。
- **云端解码器**：约 6.51M 参数，先将量化 latent 投影到 256 维 token，经 6 层 Transformer（8 头、FFN 1024、固定 14×14 窗口自注意力，交替层偏移 7 token 以跨窗口交换信息），再经 3 级 sub-pixel 上采样卷积头重建 RGB（Tanh 输出）。

### 2.2 熵约束向量量化（ECVQ）
- 每个空间位置的 D 维向量被切分为 M 个不相交子向量，各自在自己 K 项子码本中匹配；赋值准则为式 (1)：

  `k = argmin_j [ ||z − e_j||² − β_rate · log2 p_j ]`

  其中 p_j 是码字使用概率的 EMA 估计，β_rate 控制码率压力。
- **整数部署形式（式 2）**：展开平方距离并去掉与查询范数相关的公共项后，只剩三项——预计算的码字范数项、先验项、以及一个**点积项**。点积项直接由既有 PW MAC 阵列计算，其余项预先算好并作为偏置加到宽累加器输出上，再由辅助逻辑完成比较/argmin。
- **训练**：码本用 EMA 更新，梯度经直通估计器（STE）回传。

### 2.3 延迟模型（Algorithm 1，确定性 RTL 周期计数，无拟合项）
- 每块延迟取四类开销的最大值（瓶颈）：`T_block = max(T_read, T_DW, T_PW, T_write)`。
- 关键公式：
  - 批次数 `B = ⌈c_out/Q⌉`，`Δ = max(c_in + δ_acc, Q + δ_ppu)`，`Γ = c_in + ⌈Q_last/R_sh⌉ + δ_acc`
  - `T_PW = (P/L)·GROUP_LATENCY(c_in, c_out, H)`；`T_DW = (H+1)[c_in(G+δ_flush) + δ_row]`
  - 总分析延迟 `T_enc = Σ_j T_block,j`（块间无计算重叠，中间输出落 DDR）
- 常量（RTL 结构决定）：L=8，W_DMA=8 B/cyc，R_sh=2，δ_acc=6，δ_ppu=2，δ_tr=1，δ_flush=1，δ_row=4。
- **VQ 复用同一 PW 调度**：把码字维度 Dm 当作 c_in、把 M·K（全部码字数）当作 c_out 代入同一 GROUP_LATENCY，得 `T_VQ = (N_pos/L)·GROUP_LATENCY(Dm, M·K, H)`；要求 K 为 Q 的整数倍，使每个批次恰好属于单一子码本，无零填充浪费。
- 一般化量化器设计规则：穷举打分需 `N_mul,VQ = M·K·Dm = D·K` 次标量乘法，码本存 DK 个标量，索引需 `M⌈log2 K⌉` 比特——K 降低则算术、存储、索引位宽线性下降。

### 2.4 硬件实现
- **平台**：Zynq-7020（XC7Z020CLG484-1），220 个 DSP48E1，DDR↔PL 64 位通路，100 MHz。
- **DW 引擎**：按空间位置并行（每周期算一个通道内 L 个相邻像素的完整 3×3 滤波），避免第一层 3 通道时通道并行浪费；行缓冲 + 滑窗生成器片上零填充；L 通道 PPU 精确跟随。
- **PW 引擎**：输出驻留式；每周期把 1 个输入通道的 L 个激活广播到 Q 个输出通道 bank；ping-pong 缓冲重叠输入装载与计算；用标准 INT8 DSP packing 把两个零点半校正激活打包进一个 DSP48E1，**一个 DSP 恢复两个精确有符号乘积**；L=8、Q=32 → 每周期 256 乘积、128 个 DSP（结构阵列 `D_PW = LQ/2`）。
- **split-shadow 累加器退休**：批次结果拷到 shadow bank（每周期 2 通道），下一批累加立即开始，PPU 并行读出前一组；最后不足 Q 的批次只退休有效通道。
- **DW→PW 片上融合**：块内 DW 输出直接流入 PW，省掉一次 DDR 写回/读取；块间仍需物化。VQ 阶段读回 latent，与普通卷积竞争同一 PW 资源，不能同时运行。

### 2.5 分阶段协同设计（Fig. 3）
1. 用参考网络 `C_ref = (16,32,32,32,64,64)` 做**硬件供给（provisioning）**：L=8 固定（加倍到 16 需 128 位接口重设计且 256 DSP 超预算），在 Q∈{8,16,32} 中选 Q*=32。
2. 用同一延迟模型作为 **latency oracle** 指导编码器拓扑搜索（无需逐个上板）。
3. 再复用该模型（因 VQ 共享 PW 通路）指导训练后码本基数精化。
4. 最后在硅上再次验证。

### 2.6 训练目标与量化
- 损失：`L = α(1−SSIM) + (1−α)||x−x̂||₁ + β||z_e − sg[z_q]||²`，α=0.84，β=0.25。
- 三档码率预设独立训练：β_rate = 1.0 / 0.4 / 0.3（低/中/高码率）。
- 编码器 per-channel 对称有符号 INT8 权重、per-tensor 非对称无符号 INT8 激活，卷积积用更宽整数精度累加后再量化；latent 与码本共用零点 z₀=128。
