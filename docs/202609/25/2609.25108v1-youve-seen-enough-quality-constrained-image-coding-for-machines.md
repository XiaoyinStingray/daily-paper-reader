## 摘要
视觉数据正越来越多地被机器视觉系统而非人类观察者所消费。面向机器的图像编码（ICM）在压缩图像时假定主要观察者是计算机视觉应用，而人类观察者需要检查或验证其决策。受恰可察觉失真的启发——该失真相对于人类观察者将质量设定在刚好可接受的水平——我们旨在将人类观测质量限制在期望水平，从而利用剩余编码容量来提升机器性能。我们将联合压缩-分割训练重新表述为一个约束优化问题，其中编解码器必须满足预定义的、可接受的目标视觉质量，而任务项则消耗剩余编码容量。我们通过设计惩罚函数来引导质量达到期望目标，从而解决该问题。我们提出两种惩罚函数：绝对值函数和双线性函数，后者在超过目标视觉质量后施加更陡的斜率。实验结果表明，在质量约束下，所提方法相较于无约束的联合率-失真-任务优化取得了 -22.82% 的 BD-rate，相较于简单的率-失真基线取得了 -29.81% 的 BD-rate，在相同任务性能下展示了比特率降低。同时，编解码器还以合理误差满足目标视觉质量，且未增加任何复杂度开销。

## Abstract
Visual data is increasingly consumed by machine-vision systems rather than by human observers. Image Coding for Machines (ICM) compresses images assuming the main observer is a computer vision application and that the human observer needs to inspect or validate the decisions. Inspired by just-noticeable distortion, which sets the quality to the just-acceptable level for human observers, we aim to cap the human-observed quality at a desired level, with the goal of using the remaining coding capacity to improve the machine performance. We recast joint compression-segmentation training as a constrained optimization problem in which the codec must meet a predefined acceptable target visual quality while a task term consumes the remaining coding capacity. We solve this by designing a penalty function to guide the quality to the desired target. We propose two penalty functions, an absolute function and a bilinear function, the latter applying a steeper slope once the target visual quality is exceeded. Experimental results show that, under the quality constraint, the proposed method achieves a BD-rate of $-22.82\%$ over an unconstrained joint rate--distortion--task optimization and $-29.81\%$ over a simple rate--distortion baseline, showcasing bitrate reduction with the same task performance. This is achieved while the codec also meets the target visual quality with a reasonable error and without adding any complexity overhead.

## 1. 核心问题与整体含义

- **背景**：视觉数据日益被机器视觉系统而非人类消费。传统编解码器（AVC/HEVC/VVC）与多数端到端学习图像压缩（LIC）都针对人眼优化，使用 PSNR、MS-SSIM 等指标；这些指标与下游视觉模型的准确率相关性弱，导致比特被花在与任务无关的纹理细节上，而任务关键结构可能在重建中丢失。
- **研究领域**：面向机器的图像编码（ICM）应运而生，MPEG 标准化将其分为两大范式：
  - **FCM**（特征编码）：仅机器消费，压缩中间特征；
  - **VCM/ICM**（像素域）：人机混合消费，保留可解码图像并联合优化任务损失。
- **核心痛点**：现有联合优化方法通过两个拉格朗日乘子（λ₁、λ₂）隐式地权衡质量与任务，给定比特率下实现的质量是优化器"自己决定"的，而非被引导到用户期望的水平，难以精确控制人眼可接受质量。
- **核心问题**：如何显式控制编解码器输出质量，同时把从感知保真度中释放出的学习容量重新分配给下游任务？
- **动机**：受恰可察觉失真（JND）启发——人类观察者在重建超过"足够好"质量后即满足，超出该水平的保真度是比特浪费。

## 2. 方法论

### 2.1 核心思想
将联合压缩-分割训练**重新表述为约束优化问题**：在码流满足预设目标视觉质量（PSNR）的前提下，最小化率与任务损失，让剩余编码容量流向任务性能。

### 2.2 问题形式化
- 用户指定目标质量 PSNR_t：
  $$\min_\theta \; R + \lambda T \quad \text{s.t.} \quad \text{PSNR}(x, \hat{x}) = \text{PSNR}_t$$
- 因 PSNR 是 MSE 的单调变换（$\text{PSNR} = 10\log_{10}(255^2/\text{MSE})$），目标转为失真目标 $D_t = 255^2 / 10^{\text{PSNR}_t/10}$：
  $$\min_\theta \; R + \lambda T \quad \text{s.t.} \quad D(x, \hat{x}) = D_t$$
- 用**罚函数法**转为无约束目标：
  $$L = R + \lambda_1 P(D(x,\hat{x}), D_t) + \lambda_2 T$$

### 2.3 惩罚函数设计（两阶段行为）
- 当未达目标质量（$D \ge D_t$）时，退化为标准率失真 $\lambda_1 D$；
- 当超过目标质量（$D < D_t$）时，惩罚进一步花比特提升视觉质量。
- **绝对惩罚**（关于目标对称）：
  $$P_{abs}(D, D_t) = |D - D_t| + D_t$$
  缺点：低比特率下 λ₁ 小，模型仍会超出目标。
- **双线性惩罚**（超目标后斜率更陡，$\lambda_1' > \lambda_1$）：
  $$P_{bi}(D, D_t) = \begin{cases} D, & D \ge D_t \\ -\frac{\lambda_1'}{\lambda_1}D + \left(1 + \frac{\lambda_1'}{\lambda_1}\right)D_t, & D < D_t \end{cases}$$
  实验中 $\lambda_1' = 2\lambda_1$ 效果良好，可调斜率使该惩罚更灵活且整体优于绝对惩罚。

### 2.4 框架与损失
- LIC 编解码器（参数 θ，含分析变换 g_a、合成变换 g_s）与冻结的下游任务网络（参数 φ）耦合；训练仅优化 θ，任务网络梯度仍可回传。
- 三项损失：率 $R$（$\hat{y}$、$\hat{z}$ 在熵模型下的负对数似然）、失真 $D = \text{MSE}(x,\hat{x})$、任务损失 $T$（重建图上分割预测的逐像素交叉熵）。

### 2.5 基线
- **Baseline**：纯率失真学习编解码器，仅推理时接任务网络，$L = R + \lambda_1 D$。
- **JO（Joint Optimization）**：无约束联合模型，$L = R + \lambda_1 D + \lambda_2 T$。

## 6. 主要结论与发现

- **量化收益**（相同任务性能下的 BD-rate，负值代表节省）：
  - 双线性惩罚：较 Baseline **−29.81%**，较 JO **−22.82%**，较 VCM VTM **−45.78%**；
  - 绝对惩罚：较 Baseline **−20.69%**，较 JO **−11.32%**，较 VCM VTM **−38.44%**；
  - BD-mIoU 提升分别为 +5.60%/+3.86%（双线性）与 +4.29%/+2.13%（绝对）。
- **质量可控性**：编解码器能以合理误差将 PSNR 维持在目标附近，而基线无约束方法质量随比特率漂移；双线性惩罚在低到中比特率区间优势最明显，且在整个目标质量范围内均取得比特率节省。
- **比特重分配机制**：比特从道路、天空等平滑易预测区域转移到车辆、杆、物体边界等任务显著结构；低比特率下牺牲约 5 dB PSNR（31.1 vs 36.5 dB），换来 +9.2 点 mIoU（42.4% vs 33.2%），且感知上仍可接受。
- **潜表示**：提出方法的归一化潜变量空间结构更不平滑，表明熵模型校准更好，比特预算集中在少数高能量通道，任务信息通道被更强激活。
- **两点核心发现**：在 ICM 中瞄准特定失真水平是可行的；适度的惩罚执行可提升任务准确率。
- **复杂度**：不引入额外复杂度开销（编解码器结构不变）。
