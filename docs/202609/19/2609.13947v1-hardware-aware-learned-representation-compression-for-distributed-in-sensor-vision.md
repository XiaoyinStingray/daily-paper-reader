## 摘要
传感器内计算通过在传感器附近执行早期处理，降低了传输高分辨率图像数据的成本。然而，与CMOS图像传感器（CIS）集成的逻辑芯片在计算和内存方面受到严格限制，制约了传统深度神经网络划分。我们提出OASIS，一种分布式传感器内视觉框架，它使用轻量级编码器在片外传输之前生成紧凑且与任务相关的表征。编码器使用任务、熵和重建目标进行端到端训练，而解码器仅在训练期间使用。OASIS支持两条互补的部署路径。第一种应用4比特量化和霍夫曼编码，同时保留分类和密集预测任务所需的空间结构。第二种使用基于Sobol的超维计算（HDC），将编码器潜在表示转换为固定维度的二值超向量，用于联想记忆分类。对于基于SwinViT的VWW模型，将$3\times3\times8$潜在表示映射为64维超向量，相比128维配置，可额外带来$1.77\times$的通信量降低，且准确率损失小于一个百分点，与原始8位图像传输相比总体降低$18{,}816\times$。我们在AMD Xilinx Zynq UltraScale+ FPGA上实现了数字近传感器流水线，并使用直接的板级功耗测量和Vivado实现后分析，结合电路仿真的CIS模型和7纳米ASIC投影对其进行表征。在视觉唤醒词分类、手部跟踪和眼动跟踪中，OASIS将系统总能耗降低约$2\times$-$4.5\times$，同时保持有竞争力的准确率，展示了面向通信高效传感器内视觉的实用硬件-算法协同设计路径。

## Abstract
In-sensor computing reduces the cost of transmitting high-resolution image data by performing early-stage processing near the sensor. However, the logic chip integrated with a CMOS image sensor (CIS) is tightly constrained in compute and memory, limiting conventional deep neural network partitioning. We present OASIS, a distributed in-sensor vision framework that uses a lightweight encoder to generate compact, task-relevant representations before off-chip transmission. The encoder is trained end-to-end using task, entropy, and reconstruction objectives, while the decoder is used only during training. OASIS supports two complementary deployment paths. The first applies 4-bit quantization and Huffman coding while preserving the spatial structure required by classification and dense-prediction tasks. The second uses Sobol-based hyperdimensional computing (HDC) to transform the encoder latent into a fixed-dimensional binary hypervector for associative-memory classification. For the SwinViT-based VWW model, mapping a $3\times3\times8$ latent to a 64-dimensional hypervector provides an additional $1.77\times$ communication reduction with less than one percentage point of accuracy loss relative to the 128-dimensional configuration, yielding an overall $18{,}816\times$ reduction compared with raw 8-bit image transmission. We implement the digital near-sensor pipeline on an AMD Xilinx Zynq UltraScale+ FPGA and characterize it using direct board-level power measurements and Vivado post-implementation analysis, together with circuit-simulated CIS models and a 7-nm ASIC projection. Across visual wake-word classification, hand tracking, and eye tracking, OASIS reduces total system energy by approximately $2\times$-$4.5\times$ while maintaining competitive accuracy, demonstrating a practical hardware-algorithm co-design path for communication-efficient in-sensor vision.

## 1. 核心问题与研究动机

- **背景**：计算机视觉在监控、自动驾驶、AR/VR、移动设备中广泛部署，高分辨率/高帧率图像在传感器与外部处理器之间的传输造成巨大的通信、带宽与能耗开销。传统 CIS 只负责光电转换，把像素流整体送给 CPU/GPU 处理，任务相关信息提取之前就已付出高昂代价。
- **既有方案谱系**：near-sensor（加速器靠近传感器）、in-sensor（计算嵌入 CIS 外围）、in-pixel（像素内计算）。它们缩短了感知与计算的距离，但存在三类共性局限：
  - **任务与分辨率尺度受限**：多数工作仅在 MNIST 或低分辨率 CIFAR-10 上验证（SCAMP、MR-PIPA、Senputing、DPCE、PiPSim），网络浅、激活压缩能力有限。
  - **计算域与可重构性受限**：大量高效设计依赖模拟/混合信号或非易失器件，只能做固定的早期操作（通常仅一层卷积），跨任务灵活性差（如 P²M 只在像素内做第一个卷积块，剩余网络仍在片外，按 Amdahl 定律主导系统能耗）。
  - **评估方法论不严谨**：许多效率数据来自解析式 per-MAC 估计，忽略控制逻辑、存储分体、流水线停顿与互连开销，跨设计比较困难且偏乐观。
- **核心设计问题**：不是"把已有 DNN 的多少层搬到逻辑芯片上"，而是**传感器侧网络应被显式设计为产生空间与通道维度足够小、同时满足集成逻辑芯片资源约束的表征**。OASIS 将传感器侧处理建模为**学习式表征压缩问题**：编码器不必独立解决目标任务，只需生成紧凑 latent，使片外模型能恢复下游任务所需信息。
- **适用条件**：当"减少外部通信与后端处理所节省的能量"超过"本地计算紧凑表征的额外开销"时，该架构才成立。

## 2. 方法论

### 2.1 核心思想：双分支自编码器架构

- 三个学习组件：
  - **轻量编码器 E**：部署在与 CIS 集成的逻辑芯片上，把传感器输入变换为远小于原图的 latent 张量。
  - **重建解码器 D**：仅训练时参与，推理时完全移除，不进入部署数据通路。
  - **应用相关处理分支**：片外执行，决定最终任务输出。
- 关键解耦：**表征学习与最终任务推理分离**，编码器专注激进降维，任务特定处理留在片外。

### 2.2 编码器骨干

- **ResNet 变体**：3 个 stage，每 stage 2 个残差块；首层 7×7 卷积、stride=4 做激进下采样；通道配置 [128, 256, d]，每层空间下采样 2×，输出空间尺寸 s×s。
- **SwinViT 变体**：基于层级 Swin Transformer；patch size 由 4 增大到 8 以减少高分辨率输入的 token 数；4 个 stage（每 stage 2 个 block），通道 [64, 128, 160, d]，head 数 [2, 4, 5, 4]；早期通道扩张受限，靠近输出时更激进压缩。
- **设计动机**：常规骨干往往在空间降维前逐步增加特征维度，导致参数与中间激活难以驻留片上存储；OASIS 的紧凑编码器使**模型与工作特征缓冲全部驻留片上**，避免传感器侧访问外部 DRAM。

### 2.3 训练目标与量化

- 总损失：**L = MSE(X, X̂) + β·L_entropy + γ·L_task**
  - 重建项约束压缩表征保留输入信息（自监督信号）；
  - 任务项显式保留目标应用所需特征；
  - 熵项直接作用于量化后 latent：`L_entropy = max(E[-log2 P(Z_quant)] − H_ref, 0)`，用直方图统计估计离散分布，当期望编码熵超过 H_ref 时鼓励编码器把输出重新分配到更少的频繁符号上。
- **量化感知训练（QAT）**：对称均匀量化，量化范围用动量式过程动态更新；对不可微的取整操作用**直通估计器（STE）**近似反传梯度；反量化 `Z_dequant = Z_quant / q_scale`，`q_scale = 2·max/(2^n − 1)`。
- **解码器结构**：expand–contract–expand（ECE）；量化表征先反量化并**注入模拟高斯噪声**（模拟有限精度扰动，提升 latent 稳定性），再做三次尺度变换恢复空间/通道维度。

### 2.4 两条互补部署路径

- **路径①：量化 + Huffman 编码（默认路径）**
  - 保留编码器输出的空间结构，支持分类与稠密预测任务；
  - 4-bit 量化后符号分布高度集中，Huffman 树为高概率值分配短码，无损恢复量化符号序列，不引入额外精度损失；
  - 实现上 4-bit 量化器与 16 项 Huffman 查找表以 II=1 流水化，查找表全部分区为寄存器，64-bit 移位寄存器打包成 32-bit 输出字。
- **路径②：Sobol 超维计算（HDC，分类专用）**
  - 把展平的 latent z ∈ R^m 映射到 D 维超向量空间（D 与 m 解耦，**通信量由 D 决定而非 latent 形状**）；
  - 每个归一化特征量化到 level index k，查表得到 level 超向量；level 向量由**低差异 Sobol 序列**生成（替代 LFSR 伪随机生成，改善准正交性）；
  - 通过 binding（双极 ±1 逐元素乘 / 二值 XOR）与 bundling（累加后取 sign）得到样本超向量；
  - 训练：梯度无关的单遍训练——每个样本超向量累加到其真值类原型，最后对累加器取 sign 得到类原型；
  - 推理：查询 latent 编码为超向量后与所有类原型做余弦相似度比较，取最高分；
  - **Huffman 不适用于 HDC**：二值源只有 {0,1} 两个符号，Huffman 树无论倾斜程度都只能分配 1 bit/符号，无压缩收益；且 Sobol level 向量本身趋于均匀分布。因此 64 维超向量直接传输。

### 2.5 硬件架构与能量模型

- **系统组成**：APS（列并行读出，列级 SAR / 多斜坡 ADC）→ TSV 高带宽低能耗 die-to-die 接口 → 传感器侧逻辑芯片（编码器 + 后编码处理）→ MIPI / 有线无线接口 → 片外任务处理器。
- **传感器侧加速器**：权重固定（weight-stationary）组织，PE 内含量化 MAC 数据通路与本地激活/权重存储；编码器参数全部驻留片上 BRAM。
  - SwinViT：注意力限于局部窗口，特征图逐窗口处理，Q/K/V 与注意力分数存储随窗口大小而非全图扩展；
  - ResNet：少量 scratch buffer 跨残差块复用，存储容量不随网络深度线性增长；
  - 流水线并行：ResNet 空间卷积核循环全展开、输入通道累加展开 4 倍，权重数组沿输入通道分区；BN/激活/残差加法 II=1。SwinViT 的 Q/K/V/输出投影通道累加展开 4 倍，注意力分数生成与概率加权值累加逐窗口独立且 II=1。
- **总能量模型**：`E_Total = E_APS + E_TSV + E_Inf + E_Enc + E_Back`
  - `E_APS = (E_read/pix + E_ADC/pix)·N_pix`，22nm GF F
