## 摘要
视频压缩旨在在受限比特率下最小化重建失真。现有的视频隐式神经表示（INRs）通常独立解码帧，使中间特征不以先前重建为条件，且内容嵌入缺乏显式时间预测。我们提出 TCNeRV，它在特征域和嵌入域中均利用重建上下文。其多尺度时序上下文融合（MTCF）模块在多个解码器尺度上注入门控历史特征，而时序嵌入残差编码（TERC）预测每个内容嵌入并仅编码其残差。在约 3M 参数下，TCNeRV 在 UVG 数据集上取得 36.08 dB 的平均 PSNR，比 HNeRV-Boost 高出 2.20 dB。相对于 HM、DCVC 和 HiNeRV，它分别将 BD-rate 降低 22.06%、66.73% 和 29.85%，在有限模型容量下展现出具有竞争力的率失真性能。

## Abstract
Video compression aims to minimize reconstruction distor tion under a constrained bit rate. Existing video implicit neural representations (INRs) often decode frames independently, leaving intermediate features unconditioned on previous reconstructions and content embeddings without explicit temporal prediction. We propose TCNeRV, which exploits reconstructed context in both feature and embedding domains. Its multi-scale temporal-context fusion (MTCF) module injects gated historical features at multiple decoder scales, while temporal embedding-residual coding (TERC) predicts each content embedding and codes only its residual. With approximately 3M parameters, TCNeRV achieves an average PSNR of 36.08 dB on the UVG dataset, outperforming HNeRV-Boost by 2.20 dB. It reduces BD-rate by 22.06%, 66.73%, and 29.85% relative to HM, DCVC, and HiNeRV, respectively, demonstrating competitive rate-distortion performance with limited model capacity.

## 2. 方法论
- **总体框架**：TCNeRV 基于 HNeRV-Boost，使用量化后的内容嵌入、时序嵌入和条件解码器参数表示视频。共享 ConvNeXt 编码器提取当前内容嵌入；六阶段条件解码器逐级恢复空间分辨率。
- **双域时序建模**：  
  - **MTCF**：在解码特征域注入历史重建特征，减少失真；  
  - **TERC**：在内容嵌入域预测当前嵌入并只编码残差，去除时间冗余。
- **MTCF 多尺度时序上下文融合**：  
  - 在 Stage 3 和 Stage 4 工作，分辨率分别为 135×240 和 270×480。  
  - 将前一重建帧 `c_t` 缩放并变换为尺度对齐的上下文特征：`f_ctx_i = Φ_i[Resize(c_t; H_i, W_i)]`。  
  - `Φ_i` 包含 3×3 卷积、GELU 激活和 1×1 卷积，将 3 通道映射到 `max(C_i,32)` 再到 `C_i`。  
  - 通过可学习门控融合：`a_i = sigmoid(g_i)`，`f_out_i = f_dec_i + a_i ⊙ f_ctx_i`。  
  - Stage 3 提供布局和运动线索，Stage 4 增强边缘和纹理；门控用于抑制遮挡、快速运动或场景变化下的不可靠历史信息。  
  - 首帧使用零上下文，后续帧使用前一重建，形成编码器和解码器共享的因果闭环。
- **TERC 时序嵌入残差编码**：  
  - 共享 ConvNeXt 编码器提取目标嵌入 `y_t = E(x_t; φ)`，嵌入维度 `C_e=16`，空间尺寸 `9×16`。  
  - 当前嵌入预测为：首帧 `y_pred_t = 0`；后续帧 `y_pred_t = P(stopgrad[E(c_t; φ)])`，其中 `P` 是 1×1 卷积预测器。  
  - 只量化和熵编码残差 `r_t = y_t - y_pred_t`。  
  - 解码时重建嵌入：`e_y_t = stopgrad(y_pred_t) + r_hat_t`。  
  - 首帧编码完整嵌入，后续帧只编码时间不可预测信息；stop-gradient 防止预测分支和残差分支相互抵消。  
  - 训练损失、熵正则化和压缩微调沿用 HNeRV-Boost。
