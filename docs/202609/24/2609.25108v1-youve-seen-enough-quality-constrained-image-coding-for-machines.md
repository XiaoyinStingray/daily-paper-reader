## 摘要
视觉数据正越来越多地由机器视觉系统而非人类观察者使用。面向机器的图像编码（ICM）在压缩图像时假定主要观察者是计算机视觉应用，而人类观察者需要检查或验证其决策。受恰可察觉失真的启发——其将质量设定为人类观察者刚好可接受的水平——我们旨在将人类观察到的质量限制在期望水平，从而利用剩余编码容量来提升机器性能。我们将联合压缩-分割训练重新表述为一个约束优化问题，其中编解码器必须达到预定义的、可接受的目标视觉质量，而任务项则消耗剩余编码容量。我们通过设计惩罚函数来引导质量达到期望目标，从而求解该问题。我们提出两种惩罚函数：绝对值函数和双线性函数，后者在超过目标视觉质量后采用更陡的斜率。实验结果表明，在质量约束下，与无约束的联合率-失真-任务优化相比，所提方法取得了 $-22.82\%$ 的 BD-rate；与简单的率-失真基线相比，取得了 $-29.81\%$ 的 BD-rate，在相同任务性能下展示了比特率降低。同时，编解码器还能以合理的误差达到目标视觉质量，且不增加任何复杂度开销。

## Abstract
Visual data is increasingly consumed by machine-vision systems rather than by human observers. Image Coding for Machines (ICM) compresses images assuming the main observer is a computer vision application and that the human observer needs to inspect or validate the decisions. Inspired by just-noticeable distortion, which sets the quality to the just-acceptable level for human observers, we aim to cap the human-observed quality at a desired level, with the goal of using the remaining coding capacity to improve the machine performance. We recast joint compression-segmentation training as a constrained optimization problem in which the codec must meet a predefined acceptable target visual quality while a task term consumes the remaining coding capacity. We solve this by designing a penalty function to guide the quality to the desired target. We propose two penalty functions, an absolute function and a bilinear function, the latter applying a steeper slope once the target visual quality is exceeded. Experimental results show that, under the quality constraint, the proposed method achieves a BD-rate of $-22.82\%$ over an unconstrained joint rate--distortion--task optimization and $-29.81\%$ over a simple rate--distortion baseline, showcasing bitrate reduction with the same task performance. This is achieved while the codec also meets the target visual quality with a reasonable error and without adding any complexity overhead.

- **核心矛盾**：面向机器编码（ICM/VCM）需要兼顾“人可检查”与“机器可理解”。现有联合优化方法通常用多个拉格朗日乘子隐式平衡率、失真和任务损失，导致给定码率下实际质量不可控，可能在任务无关纹理上浪费码率。
- **论文动机**：受“恰可察觉失真”（JND）启发，认为人类观察者只需达到“够好”的质量即可。因此应将人眼可观察质量限制在用户指定目标，把剩余编码容量重新分配给机器任务。
- **核心问题**：如何在联合压缩-分割训练中显式控制编解码器输出质量，并将从感知保真中释放出的学习容量用于提升下游任务性能？

## 2. 方法论

- **整体框架**：将可训练 LIC 编解码器与冻结的下游任务网络耦合。输入图像 \(x\) 经分析变换、量化、合成变换得到重建 \(\hat{x}\)，再送入任务网络。训练时只优化编解码器参数 \(\theta\)，任务网络参数 \(\phi\) 冻结，但其梯度可回传到编解码器。
- **三类损失**：
  - 率损失 \(R\)：量化隐变量在熵模型下的负对数似然。
  - 失真损失 \(D\)：\(D=\mathrm{MSE}(x,\hat{x})\)。
  - 任务损失 \(T\)：分割预测的逐像素交叉熵。
- **基线形式**：
  - 纯率-失真基线：\(L_{\text{Baseline}}=R+\lambda_1 D\)。
  - 无约束联合优化 JO：\(L_{\text{JO}}=R+\lambda_1 D+\lambda_2 T\)。
- **质量约束建模**：
  - 用户指定目标 PSNR 值 \(\mathrm{PSNR}_t\)。
  - 因 PSNR 是 MSE 的单调变换，将目标转为失真目标：\(D_t=255^2/10^{\mathrm{PSNR}_t/10}\)。
  - 约束优化问题为：\(\min_\theta R+\lambda T\)，约束 \(D(x,\hat{x})=D_t\)。
  - 用惩罚法转为无约束目标：\(L=R+\lambda_1 P(D,D_t)+\lambda_2 T\)。
- **惩罚函数设计**：
  - 两阶段行为：未达到目标质量时（\(D\ge D_t\)），退化为普通率-失真项 \(\lambda_1 D\)；达到目标后，惩罚继续提升视觉质量。
  - **绝对惩罚**：\(P_{\text{abs}}(D,D_t)=|D-D_t|+D_t\)，对目标两侧对称惩罚。
  - **双线性惩罚**：当 \(D\ge D_t\) 时为 \(D\)；当 \(D<D_t\) 时采用更陡斜率 \(-\lambda'_1/\lambda_1\)，即：
    \[
    P_{\text{bi}}(D,D_t)=
    \begin{cases}
    D, & D\ge D_t,\\
    -\frac{\lambda'_1}{\lambda_1}D+\left(1+\frac{\lambda'_1}{\lambda_1}\right)D_t, & D<D_t.
    \end{cases}
    \]
  - 实验中发现 \(\lambda'_1=2\lambda_1\) 较合适。双线性惩罚在超过目标后更强烈地抑制继续提升保真度。
- **实现特点**：不增加额外复杂度开销；通过惩罚函数显式引导质量达到目标，而非仅靠损失权重隐式权衡。

## 6. 主要结论与发现

- 所提质量约束公式能够在满足目标视觉质量的同时，将码率从感知保真重新分配到机器任务。
- **双线性惩罚最优**：
  - 相对 Baseline：BD-rate 为 \(-29.81\%\)，BD-mIoU 为 \(+5.60\%\)。
  - 相对 JO：BD-rate 为 \(-22.82\%\)，BD-mIoU 为 \(+3.86\%\)。
  - 相对 VTM：BD-rate 为 \(-45.78\%\)，BD-mIoU 为 \(+10.75\%\)。
- **绝对惩罚次之**：
  - 相对 Baseline：BD-rate \(-20.69\%\)，BD-mIoU \(+4.29\%\)。
  - 相对 JO：BD-rate \(-11.32\%\)，BD-mIoU \(+2.13\%\)。
  - 相对 VTM：BD-rate \(-38.44\%\)，BD-mIoU \(+10.29\%\)。
- 固定目标 PSNR 分析表明，在 25–36 dB 的较宽目标范围内均可获得码率节省；但绝对惩罚在高目标质量段（如 33–36 dB）相对 JO 出现正 BD-rate，说明其灵活性不足。
- 低码率案例分析：所提方法在约 0.030 bpp 下主动损失约 5 dB PSNR（31.06 dB vs. Baseline 36.49 dB / JO 36.77 dB），但 mIoU 从 33.2%/38.1% 提升到 42.4%，即用可接受感知质量换取显著任务增益。
- 空间分析显示，比特更多分配给车辆、杆、物体边界等任务显著区域，减少分配给道路、天空等均匀区域。
- Latent 分析显示，所提方法 latent 空间规律性更低、熵模型更校准，并将比特预算集中在少数高能量通道。
- 总体结论：在机器编码中显式约束失真目标是可行的，适度惩罚执行能提升任务准确率。
