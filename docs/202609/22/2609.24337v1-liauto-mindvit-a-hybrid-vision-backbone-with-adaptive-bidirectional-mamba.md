## 摘要
尽管基于Mamba的模型在长序列建模方面展现出巨大潜力，但将其适配到视觉任务仍具挑战，因为视觉理解需要局部邻域相关性和多方向空间上下文。本文提出LiAuto-MindViT，一种新颖的混合视觉骨干网络，融合了CNN、Mamba和Transformer的优势。我们设计的核心是自适应双向Mamba（ABM），它通过带有可学习alpha混合的双向选择性扫描，消除了单向SSM的方向偏差，实现了内容自适应的方向融合，且无需穷举多路径路由的开销。为进一步加速推理，我们提出了一种部署友好的重参数化ConvSE（RepConvSE）模块，利用结构重参数化来降低延迟和内存访问开销。大量实验表明，LiAuto-MindViT在图像分类、目标检测和语义分割上达到了最先进性能，同时通过重参数化实现了高效推理。

## Abstract
While Mamba-based models have shown strong potential for long sequence modeling, adapting them to vision is challenging due to the requirement of local neighborhood correlations and multi-directional spatial contexts for visual understanding. In this paper, we present LiAuto-MindViT, a novel hybrid vision backbone that synergizes the strengths of CNNs, Mamba, and Transformers. The core of our design is the Adaptive Bidirectional Mamba (ABM), which eliminates the directional bias of unidirectional SSMs through bidirectional selective scanning with learnable alpha blending, enabling content-adaptive directional fusion without the overhead of exhaustive multi-path routing. To further accelerate inference, we propose a deployment-friendly Reparameterized ConvSE (RepConvSE) module that leverages structural reparameterization to reduce latency and memory access overhead. Extensive experiments demonstrate that LiAuto-MindViT achieves state-of-the-art performance on image classification, object detection, and semantic segmentation while enabling efficient inference through reparameterization.

## 2. 方法论

### 2.1 整体架构

- 采用四阶段层次化结构，逻辑上分为：
  - **Local Extraction Network, LEN**：前两阶段，用 CNN 高效处理高分辨率局部特征；
  - **Global Perception Network, GPN**：后两阶段，用 ABM 与 Transformer 建模全局上下文。
- 阶段间使用 **3×3、stride=2 卷积**下采样，构建特征金字塔。
- 微观块遵循 MetaFormer 结构：
  - \(\hat{X} = \text{TokenMixer}(\text{Norm}(X)) + X\)
  - \(Y = \text{ChannelMixer}(\text{Norm}(\hat{X})) + \hat{X}\)
- 不同阶段实例化不同 TokenMixer / ChannelMixer：
  - Stage 1：RepMixer + ConvFFN；
  - Stage 2：RepMixer / RepConvSE；
  - Stage 3：ABM；
  - Stage 4：LaPE-Transformer / MSA。
- 模型变体：
  - **T**：12.6M 参数；
  - **S**：36.8M 参数；
  - **B**：82.5M 参数；
  - 嵌入维度为 \(\{C, 2C, 4C, 8C\}\)。

### 2.2 Adaptive Bidirectional Mamba, ABM

- **核心思想**：基于 Mamba2 的 Structured State Space Duality 公式，保留高效因果选择性扫描，同时通过双向扫描消除单向 SSM 的方向偏置。
- **双向扫描**：
  - 将 SSM heads 均匀分为 forward 组和 backward 组；
  - forward 组按原序列扫描；
  - backward 组反转序列后扫描，再翻转回来；
  - 形式为：
    - \(Y_{fwd} = \text{SSD}(X_f, \Delta_f, A_f, B_f, C_f, D_f)\)
    - \(Y_{bwd} = \text{flip}(\text{SSD}(\text{flip}(X_b), \text{flip}(\Delta_b), A_b, \text{flip}(B_b), \text{flip}(C_b), D_b))\)
- **可学习 alpha 混合**：
  - 不采用简单拼接，而是用轻量投影 \(W_\alpha\) 生成逐 token 混合系数：
    - \(\alpha = \sigma(W_\alpha X)\)
  - 混合方式：
    - \(\hat{Y}_{fwd} = \alpha \odot Y_{fwd} + (1-\alpha) \odot Y_{bwd}\)
    - \(\hat{Y}_{bwd} = (1-\alpha) \odot Y_{fwd} + \alpha \odot Y_{bwd}\)
  - 最后沿 head 维拼接。
  - \(W_\alpha\) 初始化为零，使训练初期 \(\alpha=0.5\)，保证双向贡献均衡、优化稳定。
- **位置信息补偿**：在每个 ABM 块中的 attention 和 FFN 前加入 **3×3 深度可分离卷积 CPE**，提供隐式相对位置信息，补偿 1D 序列化造成的空间结构损失。

### 2.3 Reparameterized ConvSE, RepConvSE

- **目标**：替代 ConvFFN，降低推理延迟和内存访问开销，同时增强通道选择能力。
- **设计要点**：
  - 去除 depthwise 卷积，改用标准卷积与 identity 分支；
  - 将激活函数移到模块末端；
  - 引入可学习的 vector-relative SE 模块，置于 skip connection 前；
  - 第一个 SE 提升扩展中间表示的选择性，第二个 SE 促进残差融合和下游表示。
- **公式流程**：
  - \(Y = \{[(X * K_1 + b_1) * K_2 + b_2] \odot F_1(v_1) * K_3 + b_3\} \odot F_2(v_2) + X\)
  - 推理时可重参数化为：
    - \(K_{Rep} = K_1 * K_2 \odot F_1(v_1) * K_3 \odot F_2(v_2) + I\)
    - \(b_{Rep} = [(b_1 * K_2 + b_2) \odot F_1(v_1) * K_3 + b_3] \odot F_2(v_2)\)
    - \(Y = X * K_{Rep} + b_{Rep}\)
- **部署策略**：在 LEN 第二阶段的最后 \(N_2/2\) 个块中用 RepConvSE 替换 ConvFFN，深层通道选择更关键。
