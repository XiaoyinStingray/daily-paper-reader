## 摘要
视觉数据正越来越多地由机器视觉系统而非人类观察者所使用。面向机器的图像编码（ICM）在压缩图像时，假设主要观察者是计算机视觉应用，并且人类观察者需要检查或验证其决策。受恰可察觉失真的启发——其将质量设定为人类观察者可接受的最低水平——我们旨在将人类观察到的质量限制在期望水平，目标是用剩余的编码容量来提升机器性能。我们将联合压缩-分割训练重新表述为一个约束优化问题，其中编解码器必须满足预定义的、可接受的目标视觉质量，而任务项则消耗剩余的编码容量。我们通过设计一个惩罚函数来将质量引导至期望目标，从而解决该问题。我们提出两种惩罚函数：绝对值函数和双线性函数，后者在超过目标视觉质量后采用更陡的斜率。实验结果表明，在质量约束下，所提方法相较于无约束的联合率-失真-任务优化实现了 -22.82% 的 BD-rate，相较于简单的率-失真基线实现了 -29.81%，在相同任务性能下展示了比特率降低。同时，编解码器还能以合理误差满足目标视觉质量，并且不增加任何复杂度开销。

## Abstract
Visual data is increasingly consumed by machine-vision systems rather than by human observers. Image Coding for Machines (ICM) compresses images assuming the main observer is a computer vision application and that the human observer needs to inspect or validate the decisions. Inspired by just-noticeable distortion, which sets the quality to the just-acceptable level for human observers, we aim to cap the human-observed quality at a desired level, with the goal of using the remaining coding capacity to improve the machine performance. We recast joint compression-segmentation training as a constrained optimization problem in which the codec must meet a predefined acceptable target visual quality while a task term consumes the remaining coding capacity. We solve this by designing a penalty function to guide the quality to the desired target. We propose two penalty functions, an absolute function and a bilinear function, the latter applying a steeper slope once the target visual quality is exceeded. Experimental results show that, under the quality constraint, the proposed method achieves a BD-rate of $-22.82\%$ over an unconstrained joint rate--distortion--task optimization and $-29.81\%$ over a simple rate--distortion baseline, showcasing bitrate reduction with the same task performance. This is achieved while the codec also meets the target visual quality with a reasonable error and without adding any complexity overhead.

## 1. 核心问题与整体含义

- **研究背景**：图像/视频数据大量由机器视觉系统直接消费，而非人类观察者。面向机器的图像编码（ICM）需要在压缩时兼顾机器任务性能，同时保留人类可检查/验证决策所需的可解码图像。
- **核心矛盾**：传统学习图像压缩（LIC）主要优化 PSNR、MS-SSIM 等面向人眼的保真度指标，但这些指标与下游视觉任务准确率相关性较弱。大量码率可能被花在任务无关的纹理细节上，而任务关键结构反而丢失。
- **研究动机**：受“恰可察觉失真”（JND）启发，人类观察者只需达到“足够好”的质量。超过该质量继续提升保真度会浪费编码容量。作者希望显式限制人眼观察质量，把剩余码率用于提升机器任务性能。
- **核心问题**：在联合压缩-分割训练中，如何显式控制编解码器输出质量，并将从感知保真度中释放出的学习容量重新分配给下游任务，而不是仅通过率-失真-任务损失中的两个拉格朗日乘子隐式权衡质量与任务。

## 2. 方法论

- **总体框架**：将可训练 LIC 编解码器与冻结的下游任务网络耦合。输入图像经编码器得到量化潜变量，再解码为重建图像，送入任务网络。训练时只优化编解码器参数，任务网络冻结但提供可微任务损失。
- **损失组成**：
  - 率损失 \(R\)：量化潜变量在熵模型下的负对数似然。
  - 失真损失 \(D\)：重建图像与原图的 MSE。
  - 任务损失 \(T\)：分割预测的逐像素交叉熵。
- **约束优化建模**：目标是最小化率与任务损失，同时要求 PSNR 达到用户指定目标 \(PSNR_t\)：
  - \(\min R + \lambda T \quad s.t. \quad PSNR(x,\hat{x}) = PSNR_t\)
  - 由于 PSNR 是 MSE 的单调变换，可转换为失真目标 \(D_t = 255^2 / 10^{PSNR_t/10}\)，即约束 \(D(x,\hat{x}) = D_t\)。
- **惩罚法转换**：将约束问题转为无约束目标：
  - \(L = R + \lambda_1 P(D,D_t) + \lambda_2 T\)
  - 其中 \(P\) 为惩罚函数，替代普通失真项。
- **惩罚函数设计**：
  - 两阶段行为：未达到目标质量时（\(D \ge D_t\)）退化为标准率-失真项 \(\lambda_1 D\)；达到目标质量后（\(D < D_t\)）惩罚继续提升视觉质量。
  - **绝对惩罚**：\(P_{abs}(D,D_t)=|D-D_t|+D_t\)，在目标两侧对称惩罚。低码率下 \(\lambda_1\) 较小时可能仍过冲目标。
  - **双线性惩罚**：当 \(D \ge D_t\) 时 \(P=D\)；当 \(D < D_t\) 时使用更陡斜率 \(\lambda'_1\)，将模型推回目标附近。实验中取 \(\lambda'_1=2\lambda_1\) 较合适。
- **与基线区别**：
  - 纯率-失真基线：\(L_{Baseline}=R+\lambda_1 D\)，任务网络只在推理时使用。
  - 无约束联合优化 JO：\(L_{JO}=R+\lambda_1 D+\lambda_2 T\)。
  - 本文方法：用质量惩罚函数替换普通失真项，显式引导质量达到目标，而不是让优化器隐式决定质量水平。
