## 摘要
二次型$N\times N$注意力分数矩阵仍然是扩展Transformer以处理更长输入长度的主要障碍。现有的高效注意力方法通常通过施加稀疏性（使得每个查询仅关注一小部分键）或使用低秩/核技巧（将全局交互压缩到低维表示中）来缓解这一瓶颈。我们提出\emph{ELSAA}，一种高效的低秩与稀疏注意力近似方法。重要的是，ELSAA并\emph{不}将Transformer中学习到的投影或输出矩阵分解为稀疏和低秩因子。相反，在密集投影产生$Q,K,V$后，ELSAA近似诱导出的注意力分数算子本身：稀疏分支捕获选定的高相似性交互，而低秩分支总结弥散的全局交互。由于这两个分支可以在具有非常不同分母质量的支撑集上进行归一化，ELSAA引入了一个分母感知融合项，根据稀疏分支相对于低秩分支的估计注意力质量来缩放稀疏分支。这提供了一个实用的框架，用于在不生成完整二次分数矩阵的情况下构建低秩和稀疏注意力输出，旨在实现更长上下文的训练，同时保留尖锐的token级交互和广泛的上下文混合。

## Abstract
The quadratic $N\times N$ attention score matrix remains a central obstacle to extending Transformers to longer input lengths. Existing efficient attention methods usually reduce this bottleneck by either imposing sparsity, so that each query attends to only a small subset of keys, or by using low-rank/kernel sketches, so that global interactions are compressed into a lower-dimensional representation. We propose \emph{ELSAA}, an efficient low-rank and sparse approximation of attention. Importantly, ELSAA does \emph{not} decompose the learned projection or output matrices of the Transformer into sparse and low-rank factors. Instead, after dense projections produce $Q,K,V$, ELSAA approximates the induced attention score operator itself: a sparse branch captures selected high-similarity interactions, while a low-rank branch summarizes diffuse global interactions. Since the two branches can be normalized over supports with very different denominator mass, ELSAA introduces a denominator-aware fusion term that scales the sparse branch according to its estimated attention mass relative to the low-rank branch. This gives a practical framework for constructing low-rank and sparse attention outputs without materializing the full quadratic score matrix, aiming to enable longer-context training while preserving both sharp token-level interactions and broad contextual mixing.

## 1. 论文的核心问题与整体含义（研究动机和背景）

Transformer 架构的核心是自注意力机制，其计算复杂度为 $O(N^2)$，其中的 $N$ 是序列长度。这一二次瓶颈严重限制了模型处理长上下文的能力。现有的高效注意力方法主要分两类：

- **稀疏方法**：让每个查询只关注少数键（如局部窗口、哈希、聚类等），能保留精确的局部交互，但可能丢失弥散的全局信息。
- **低秩/核方法**：通过压缩特征或地标近似全局交互（如 Linformer、Performer、RACE 等），能以线性复杂度覆盖全局，但会平滑化尖锐的 token‑token 依赖。

两类方法互补，但简单相加会面临两个分支归一化分母不一致带来的尺度错配问题。ELSAA 旨在同时利用稀疏和低秩结构，通过分母感知的融合机制正确组合两条分支的输出，从而在不生成完整 $N\times N$ 分数矩阵的前提下，兼顾局部精确交互和全局上下文混合。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想**：对同一个查询 token，使用一个稀疏分支精确计算高相似度键的注意力，同时使用一个低秩分支在压缩表示中汇总全局上下文，最后通过一个分母感知的乘法因子 $m_{\text{sparse}}$ 将两个分支的输出按比例融合，解决尺度不匹配问题。

**关键技术细节**：

1. **低秩分支：RACE 注意力**  
   - 利用多个哈希表（$L_s$ 个，每个使用 $\gamma$ 个超平面）将键和查询软分配到 $2^\gamma$ 个桶中。  
   - 统计每个桶的键向量和值向量累积量（桶质量 $A^{(\ell)}$、桶值 $B^{(\ell)}$）。  
   - 查询通过读取所有桶的平均摘要得到输出 $O_{lr}$ 和分母代理 $d_{lr}$。  
   - 针对因果（causal）场景，将序列分块，用前缀和分别处理块间和块内贡献，保持线性复杂度。

2. **稀疏分支：sortLSH 精确注意力**  
   - 使用排序类 LSH 对查询和键进行哈希、排序、分组为固定大小的块（块大小 $s$）。  
   - 在同一块内计算精确注意力（假设高相似度对出现在排序后的对角块附近）。  
   - 返回稀疏输出 $O_{\text{sparse}}$ 及其分母 $d_{\text{sparse}}$。  
   - 因果版本采用递归分治结构，将序列二分后递归处理，再合并未来‑过去块的结果。

3. **分母感知的稀疏‑低秩融合**  
   - 对于第 $i$ 个 token，定义缩放因子：
     \[
     m_{\text{sparse},i} = \frac{d_{\text{sparse},i}}{d_{\text{sparse},i} + \lambda_i d_{lr,i} + \varepsilon}
     \]
     其中 $\lambda_i$ 可以是固定值、可学习标量或查询相关函数。  
   - 同时学习两个逐 token 门控 $g_{\text{sparse}}, g_{lr}$（通过一个 MLP + sigmoid 产生）。  
   - 最终输出：
     \[
     O_i = g_{\text{sparse},i} \, m_{\text{sparse},i} \, O_{\text{sparse},i} + g_{lr,i} \, O_{lr,i}.
     \]

**算法流程（非因果版本）**：  
输入隐藏态 $X$ → 投影得 $Q,K,V$ → 运行 RACE 分支得 $(O_{lr}, d_{lr})$ → 运行 sortLSH 分支得 $(O_{\text{sparse}}, d_{\text{sparse}})$ → 计算 $m_{\text{sparse}}$ → 计算门控 → 融合输出 → 乘以输出投影 $W^O$。

## 6. 论文的主要结论与发现

1. **分母感知修正有效**：ELSAA 在所有长上下文任务上一致优于无修正的 Sort Lsh RACE（平均测试准确率 +1.33 pp），尤其在结构化视觉任务上提升更明显。  
2. **任务特性决定分支偏好**：长文本任务（ArXiv、检索）中低秩分支占优；长上下文视觉任务中稀疏分支更重要。ELSAA 能通过门控和 $m_{\text{sparse}}$ 自动适应不同模式。  
3. **精确注意力在极长上下文失效**：Text Retrieval @64K 时 Exactflash 学习失败（准确率≈50%），而 ELSAA 达到 65.34%，说明近似注意力提供了隐式结构先验。  
4. **NIAH 长度外推**：ELSAA 在训练长度 1024 下，既能在短于训练长度（512）上达到 100%（靠低秩分支），也能在极长（65536）上保持 84.2%（靠稀疏分支），而 RACE 长距离崩溃，Sparse LSH 短距离失败。  
5. **因果版本有竞争力**：在因果 ArXiv @64K 上 ELSAA 优于 Exactflash（91.47% vs 87.44%），在 Tiny ImageNet 上接近。

## 7. 优点

- **方法新颖性**：不分解权重矩阵，而是分解注意力算子本身；引入分母感知融合解决了分支尺度错配这一被忽视的问题。
