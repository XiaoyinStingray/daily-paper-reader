# Order Matters: Competition-Guided Query Ordering for RNN-Based Object Detection 

Shengjian Wu 1,2 Li Sun 1,3 ∗ Yu Shangguan 1 Qingli Li 1

## Abstract 

DETR-style detectors use one-to-one bipartite matching during training to assign object queries to ground-truth objects, enabling end-to-end set prediction without non-maximum suppression (NMS). However, without an explicit de-duplication procedure, multiple queries can still produce highly similar hypotheses for the same object, making training unstable and predictions less decisive. Inspired by the se-quential ordering of NMS, we propose DETRNN, a plug-and-play module that turns unordered object queries into a competition-aware sequence for recurrent refine-ment. DETRNN builds an explicit confidence-and-similarity based order from prior predictions, then refines queries with an RNN along this order to model competition inside the decoder. This ordered recurrent refinement reduces redundant predic-tions, stabilizes optimization, and improves final detection accuracy. Experiments on multiple DETR-style detectors show consistent gains with comparable efficiency. Code is available at https://github.com/nigelwoo2008-coder/DETRNN .

## 1 Introduction 

Transformer-based detectors such as DETR [1] unify object detection into an end-to-end set prediction problem. During training, DETR applies one-to-one bipartite matching between object queries and ground-truth objects, which removes post-processing NMS, avoiding manual threshold tuning. Despite this elegant formulation, DETR still suffers from redundant hypotheses, especially in dense scenes (Fig. 1b). Multiple queries can converge to similar regions with close confidence scores, but only one prediction can be matched to each ground-truth object, leaving the others as competing duplicates and slowing convergence. A useful reference point is classical NMS. NMS resolves redundancy via an explicit sequential procedure: it ranks predictions and greedily removes highly overlapping candidates (Fig. 1a). This sequential order is a strong and simple cue for organizing competition among duplicates. However, using NMS as a hard post-processing step is not always ideal: it is non-learnable, can be threshold-sensitive, and may even hurt in some cases. This motivates a different goal: rather than performing NMS as post-processing, we use an explicit competition order to guide learnable decoder refinement and reduce redundancy. In DETR, query interaction is mainly handled by self-attention. Recent analyses (e.g., DAC-DETR [2], OneNet [3]) suggest that self-attention, together with one-to-one matching used during training, plays an NMS-like role by suppressing duplicates over decoders. Yet self-attention is parallel and order-agnostic, and it does not provide an explicit competition order. Therefore, prior work typically injects competition priors by modifying attention patterns or biases, such as easing winner-versus-competitor interaction in EASE-DETR [4] or introducing relation priors in Relation-DETR [5], or by applying decoder-wise NMS to discard redundant queries, e.g., DDQ [6]. While effective, these designs remain within parallel attention and rely on carefully crafted attention modifications or query pruning.

We propose a more direct alternative: use an RNN to refine queries along an explicit competition sequence. RNNs are naturally suited for sequential modeling, but DETR queries have an arbitrary order with no competition cue. To bridge this gap, we introduce DETRNN , which constructs a competition sequence from prior predictions by sorting queries using confidence and similarity under 

Competition-Guided Query Ordering (CGQO), mimicking the ranking-and-grouping behavior of NMS. A learnable RNN-based query interaction then refines queries along this sequence, making redundant competitors easier to suppress (Fig. 1c). As a result, DETRNN improves training stability and detection quality by suppressing duplicates and making the correct prediction stand out. To our knowledge, DETRNN is among the first attempts to use an RNN as the query-interaction module in DETR decoders, enabling redundant predictions to be suppressed during decoding. We validate DETRNN on diverse DETR-family baselines, including Def-DETR++ [7], DINO [8], MS-DETR [9], and recent LoRA-DETR [10]. The consistent experimental gains across these architectures show a practical accuracy–efficiency trade-off. The contributions of this paper are summarized as follows: • We identify query ordering as a missing inductive bias for de-duplication in end-to-end detection, turning redundancy suppression into an explicit sequential refinement problem. • We introduce a plug-and-play ordered recurrent query interaction: CGQO builds a competi-tion order from prediction similarity, and an RNN refines object queries along this order to suppress redundant hypotheses. • Extensive experiments validate CGQO-guided RNN interaction as an effective alternative to decoder self-attention, reducing prediction redundancy and improving AP across diverse detectors with comparable efficiency. 

## 2 Related Work 

2.1 End-to-end Object Detectors 

DETR [1] introduced a transformer-based end-to-end detector, but its high computational cost, slow convergence, and weak small-object performance limit practical use. Def-DETR [7] alleviates these issues with deformable attention. Other query-based detectors, such as Sparse R-CNN [11] and AdaMixer [12], redesign query decoding with learnable proposals, dynamic convolution, or RoI-based feature extraction. Another line improves convergence and matching stability by enriching query supervision. DN-DETR [13] and DINO [8] introduce denoising queries, while Hybrid-DETR [14], MS-DETR [9], LoRA-DETR [10] and related methods [15, 16, 17, 18, 19, 20] expand query groups or use richer GT–prediction matching to provide more positive supervision. Beyond supervision and matching, stage-wise reuse [21, 22], ranking-aware [23], and dynamic-query methods [24, 25, 26] 2improve query propagation, quality, or allocation. These methods improve optimization or query utilization, but they do not explicitly model the order of competition among redundant queries. OneNet [3] points out that NMS-free detection relies on one-to-one supervision to avoid duplicate predictions. DAC-DETR [2] further shows that decoder self-attention plays a key role in redundancy removal by mediating query–query interaction. However, when decoding hundreds of object queries, parallel self-attention may still struggle to focus on close competitors, often requiring many epochs and multiple decoder stages. Recent methods therefore improve de-duplication in two main ways. Some select or prune queries, e.g., filtering salient queries before decoding [27, 28] or applying NMS-style query pruning across decoder stages [6, 29]. Others reshape parallel query interaction with spatial/IoU or prediction-aware attention priors [30, 12], and recent competition-aware designs such as Relation-DETR [5], EASE-DETR [4], and Dual-R-DETR (formerly Route-DETR) [31]. Rather than further modifying parallel pairwise attention or pruning queries, we study ordered recurrent query interaction, where an RNN exploits an explicit competition order to suppress redundant hypotheses inside the decoder. 

2.2 Vision RNNs 

Recurrent Neural Networks (RNNs), including LSTM [32] and GRU [33], were originally designed for temporal modeling, and recent variants such as Mamba [34], RWKV [35], TTT [36], and xLSTM [37] further improve efficient long-range sequence modeling. In vision, RNN-style models are often used to process image tokens or enhance feature extractors: Vision Mamba [38] and Vision-RWKV [39] model image tokens sequentially, VMamba [40] explores multidirectional scanning, and Mamba-YOLO [41] integrates SSM blocks into ViTs and FPN. These methods mainly improve visual representations, while DETR’s redundancy handling depends on decoder query interaction. A related detector, Recurrent DETR [42], iterates transformer decoder blocks for variable-size prediction, rather than using RNNs for query interaction. In contrast, DETRNN applies recurrent modeling inside the DETR decoder to refine competition-ordered queries and reduce redundancy. 

## 3 Method 

3.1 Preliminaries DETR -style detectors employ a fixed set of learnable object queries Z = {z1, z 2, · · · , z N } ∈ RN ×d

to produce a set of detection predictions, where each query zi outputs a classification score and a bounding box. Hungarian bipartite matching enforces a one-to-one assignment between predictions and ground truth objects, enabling end-to-end detection without explicit NMS. In practice, however, multiple queries may converge to highly overlapping hypotheses around the same object with similar confidence, creating redundant competitors. Since only one prediction can be matched to each ground truth, small score fluctuations may switch the matched prediction during training, making supervision noisy and slowing convergence, especially in crowded scenes. To mitigate this issue, decoder self-attention is used for query–query interaction. Recent analyses (DAC-DETR [2], OneNet [3]) suggest that self-attention, together with one-to-one matching, im-plicitly plays an NMS-like role by gradually suppressing duplicates. Nevertheless, self-attention remains parallel and order-agnostic, and does not explicitly organize competitors into a sequential competition procedure. 

Recurrent Neural Networks (RNNs) are designed to process sequential data by maintaining hidden states across time steps. Given a sequence x1, x 2, ..., x T , a standard RNN, denoted as 

[ot, h t] = RNN (xt, h t−1), computes the hidden state ht and output ot at time step t as: 

ht = f (Whht−1 + Wxxt + b) ot = Woht (1) where f (·) is a non-linear activation function, e.g., tanh; Wx, Wh and Wo are static weight matrices for the input, the hidden state transition and the output, respectively, with b as a bias term. RNN-style models provide a natural sequential inductive bias by refining representations along an ordered stream. This makes them a suitable candidate for modeling competition in set prediction, provided that the query sequence encodes meaningful competition cues. Given prior predictions from encoder proposals or preceding decoder outputs, Competition-Guided Query Ordering (CGQO) first constructs an explicit competition order among queries. Specifically, queries are ranked by confidence; the top-scoring query is selected as a pivot, and other queries are grouped and reordered by their similarity to the pivot (highly similar competitors are placed nearby). Unlike NMS, CGQO does not discard queries; it only provides ordering cues that the decoder can internalize for de-duplication. 

3.2 Architecture Overview 

Building on the observation above, we aim to make query competition resolvable through an explicit order and learnable sequential refinement inside the decoder. A useful reference point is classical NMS. Beyond being a post-processing rule, its procedure exposes an effective de-duplication ordering cue: it ranks candidates by confidence and organizes close duplicates to follow top-scoring ones. We aim to internalize this ordering cue into the decoder as a learnable refinement process, rather than applying threshold-sensitive post-processing. However, decoder self-attention is parallel and order-agnostic, and does not provide an explicit competition order to exploit. To this end, we propose DETRNN, a plug-and-play sequential refinement module composed of two steps (Fig. 2). First, Competition-Guided Query Ordering (CGQO) converts the unordered query set into an explicit competition-ordered stream based on prior predictions. Then, an RNN-based interaction refines queries sequentially along this order, suppressing redundant competitors more effectively. Overall, DETRNN turns de-duplication into an explicit sequential refinement process inside the decoder. We next detail Competition-Guided Query Ordering (CGQO) and the Bi-RNN refinement module. 

3.3 Competition-Guided Query Ordering 

CGQO is the first step of DETRNN: it converts the unordered query set into an explicit competition-ordered stream using prior predictions (encoder proposals or preceding decoder outputs) (Fig. 2). Unlike post-processing NMS, CGQO keeps all queries and only exposes an ordering cue for the decoder to learn de-duplication end-to-end. In practice, we use a pivot-specific threshold to adapt grouping to local crowding; the rule is given in the paragraph Density-adaptive threshold .

and score vector sref ∈ RC . For every remaining query zi (with bi and si), we compute its similarity to the pivot by combining geometric overlap and semantic agreement:

3.4 Sequential Query Refinement with Bi-RNN 

Given the competition-ordered query stream, we refine queries using an RNN-based interaction module. Self-attention updates all queries in parallel and does not leverage an explicit order. In contrast, an RNN naturally models an ordered stream, so it can directly use the CGQO order to pass suppression signals from strong candidates to their nearby competitors, reducing redundant hypotheses. Formally, let Z = {z1, z 2, · · · , z N } ∈ RN ×d denote the ordered queries produced by CGQO. An RNN processes the sequence step by step: 

[oi, h i] = RNN( zi, h i−1), (4) where hi is the hidden state and oi is the refined output at step i. To strengthen information flow, we adopt a bi-directional design by also processing the reversed sequence and combining the two directions. In practice, we use modern RNN-style blocks (e.g., Mamba [34]) for efficient sequence modeling. As shown in Fig. 2, the Bi-RNN replaces the self-attention sub-layer in the decoder, while cross-attention and FFN remain unchanged, making the module plug-and-play for DETR-family detectors. ## 4 Experiments 

4.1 Settings Datasets. We conduct experiments on MS-COCO 2017 [43] and CrowdHuman [44]. For COCO, we train on train2017 (117K images) and evaluate on val2017 (5K images) using standard mAP. CrowdHuman is a crowded human detection benchmark with heavy occlusions; we also report results on its validation (4.4K images). 

Implementation details. Since implementations of recent detectors can differ substantially, we adapt four widely used baselines for fair comparison: Def-DETR++ [7], MS-DETR [9], DINO [8], and LoRA-DETR [10]. Unless otherwise specified, experiments use the 1 × schedule of 12 epochs and follow the training recipe of Def-DETR++. We use a total batch size of 16, learning rates of 

2 × 10 −5 for the backbone and 2 × 10 −4 for the Transformer encoder–decoder, and a weight decay of 2 × 10 −5. For the sequential refinement module, we instantiate the Bi-RNN with Mamba [34] in most experiments. Module configurations, hyperparameter settings, and sensitivity results are provided in Appendix A–E.

4.3 De-duplication and Training Dynamics 

We verify decoder-internal de-duplication beyond final AP using two complementary checks: a shallow-decoder probe and training-time diagnostics. 

Shallow-decoder probe. Tab. 3 reports a 1-decoder stress test (see Appendix I for settings), where redundancy is strongest because DETR detectors typically rely on multiple decoders to gradually suppress duplicates. We build CGQO from encoder proposals and evaluate the 1st decoder output. DETRNN brings large AP gains (+5.7/+4.6/+3.7) and even outperforms the baseline with NMS. Since NMS mainly removes duplicate predictions, a larger ∆AP indicates more residual redundancy in the outputs. Baselines show large ∆AP (2.4–3.0), while DETRNN reduces it to 0.2–0.9, indicating that far fewer duplicate predictions remain for NMS to remove.

Tab. 6 compares our method with applying NMS under the 1× schedule on CrowdHuman, a crowded benchmark with heavy box overlaps, where NMS becomes sensitive to the IoU threshold. With a higher threshold ( τ =0 .8/0.9), NMS is less destructive but leaves more duplicates, so the gains are limited (typically +0 .1 ∼ +0 .2). Consistency on COCO. Following Tab. 6, Tab. 7 repeats the same NMS-threshold check on COCO. Like CrowdHuman, NMS on COCO provides only marginal gains for the baselines (+0.1–0.2 AP). Our method improves AP by +1.1/+0.5 without relying on post-processing threshold tuning.

4.8 Mechanistic Analysis of CGQO Grouping 

To examine whether CGQO forms object-centered competition groups, we analyze their evolu-tion, composition, and converged structure on the first 1,600 COCO val2017 images using Def-DETRNN++ ( 1×). Fig. 5(a) uses first-epoch checkpoints, while Figs. 5(b,c) use the converged model. 

Early grouping evolution. We measure the pivot-match rate, the percentage of GT objects whose Hungarian-matched query is also the pivot of its CGQO group; a higher rate indicates more reliable pivot selection. As shown in Fig. 5(a), it rises from 40.3% at step 100 to 80.9% at 2K and 83.8% at 4K, showing rapid improvement during early training; its converged value is reported in Fig. 5(c). 

Group composition. For each GT, we define a foreground competitor as a query with box IoU 

≥ 0.5 and GT-class score ≥ 0.05 , and examine the CGQO group containing its Hungarian-matched query. Among all members of this group, 49.10% are competitors only for the target GT, 1.72% for both the target and other GTs, and only 0.51% exclusively for other GTs; the remaining 48.67% are non-competitor queries, as expected since CGQO retains and groups all queries (Fig. 5(b)). Among foreground competitors, 99.01% are associated with the target GT, showing very little cross-object mixing. 

Object-centered grouping. The Hungarian-matched query is the group pivot in 89.24% of cases, indicating reliable pivot selection. The corresponding CGQO group covers 78.85% of the foreground competitors for the same GT, showing that most same-object competitors are grouped together. Across images, the number of groups containing foreground competitors strongly correlates with the number of GT objects (Pearson r = 0 .863 ). These complementary statistics support the object-centered structure of CGQO grouping (Fig. 5(c)). 

## 5 Conclusion 

We introduced DETRNN, which turns de-duplication in end-to-end detection into a learnable sequen-tial refinement process. By constructing a competition-aware query order and refining queries along it with an RNN module, DETRNN suppresses redundant predictions while keeping all predictions end-to-end. To our knowledge, this is among the first attempts to treat de-duplication in set-based detection as a sequential refinement problem inside the DETR decoder. Our results across diverse detectors validate a simple message: order matters—a well-structured competition order turns an unordered set into a meaningful sequence, making sequential models a natural fit for resolving duplicates in end-to-end prediction. ## A Various RNN architectures 

Figure 6 illustrates the three RNN architectures used in our method, each differing in their query interaction mechanisms but all incorporating bidirectional processing to enhance query interactions. ## C Details of Bi-RNN (Mamba) module 

Formulation of SSMs. Originating from the Kalman filter, SSMs are linear time-invariant (LTI) systems that map an input u(t) ∈ R to an output y(t) ∈ R through a hidden state h(t) ∈ RN .Specifically, continuous-time SSMs can be expressed by the following linear ordinary differential equations (ODEs): 

h′(t) = A h(t) + B u (t),y(t) = C h(t), (5) where A ∈ RN ×N , B ∈ RN ×1 and C ∈ R1×N are the weighting parameters.

Various rules can be applied, such as the zero-order hold (ZOH) in equation (6), leveraging continuous-time system properties like resolution invariance and ensuring proper normalization.

IOF is asymmetric and therefore provides a directional overlap cue aligned with the competition order: it measures how much a nearby competitor is covered by a stronger candidate. By injecting IOF-based embeddings into ∆, we condition the SSM discretization on adjacent spatial relations, providing an explicit order-aware spatial prior for query refinement.

To isolate its effect, Tab. 10 removes IOF-PE while keeping CGQO and Bi-RNN unchanged. Without IOF-PE, DETRNN still improves the attention baselines by +1.0 AP on Def-DETR++ and +0.3 AP on MS-DETR. Adding IOF-PE further brings +0.1/+0.2 AP. This shows that IOF-PE is a useful auxiliary spatial cue, but the main improvement does not rely on this conditioning.

F.3 Why CGQO+Mamba Scales 

Although Algorithm 1 is written as a sequential greedy procedure for clarity, only the pivot selection in Lines 5–10 is inherently order-dependent. The dense pairwise similarity all_sim and pivot-wise thresholds are computed once with parallel tensor operations. For each selected pivot, Lines 7–8 read one similarity row and threshold candidate queries in parallel on GPU, and the final ordering is assembled from compact O(N ) grouping results. Thus, CGQO preserves the greedy ordering semantics while keeping the expensive pairwise and per-query operations GPU-resident. CGQO still has O(N 2) pairwise similarity, but it operates on low-dimensional inputs: 4-d boxes for IoU and 80-d class scores for cosine similarity. This gives it a much smaller constant than self-attention over 256-d query features, which forms and normalizes an N ×N attention map. Mamba further scales gently with N due to its linear state-space computation. Together, these design choices improve memory scaling and prevent query ordering from becoming a bottleneck at large N .

Recent competition-aware DETR variants differ not only in how they model query competition, but also in many recipe-level components, such as auxiliary one-to-many supervision, dense/distinct query selection, cross-attention design, training-only branches, loss function and baseline-specific training settings. Integration rule. For the +Ours rows, we remove the decoder-wise competition-specific self-attention/pruning operations and use standard self-attention in those stages, while applying DETRNN (CGQO + Bi-RNN) only at the last decoder stage. ## O Alternative Order-Aware Interaction Modules 

To examine how broadly the CGQO order can be exploited, we compare Bi-RNN with several alternative order-aware interaction mechanisms on DINO/R50/ 1×, while keeping CGQO fixed. Uni-RNN processes the ordered queries in one direction; rank-bias attention injects their relative CGQO ranks into self-attention as bias; causal attention restricts attention according to the query order; and 1D convolution aggregates local neighbors along the ordered sequence. All four alternatives improve over the self-attention baseline, showing that the CGQO order can benefit different order-aware interaction mechanisms. Bi-RNN achieves the highest overall AP and AP 50 with a comparable parameter count, supporting its use as our default design. 

## P Limitations, Future Directions, and Broader Impact 

Limitations. CGQO uses a discrete, non-differentiable, hand-designed grouping rule rather than a learned ordering objective, and therefore depends on the quality of preceding predictions. DETRNN is designed for late-stage refinement, and its gains can be smaller on already strong or competition-aware baselines. Our evaluation does not cover some recent detector families such as RT-DETR and D-FINE, while extreme cases including very large or chain-structured competition groups and unusual query distributions remain insufficiently explored. 

Future directions. CGQO is not tied to box IoU and only requires a pairwise similarity measure, allowing extensions such as mask IoU for instance segmentation or task-specific similarities for 3D and video detection. Its favorable large-query memory and runtime scaling also motivates further study in dense detection settings such as remote-sensing imagery. 

Broader impact. DETRNN may benefit applications such as autonomous perception and assistive vision, while also inheriting general object-detection risks including privacy-sensitive surveillance and biased deployment.
