## 摘要
神经视频编解码器主要从 RGB 帧中提取运动与时间上下文，这为来自互补时间观测的跨模态引导留下了空间。事件流通过记录帧间亮度变化可以提供此类观测。在本工作中，我们提出事件引导的神经视频编解码器（ENVC），利用编码器和解码器共享的事件来提升 RGB 压缩效率。在运动编码方面，ENVC 构建事件引导的运动先验，并对剩余运动残差进行编码。在帧编码方面，事件条件预测器提供多尺度特征，用于门控时间上下文细化。为支持在标准视频数据集上进行训练和评估，我们合成配对的 RGB-事件数据，并通过与真实事件的比较评估其预测效用。在六个基准上，相对于 DCMVC，ENVC 在使用 PSNR-RGB 时平均节省 39.13% 的 BD-rate，在使用 LPIPS 时平均节省 67.63% 的 BD-rate。进一步分析表明，我们的增益在大运动序列上仍然存在，并且 ENVC 能够有效学习整合事件信息。这些结果展示了事件作为互补模态在降低 RGB 编码码率方面的潜力。我们的模型和代码见 https://github.com/kjungwoo03/ENVC。

## Abstract
Neural video codecs derive motion and temporal contexts mainly from RGB frames, leaving room for cross-modal guidance from complementary temporal observations. Event streams can provide such observations by recording brightness changes between frames. In this work, we propose an Event-guided Neural Video Codec (ENVC) that uses events shared by the encoder and decoder to improve RGB compression efficiency. For motion coding, ENVC forms an event-guided motion prior and codes the remaining motion residual. For frame coding, an event-conditioned predictor supplies multi-scale features for gated temporal context refinement. To support training and evaluation on standard video datasets, we synthesize paired RGB-event data and assess its predictive utility through comparisons with real events. Across six benchmarks, ENVC achieves average BD-rate savings of 39.13% using PSNR-RGB and 67.63% using LPIPS relative to DCMVC. Further analyses show that our gains persist on large-motion sequences and that ENVC effectively learns to integrate event information. These results demonstrate the potential of events as a complementary modality for reducing the RGB coding rate. Our model and code are available at https://github.com/kjungwoo03/ENVC.

## 1. 核心问题与整体含义

- **研究背景**：视频占据网络流量很大比例，神经视频编解码器（NVC）通过端到端率失真优化学习运动与残差编码，条件编码方法利用已解码信息构建时间上下文，性能已优于传统编解码器。
- **核心痛点**：现有 RGB-only 框架的时间上下文仅依赖已解码帧和传播特征。在运动模式多样或长预测链场景下，预测可靠性下降、重建误差累积，需要更多 RGB 信息才能维持重建质量。
- **研究动机**：事件流异步记录帧间亮度变化，具备微秒级时间分辨率和高动态范围。作者提出：互补的帧间变化观测能否改进时间上下文、降低 RGB 码率？
- **整体含义**：这是首次将共享事件作为时间侧信息用于 RGB 视频压缩，探索事件作为互补模态降低 RGB 编码码率的潜力。

## 2. 方法论

### 核心思想
- 编码器与解码器共享事件流 $E_{t-1:t}$，双方用其构建时间上下文；码流额外携带当前帧 RGB 信息以提升重建质量（区别于 Fig.1b 的事件直接重建设定）。
- 整体框架基于 DCVC-DC 和 DCMVC 的条件编码框架，包含四个关键模块：EFP、RMC、ECR、PCF。

### 关键技术细节
- **事件条件帧预测器（EFP）**：
  - 基于 VFPSIE 骨干网络，事件表示为 10 个时间 bin 的有符号体素网格 $V_t \in \mathbb{R}^{10\times H\times W}$。
  - 输入 $\hat{X}_{t-1}$ 和 $V_t$，输出帧预测 $P_t$ 和多尺度事件条件上下文 $\{C^{E,s}_t\}_{s=0}^2$（分辨率 ×1、×1/2、×1/4）。
  - 图像与事件分别编码，经跨模态注意力由粗到细解码估计光流并合成 RGB 帧，再与前向 warp 参考帧融合。

- **残差运动编码（RMC）**：
  - 事件运动估计器 $\mathcal{M}_E$（编解码端均运行）与当前帧运动估计器 $\mathcal{M}_X$（仅编码端）分别计算 $m^E_t$ 和 $m^X_t$。
  - 编码运动残差 $\Delta m_t = m^X_t - m^E_t$，重建运动为 $\hat{m}_t = m^E_t + \Delta\hat{m}_t$。
  - 运动熵模型使用超先验和前一重建运动隐变量。

- **事件引导上下文细化（ECR）**：
  - **参考特征对齐**：由传播解码特征 $C^R_{t-1}$ 构建多尺度参考特征，用 $\hat{m}_t$ 反向 warp 对齐；×1 尺度使用偏移多样性进一步细化。
  - **门控多尺度事件注入**：$C^{A,s}_t = C^{R,s}_t + G^s_t \odot A^s(C^{E,s}_t)$，其中 $A^s$ 为零初始化特征适配器，$G^s_t$ 为单通道 sigmoid 门控图。
  - **预测引导上下文融合（PCF）**：用 $P_t$ 提取特征，通过 DCMVC 的 base/detail 融合模块细化 ×1 上下文。

- **帧编码与优化**：
  - 使用 DCVC-DC 的条件帧编解码器，条件为 $\{C^s_t\}_{s=0}^2$，×1/4 上下文为熵模型提供时间先验。
  - RGB 编码码率 $R_t = R(\hat{y}^m_t) + R(\hat{z}^m_t) + R(\hat{y}_t) + R(\hat{z}_t)$。
  - 率失真损失 $L_{RD,t} = R_t + \lambda D(X_t, \hat{X}_t)$。

- **合成 RGB-事件数据构建**：
  - 用 Super-SloMo 时间稠密化（目标 200 fps），转 8-bit 灰度并分配时间戳。
  - 用 DVS-Voltmeter 事件模拟器生成异步事件。
  - 按原始帧时间戳分区得到 $E_{t-1:t}$，形成 $(X_{t-1}, E_{t-1:t}, X_t)$ 编码区间。

## 3. 实验设计

### 数据集与场景
- **训练**：Vimeo-90K septuplet 序列配对合成事件；级联训练使用 9,220 训练片段和 106 验证片段（各 32 帧）。
- **评估**：UVG、MCL-JCV、HEVC Classes B/C/D/E 六个标准基准，使用合成事件；额外在 MCML-4K（4K 分辨率）评估。
- **真实事件验证**：HS-ERGB（15 条测试序列）和 BS-ERGB（17 条验证序列），对比真实与合成事件。

### Benchmark 与对比方法
- 默认评估前 96 帧，intra period 为 32；I 帧使用 DCVC-DC 预训练帧内编解码器。
- **对比方法**：DCVC、DCVC-TCM、DCVC-DC、DCVC-FM、DCMVC、DCVC-RT。
- **评价指标**：PSNR-RGB、LPIPS、PSNR-Y、MS-SSIM；用 BD-rate 相对 DCMVC 汇总。

### 主要实验组
- 六个基准的 RD 性能对比（PSNR-RGB、LPIPS、PSNR-Y、MS-SSIM）。
- 事件门控分析（门激活值、RMS 比值、常数门干预）。
- 运动幅度影响（序列级和帧级运动四分位）。
- 更长 intra period 分析（32/64/96/192 帧 GOP）。
- 复杂度分析（参数量、编解码 FPS）。
- 事件压缩敏感性分析（G-PCC 压缩，不同质量因子 $q_E$）。
- 真实事件泛化实验。
- 序列级增益与失败案例分析。
- 比特分配分析（运动/帧编码/帧内码率贡献）。
- 事件对应性干预实验（lag、时序/空间 shuffle、zero event）。

## 4. 资源与算力

- **训练硬件**：4 张 NVIDIA A100-SXM4-40GB GPU。
- **训练策略**：五阶段渐进训练（先训练 EFP/EME，再训练 RMC，再训练上下文细化与条件帧编解码器，再联合优化，最后级联扩展到长序列）。
- **优化设置**：AdamW，weight decay 0.01；λ ∈ {85, 170, 380, 840}；帧权重 (0.5, 1.2, 0.5, 0.9)。
- **推理复杂度**（RTX 3090，1920×1080 UVG Beauty）：
  - ENVC：33.52M 参数，编码 0.323 FPS，解码 0.386 FPS。
  - 对比 DCMVC：21.02M 参数，编码 1.061 FPS，解码 1.208 FPS；DCVC-RT 可达 57.221/51.198 FPS。
- **训练时长**：文中未明确说明具体训练时长（小时/天数），仅说明使用 FRB 和级联训练降低内存消耗。

## 5. 实验数量与充分性

### 实验规模
- **六个标准基准**上的完整 RD 曲线（PSNR-RGB、LPIPS、PSNR-Y、MS-SSIM 四套指标）。
- **额外数据集**：MCML-4K 4K 分辨率验证。
- **真实事件数据集**：HS-ERGB 和 BS-ERGB 共 32 条序列。
- **多组消融/分析实验**：
  - 门控分析（12 序列，Q1，15 P 帧）。
  - 常数门干预（4 序列，G=0 和 G=1）。
  - 运动幅度分析（30 条 MCL-JCV 序列，帧级四分位）。
  - intra period 分析（7 条 UVG 序列，4 种 GOP 长度）。
  - 事件压缩敏感性（7 条 UVG 序列，多种 $q_E$）。
  - 事件对应性干预（13 序列，6 种条件）。
  - 比特分配分析（7 条 UVG 序列，按事件数分块）。
  - 序列级失败案例分析（53 条序列）。

### 充分性与公平性评估
- **充分性**：实验覆盖广泛，包含多数据集、多指标、多消融维度，对方法机理（门控、事件对齐、运动幅度）做了深入分析，较充分。
- **公平性**：
  - 所有对比方法在相同数据集和评估协议下测试。
  - 事件传输成本被视为固定开销，报告的是额外 RGB 编码成本，设定合理。
  - 但对比方法（如 DCVC-RT）未使用事件信息，属于跨模态对比而非同构对比。
  - 主要实验基于合成事件，与真实场景存在域差距。
  - 部分分析（如门控干预）作者承认不能完全隔离空间变化效应。

## 6. 主要结论与发现

- **RD 性能**：在六个基准上相对 DCMVC 平均节省 **39.13% PSNR-RGB BD-rate** 和 **67.63% LPIPS BD-rate**；PSNR-Y 节省 53.51%，MS-SSIM 节省 40.00%。
- **大运动序列有效**：序列级大运动组节省 56.60%，小运动组 47.96%；帧级最高运动四分位仍节省 65.9%。
- **事件确实被有效利用**：
  - 门控平均激活值（0.373/0.140/0.130）远低于初始化 0.982，模型学会衰减适配器输出。
  - 常数门干预（G=0 或 G=1）导致 PSNR 下降 2.30–3.89 dB，说明学习到的调制对重建至关重要。
  - 事件对应性干预（lag、shuffle）导致 PSNR 下降 0.72–5.16 dB，bpp 上升 2–14 倍，证明模型利用了事件与目标帧的时空对应关系。
- **比特分配**：运动码率降低 67.9%，帧编码码率降低 39.8%；有事件区域（≥16 事件/块）占 35.4% 块但贡献 69.6% 帧隐变量比特节省。
- **局限场景**：低活动序列（如 HEVC-E）PSNR-RGB 增益较小（7.76%），但 LPIPS 增益仍显著（51.60%）；Jockey 序列出现正 BD-rate（+56.6%），但 LPIPS 仍为 -52.4%。
- **真实事件泛化**：ENVC 可零微调应用于真实事件，但性能低于合成事件，存在域差距。
- **事件压缩敏感性**：坐标量化导致空间结构破坏（$q_E=0.5$ 时占用像素降至 53.4%，相关仅 0.396），RGB 质量下降 4.20 dB。

## 7. 优点

- **新颖的跨模态思路**：首次将共享事件作为时间侧信息用于 RGB 视频压缩，区别于事件直接重建的设定，兼顾重建保真度与编码效率。
- **模块化设计清晰**：EFP、RMC、ECR、PCF 分工明确，事件引导的运动先验 + 残差编码 + 门控上下文注入形成完整闭环。
- **合成数据管线合理**：通过时间稠密化 + 事件模拟生成配对数据，并系统评估了合成事件与真实事件在统计特性和预测质量上的可比性。
- **实验分析深入**：
  - 门控分析、常数门干预、事件对应性干预多角度验证事件利用机制。
  - 运动幅度、intra period、比特分配等分析揭示方法适用边界。
  - 失败案例与事件压缩敏感性分析诚实且有价值。
- **多指标验证**：PSNR-RGB、LPIPS、PSNR-Y、MS-SSIM 一致显示增益，降低单一指标偏差风险。
- **开源**：模型与代码已公开。

## 8. 不足与局限

- **计算复杂度高**：33.52M 参数，编解码仅 0.323/0.386 FPS，远慢于 DCMVC（1.061/1.208 FPS）和 DCVC-RT（57/51 FPS）。编解码两端均需运行 EFP 和 EME，增加时延，实用性受限。
- **真实事件域差距**：训练于合成事件，真实事件下 RGB 码率更高、质量更低，泛化未完全迁移。
- **事件压缩敏感**：坐标量化会破坏事件空间结构，当前 checkpoint 对压缩事件敏感，需 compression-aware 训练。
- **低活动场景增益有限**：HEVC-E 上 PSNR-RGB 仅节省 7.76%，I 帧占码率比例高（56.2%）稀释了 P 帧收益。
- **个别序列失败**：Jockey 序列整体 BD-rate 为正（+56.6%），复杂运动、遮挡和重复纹理是潜在原因，但作者未完全隔离归因。
- **合成事件依赖**：主要实验基于合成事件，虽经真实事件对比验证，但合成事件更密集（×1.54/1.59），与真实分布存在差异。
- **事件编码未联合优化**：事件传输成本被视为固定开销，未探索 RGB-事件联合压缩，跨模态冗余未被充分利用。
- **门控干预实验局限**：G=0 仅禁用门控注入分支，其他事件通路仍活跃，无法完全隔离空间变化效应。
