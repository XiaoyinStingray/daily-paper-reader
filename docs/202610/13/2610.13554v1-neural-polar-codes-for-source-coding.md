## 摘要
本文提出了一种利用极化码进行无损和有损信源压缩的数据驱动方法。经典极化信源编码能够以低复杂度为二元无记忆信源达到基本极限。然而，对于未知的具有记忆的 q 元信源，连续消除（SC）译码需要显式信源模型，并且计算上可能过于昂贵。我们给出了解析 SC 递推，并表明精确实现的计算复杂度随字母表大小呈二次增长、随状态空间规模呈三次增长。为克服这些局限，我们开发了直接从数据训练的神经极化译码器，以近似合成极化坐标的条件分布，而无需显式信源模型。学习到的分布能够估计熵率、互信息和率失真函数，并支持显式极化压缩方案。对于无损压缩，我们识别高熵极化坐标，并利用学习到的 SC 递推重建其余坐标。对于有损压缩，我们将神经极化译码器与神经测试信道结合，以估计并优化互信息-失真权衡，并构造显式有损极化码。我们还将该框架扩展到具有译码器边信息的 Wyner-Ziv 压缩，通过学习条件极化分布和重建映射来实现。在无记忆信源、有记忆信源和真实基因组数据上的实验表明，当解析 SC 译码器可用时，学习到的译码器与其高度吻合；而当传统方法计算不可行或信源模型不可用时，学习到的译码器仍然适用。

## Abstract
This paper presents a data-driven approach to lossless and lossy source compression using polar codes. Classical polar source coding achieves fundamental limits with low complexity for binary memoryless sources. However, for unknown q-ary sources with memory, successive-cancellation (SC) decoding requires an explicit source model and can be computationally prohibitive. We present analytical SC recursions and show that exact implementations scale quadratically with alphabet size and cubically with state-space size. To overcome these limitations, we develop neural polar decoders trained directly from data to approximate conditional distributions of synthetic polar coordinates without requiring an explicit source model. These learned distributions enable estimation of entropy rates, mutual information, and rate-distortion functions, and support explicit polar compression schemes. For lossless compression, we identify high-entropy polarized coordinates and reconstruct the remaining coordinates using the learned SC recursion. For lossy compression, we combine neural polar decoders with a neural test channel to estimate and optimize the mutual information-distortion tradeoff and construct an explicit lossy polar code. We also extend the framework to Wyner-Ziv compression with decoder side information by learning conditional polarized distributions and a reconstruction mapping. Experiments on memoryless sources, sources with memory, and real genomic data show that the learned decoders closely match analytical SC decoders when available and remain applicable when conventional methods are computationally infeasible or the source model is unavailable.
