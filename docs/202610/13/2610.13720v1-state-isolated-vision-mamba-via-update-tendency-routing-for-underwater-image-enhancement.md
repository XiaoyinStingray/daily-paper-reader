## 摘要
Vision Mamba 最近作为一种高效替代卷积和基于 Transformer 的架构而出现，它通过循环状态演化建模长程空间依赖。现有研究主要改进 token 序列化、扫描策略或专家路由，但在很大程度上忽略了一个状态层面的问题：应如何组织循环状态以用于空间异质的视觉恢复？在本文中，我们表明，迫使具有异质更新行为的 token 循环修改共享隐藏状态会导致持续的跨内容干扰，我们将其称为“State Contention”。我们进一步认为，有效的循环建模应根据 token 兼容性而非 token 排序来组织状态演化。基于这一观察，我们引入“State Isolation”，一种面向 Vision Mamba 的新循环状态组织原则：具有兼容状态更新倾向的 token 在独立的循环状态流中演化。为实例化这一原则，我们提出 IsoMamba，一种 Δ 引导的架构，它构建模型内在的更新表示，通过无标签聚类发现更新兼容的 token 组，并按照“聚类—路由—隔离”（cluster–route–isolate）范式将它们路由到隔离的 Mamba 专家。此外，我们开发了一种动态通道重加权目标，以补偿水下图像中波长相关的重建难度。大量实验表明，IsoMamba 在多个水下图像增强基准上持续取得最先进性能，同时提供更干净的隐藏状态响应，验证了状态隔离循环建模的有效性。

## Abstract
Vision Mamba has recently emerged as an efficient alternative to convolutional and Transformer-based architectures by modeling long-range spatial dependencies through recurrent state evolution. Existing studies primarily improve token serialization, scanning strategies, or expert routing, yet largely overlook a state level question question: how should recurrent states be organized for spatially heterogeneous visual restoration? In this paper, we show that forcing tokens with heterogeneous update behaviors to recurrently modify a shared hidden state leads to persistent cross-content interference, which we term \textbf{State Contention}. We further argue that effective recurrent modeling should organize state evolution according to token compatibility rather than token ordering. Based on this observation, we introduce \textbf{State Isolation}, a new recurrent state organization principle for Vision Mamba,tokens with compatible state-update tendencies evolve within independent recurrent state streams. To instantiate this principle, we propose \textbf{IsoMamba}, a $Δ$-guided architecture that constructs model-intrinsic update representations, discovers update-compatible token groups through label-free clustering, and routes them to isolated Mamba experts following a \textbf{cluster--route--isolate} paradigm. In addition, we develop a dynamic channel-wise reweighting objective to compensate for wavelength-dependent reconstruction difficulty in underwater images. Extensive experiments demonstrate that IsoMamba consistently achieves state-of-the-art performance on multiple underwater image enhancement benchmarks while providing cleaner hidden state responses, validating the effectiveness of state isolated recurrent modeling.
