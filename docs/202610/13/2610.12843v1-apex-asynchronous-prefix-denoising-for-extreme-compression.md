## 摘要
更少的潜在 token 有望带来更廉价的扩散模型。然而，激进的潜在压缩会造成重建-生成困境：增加通道数能改善重建，却会让生成变得更困难。我们提出 APEX，即用于极端压缩的异步前缀去噪（Asynchronous Prefix denoising for EXtreme compression），它将层次化潜在空间与跨通道组的异步去噪相结合。我们的自编码器将通道前缀按从结构到细节的顺序排列，而一个共享去噪器在错开的局部时间上生成它们，且不增加 token 数。在 ImageNet-512 上，APEX 在 64× 和 128× 压缩下、每个评估的通道数上都优于现有方法。在训练和引导采样计算量匹配的情况下，它在每个评估预算下也优于 256-token 模型，并且在计算量更低时增益更大。代码见 https://daviddinkevich.github.io/APEX。

## Abstract
Fewer latent tokens promise cheaper diffusion. Yet aggressive latent compression creates a reconstruction-generation dilemma: adding channels improves reconstruction but makes generation harder. We introduce APEX, short for Asynchronous Prefix denoising for EXtreme compression, which pairs a hierarchical latent space with asynchronous denoising over channel groups. Our autoencoder orders channel prefixes from structure to detail, while one shared denoiser generates them at staggered local times without adding tokens. On ImageNet-512, APEX outperforms existing methods at every evaluated channel count under 64x and 128x compression. At matched training and guided sampling compute, it also outperforms a 256-token model at every evaluated budget, with larger gains at lower compute. Code is available at https://daviddinkevich.github.io/APEX.

## 1. 核心问题与整体含义

- **背景**：现代扩散模型普遍采用 Transformer，注意力开销随 token 数二次增长。潜在扩散（Latent Diffusion）通过将图像压缩到更小的空间网格来降低该开销，而**更强的空间压缩意味着更少的 token**。
- **两难困境**：为了在网格缩小时保持重建质量，通常需要增加 latent 通道数，但这会产生越来越宽的 latent。这触发了已被广泛证实的**重建-生成困境（reconstruction-generation dilemma）**：增加通道能保留更多图像特定信息（精确纹理、局部细节），降低重建误差，但同时增加了扩散模型必须生成的信息量，使生成更难。
- **两难的本质**：标准潜在扩散面临糟糕的取舍——用较少通道牺牲重建质量，或用更多细节牺牲生成质量。现有方法通过限制 latent 信息或引入预训练语义结构来缓解，但最接近的结构化 latent 方法（DC-AE 1.5）仍在**共享时间步**下对每个保留前缀去噪，在 128× 压缩（512² 图像 → 4×4 网格、仅 16 token）下问题尤为严重。
- **整体含义**：APEX 的目标是**在不增加额外信息瓶颈的前提下**，通过改变通道的组织方式与生成方式，让极端空间压缩在潜在扩散中真正具有竞争力，把高压缩从"每步加速"变成"质量-计算优势"。

## 2. 方法论

### 核心思想
- 将层次化潜在空间与**跨通道组的异步去噪**结合：把生成分解为**结构生成 → 条件细化**，粗结构从头生成，精确纹理在场景建立后更容易预测。
- 关键点：异步沿**通道维度**进行，**不增加 token 数**。

### 组件一：分辨率感知的自编码器（结构到细节排序）
- 将 latent 划分为通道块并构成累积层级：
  - `z = [b0‖b1‖…‖bL-1]`，累积前缀 `z(ℓ) = [b0‖…‖bℓ]`，通道数 `Cℓ = Σ dk`，空间网格不变。
- 训练时均匀采样一个 level `ℓ`，保留其累积表示，**将后续通道块置零**；共享解码器输出全分辨率图像，但重建与目标都被 resize 到该 level 分配的分辨率后再计算损失。
- 结构到细节启发式：低通道数时，约 4× 累积通道对应 2× 目标分辨率边长；较大宽度时引入中间 level 避免 refinement 组过大，目标分辨率单调递增至全分辨率。
- 命名约定：如 `f64c8−32−128` 表示 64× 压缩、累积通道 8/32/128，对应 128²/256²/512² 目标。
- 目的：阻止窄 level 把有限容量花在孤立高频特征上，鼓励早期 level 保留连贯布局与形状。

### 组件二：交错通道扩散（Staggered Channel Diffusion）
- **全局时钟 τ 与局部时间**：每个 level 有局部时间 `tℓ(τ)`，从 1（噪声）单调降到 0（干净），满足 `t0 ≤ t1 ≤ … ≤ tL-1`，保证早期 level 不会比其条件的细化 level 更噪声。
- **三种状态**：unstarted（输入置零）、denoising（按局部时间加噪）、done（干净，作为固定上下文）。
- **等间隔交错（Equal-gap）**：`tℓ(τ) = clip(1 + ℓ·g − τ, 0, 1)`，`τ ∈ [0, 1+(L−1)g]`；第 0 层立即开始，后续每层延迟 g，早期层始终更靠后（更干净）。
- **训练**：从采样密度 `τ ∼ q` 抽时钟，各 denoising block 按标准 flow matching 插值各自加噪；目标函数为加权速度误差 `L(τ) = Σ wℓ(τ)‖v̂ℓ − vℓ‖²`，权重在 denoising 状态外为零、denoising 状态内归一化相等，防止宽细化层因通道多而主导。
- **时钟采样密度**：给 `0 < τ < 1`（L0 去噪区间）分配概率 `pL0`，剩余概率在 `(1, T)` 上均匀；主模型用 `pL0 = 0.9`。
- **推理采样**：将时钟离散化为包含各激活点 `ℓ·g` 的网格；**每一步只用一次共享网络评估服务所有 level**，每个 block 按各自时间增量更新。等间隔调度下增量对 denoising level 均为 `−∆τ`，等价于一次共享 Euler 更新，**每步成本与 flat 模型相同**；新激活的 block 从高斯噪声初始化。
- **DiT 初始化**：b0 对应输入投影行用标准 SiT 初始化，b1…bL-1 对应行初始化为零，模型从 L0-only 生成器平滑起步。
