State-Isolated Vision Mamba via Update-Tendency Routing
for Underwater Image Enhancement
Yan Luo
Laibin Chang
Zefan Feng
Yi’ang Chen
Kui Jiang
Zhengguo Li
Abstract
Vision Mamba has recently emerged as an efficient al-
ternative to convolutional and Transformer-based archi-
tectures by modeling long-range spatial dependencies
through recurrent state evolution. Existing studies pri-
marily improve token serialization, scanning strategies,
or expert routing, yet largely overlook a more funda-
mental question: how should recurrent states be orga-
nized for spatially heterogeneous visual restoration? In
this paper, we show that forcing tokens with heteroge-
neous update behaviors to recurrently modify a shared
hidden state leads to persistent cross-content interfer-
ence, which we term State Contention. We further argue
that effective recurrent modeling should organize state
evolution according to token compatibility rather than
token ordering.
Based on this observation, we intro-
duce State Isolation, a new recurrent state organization
principle for Vision Mamba, where tokens with compat-
ible state-update tendencies evolve within independent
recurrent state streams. To instantiate this principle, we
propose IsoMamba, a ∆-guided architecture that con-
structs model-intrinsic update representations, discovers
update-compatible token groups through label-free clus-
tering, and routes them to isolated Mamba experts fol-
lowing a cluster–route–isolate paradigm.
In addition,
we develop a dynamic channel-wise reweighting objec-
tive to compensate for wavelength-dependent reconstruc-
tion difficulty in underwater images. Extensive experi-
ments demonstrate that IsoMamba consistently achieves
state-of-the-art performance on multiple underwater im-
age enhancement benchmarks while providing substan-
tially cleaner hidden-state responses, validating the effec-
tiveness of state-isolated recurrent modeling. Our code is
available at: https://github.com/kkoucy/IsoMamba.

Introduction
Underwater images suffer from wavelength-dependent ab-
sorption and scattering that accumulate along the line
of sight [23].
Variations in scene depth, illumination,
and water conditions make the resulting degradation spa-
tially non-uniform [1]. Consequently, severely attenuated
regions may require stronger color and contrast correc-
tion, whereas mildly degraded structures should be pro-
cessed more conservatively. Effective underwater image

processing of heterogeneous restoration requirements.
CNN- and Transformer-based methods have signifi-

between computational cost and receptive field [51, 72].
State Space Models (SSMs), particularly Mamba [11],
provide an efficient alternative by propagating informa-
tion over long token sequences with linear complexity.
Vision Mamba methods typically focus on how a two-
dimensional feature grid is serialized, using raster, lo-
cal, semantic, or frequency-aware scanning to improve
information propagation [18, 21, 33]. Recent restoration
approaches further employ multi-expert routing to im-
prove adaptability to diverse degradations [50, 65]. How-
ever, the organization of recurrent state sharing is typ-
ically a consequence of sequence construction or expert
assignment rather than an explicit modeling objective.
Whether tokens that successively modify the same recur-
rent trajectory exhibit compatible state-update behavior
remains largely unexamined. This motivates a state-level
question: which tokens should share the same recurrent
state evolution?
We investigate this question in the context of spa-
tially heterogeneous image restoration.

and group tokens by similarity in this space. The coherent
patterns in Figure 2(d) suggest that these groups capture
structured update behavior without relying on explicit
semantic or spatial criteria. Based on this grouping, we
introduce State Isolation: tokens with similar estimated
update tendencies share recurrent evolution, whereas dif-
ferent groups evolve through separate state streams. This
design is intended to resolve interference between tokens
with dissimilar update behaviors while preserving recur-
rent interaction within each compatible group.

Methodology
2.1
Overview
As illustrated in Figure 3, IsoMamba adopts an asym-
metric U-shaped architecture. The encoder uses Global
MBlocks with four direction selective scanning to estab-
lish image level context, while the decoder employs Iso-
lated MBlocks to reorganize recurrent evolution according
to token-wise update compatibility. At each stage, the
encoder provides the corresponding decoder stage with
two stop-gradient cues: the input-dependent discretiza-
tion signal ∆for update-aware routing and the aggregated
terminal states for global coordination.
Each decoder
stage then performs update-tendency modeling, state-
compatible routing, and isolated recurrent evolution.

2.4
Isolated Recurrent Evolution
Tokens assigned to group k are gathered into a compact
sequence and processed by a dedicated Mamba expert:
Yk = Mambak (Xhw | Mhw = 1) .
(8)
Each expert maintains an independent recurrent state,
allowing tokens with similar estimated update tenden-
cies to evolve within the same stream while isolating dif-
ferent groups. This organization is designed to alleviate
State Contention by preventing dissimilar update regimes
from repeatedly modifying a common recurrent trajec-
tory. The expert outputs are subsequently pushed back
to their original coordinates and merged into the decoder
feature map, preserving spatial correspondence and out-
put resolution.
2.5
Global State Coordination
State isolation improves local adaptivity but may weaken
communication across groups.
We therefore inject a
shared global state into each expert through lightweight
feature-wise modulation.
At each decoder stage, the terminal hidden states from
the four encoder scan directions are aggregated into a
global descriptor Hg. For an expert output Yk, channel-
wise modulation parameters are predicted as
[γ, β] = MLP(sg[Hg]),
eYk = Yk ⊙(1 + γ) + β.
(9)
The same global descriptor is shared across experts, co-
ordinating independently restored regions under a com-
mon image-level context. The final MLP layer is zero-
initialized so that the modulation begins as an identity
mapping.

3.1
Experimental Settings
Datasets. We jointly train IsoMamba from scratch on
the union of the UIEB [32] and LSUI [42] training sets,
containing 800 and 3,502 paired images, respectively.
Evaluation is conducted under both full-reference (FR)
and no-reference (NR) settings. For FR evaluation, we
use 90 images from UIEB, 400 images from LSUI, and
481 images from EUVP [22]. For NR evaluation, we use
45 images from U45 [34], 60 images from C60 [32], and 16
images from SQUID [3]. Following a unified resize-based
protocol, all test images are resized to 256×256 for every
competing method.

Metrics.
For paired benchmarks, we report PSNR,
SSIM, and MSE to measure pixel fidelity and structural
preservation.
For unpaired real-world benchmarks, we
report UCIQE [57], UIQM [40], URanker [17], and CLIP-
IQA [49], which assess underwater-specific visibility, color
naturalness, perceptual quality, and semantic image qual-
ity from complementary perspectives.
Implementation Details. IsoMamba is implemented
in PyTorch 2.4.1 and trained on a single NVIDIA RTX
4090 GPU. We use AdamW with an initial learning rate
of 1 × 10−4 and (β1, β2) = (0.9, 0.999). The network is
optimized for 300K iterations with a batch size of 2, using
cosine annealing for learning-rate decay. Unless otherwise
stated, all ablations are conducted on the UIEB test set
with identical training configurations.
Compared Methods. We compare IsoMamba with
representative CNN-, Transformer-, diffusion-, RWKV-,
and Mamba-based methods, including U-Shape [42], DM-
UIE [47], GUPDM [38], Semi-UIR [20], wMamba [16],
CECF [9], MambaIR [19], WF-Diff [66], HCLR [68], F-
RWKV [67], HINT [70], Concertormer [26], MaIR [31],
EVSSM [25] and DTIUIE[69].

Recurrent State Organization Analy-
sis

Conclusion
This work identifies State Contention as a critical limita-
tion of Vision Mamba for spatially heterogeneous restora-
tion, where tokens with incompatible update require-
ments interfere through a shared recurrent state. We in-
troduce State Isolation and instantiate it with IsoMamba,
which organizes tokens by model-intrinsic update ten-
dency and routes incompatible groups to independent
state streams. Extensive experiments demonstrate that
the gains arise from improved recurrent-state organiza-
tion rather than increased expert capacity.
These re-
sults highlight recurrent-state organization as a comple-
mentary design dimension to token scanning in Vision
Mamba.

Related Work
2.1
Underwater Image Restoration
Recent underwater image restoration methods in-
creasingly view UIE as a joint global and local model-
ing problem: wavelength-dependent absorption shifts
the overall color distribution, while scattering and
depth variation cause spatially varying haze and de-
tail loss [1, 23]. Representative designs show a clear
architectural trend toward balancing these two needs.
PUIE-Net models the ambiguity of paired references
with a conditional VAE, where a global latent code
modulates local convolutional features, so the model
can express multiple plausible enhancement styles
[14].
SGUIE-Net pushes adaptivity further by us-
ing semantic guidance to apply different enhancement
behaviors across regions, but it also introduces re-
liance on segmentation quality under heavy degra-
dation [44].
U-shape Transformer brings stronger
global interaction through self-attention and com-
bines spatial-wise global modeling with channel-wise
fusion for color correction, at the cost of higher com-
pute [42]. WF-Diff separates global tone and local
details in the frequency domain and uses diffusion
to refine high-frequency components, improving per-
ceptual details but adding iterative cost [66]. Most
recently, SS-UIE adopts Mamba-style selective scan-
ning to obtain global context with linear complexity,
aiming at a better speed quality trade-off for high-
resolution inputs [41].
Overall, these advances improve global consistency
and local fidelity, yet the core challenge remains: dif-
ferent clusters within one image can demand incom-
patible restoration behaviors, which motivates archi-
tectures that can adapt their processing more explic-
itly across space.
2.2
SSMs
for
Vision
and
Image
Restoration
State space models (SSMs) have recently re-emerged
as an efficient alternative to attention for long-
range sequence modeling. Mamba introduces input-
dependent selective updates and achieves linear-
time processing, which makes it attractive for high-
resolution vision tasks [11]. Following this line, Vim
and VMamba adapt Mamba to images by serializing
2D features into scan-ordered sequences with multi-
directional scans so that each token can access global
context with linear complexity [35, 71]. Building on
these visual backbones, restoration-oriented designs
such as MambaIR further integrate SSM blocks into
image restoration pipelines and augment the vanilla
scan-based module with local enhancement and chan-
nel attention to better preserve textures and handle
channel redundancy [19].
To better cope with diverse degradations, recent
works start to combine Mamba with mixture-of-
experts (MoE) routing.
Uni-UIR introduces ex-
pert specialization for distinct underwater degrada-
tions and uses a gating module to route features
to the most suitable experts [65].
M2-Restore fur-
ther proposes a CLIP-guided MoE router that fuses
task-conditioned prompts with CLIP-derived seman-
tic priors, and refines routing via cross-modal feature
calibration to select experts for different degrada-
tion types [50]. Beyond routing, several studies also
begin to revisit structural limitations of scan-based
SSMs.
MambaIRv2 equips SSM restoration with
non-causal interactions, moving closer to the bidi-
rectional information mixing of vision transformers
[18]. Spatial-Mamba highlights the spatial-topology
mismatch introduced by 2D-to-1D serialization, and
proposes neighborhood state fusion in the state space
to better preserve spatial structure even under a sin-
gle scan [55].
These developments suggest that improving visual
SSM restoration is not only about stronger routing
1


cues, but also about addressing structural issues in-
duced by serialization and state evolution, which mo-
tivates our design.

Limitations and Future Work
Our method is motivated by the mechanism-level
diagnosis
of
State
Contention,
identifying
that
mechanism-agnostic serialization leads to conflicting
update behaviors. We have substantiated this diag-
nosis through extensive hidden state visualizations
and consistent quantitative improvements, utilizing
the learned ∆as an effective, data-driven proxy for
state isolation. From a theoretical perspective, while
our empirical evidence is robust, formally character-
izing the bounds of error propagation caused by in-
terleaved transitions remains an open frontier for the
SSM community. We believe our findings pave the
way for future work to develop a rigorous mathemat-
ical metric for ”coupling intensity,” linking the scan
order directly to the stability analysis of recursive
update equations. In terms of application, while Iso-
Mamba excels in handling color and haze, its perfor-
mance on motion deblurring (e.g., GoPro) suggests
room for improvement in modeling complex motion
trajectories. Future iterations could explore integrat-
ing motion-aware priors into the clustering mecha-
nism to further broaden the scope of restoration dy-
namics.
