## 摘要
生成式图像压缩在低码率下能产生视觉上合理的重建，然而当码率趋近于零时其行为在很大程度上仍未得到探索。当被推到正常操作码率以下时，代表性编解码器会经历语义崩溃：它们不是优雅地丢失源特定的细节，而是产生畸形或无法识别的内容。我们的分析确定了两个因素。随着码率降低，重建损失在梯度和视觉结果上与语义目标日益冲突，而像素空间和面向重建的VAE扩散模型在语义保持上变得效率更低。在这些发现的指导下，我们提出了RAE-CoD，一种在表示自编码器（RAE）空间中构建的面向压缩的扩散（CoD），它在压缩表示和源表示之间直接对齐，对于256×256图像，仅用16比特就能保持可识别的、自然结构化的内容。我们使用五个视觉基础模型（VFM）和一个盲法视觉-语言模型协议来评估该框架。在MSCOCO-30K上，RAE-CoD在所有评估中脱颖而出。在0.001-0.008 bpp时，相对于最佳竞争对手，它将相对VFM特征MSE和Fréchet距离比率至少降低了25.7%和69.1%。同时，重建的语义可识别性和质量几乎保持不变，而源一致性平滑下降，用向无条件生成的优雅过渡取代了突然的语义崩溃。代码将在 https://github.com/LuizScarlet/RAE-CoD 发布。

## Abstract
Generative image compression produces visually plausible reconstructions at low bitrates, yet their behavior as the rate approaches zero remains largely unexplored. When pushed below normal operating rates, representative codecs undergo semantic collapse: rather than gracefully losing source-specific detail, they produce malformed or unrecognizable content. Our analysis identifies two factors. As the bitrate decreases, reconstruction losses increasingly conflict with semantic objectives on gradients and visual results, while pixel-space and reconstruction-oriented VAE diffusion models become less efficient on semantic preservation. Guided by these findings, we introduce RAE-CoD, a compression-oriented diffusion (CoD) built in a representation autoencoder (RAE) space with direct alignment between compressed and source representations, preserving recognizable, naturally structured content for a $256\times256$ image with as few as 16 bits. We evaluate this framework using five vision foundation models (VFM) and a blinded vision-language model protocol. On MSCOCO-30K, RAE-CoD stands out from all evaluation. At 0.001-0.008 bpp, it reduces relative VFM feature MSE and Fréchet Distance ratio by at least 25.7% and 69.1% over the best competitors. Meanwhile, semantic recognizability and quality of the reconstructions remain nearly constant while source consistency falls smoothly, replacing abrupt semantic collapse with a graceful transition toward unconditional generation. Code will be released at https://github.com/LuizScarlet/RAE-CoD.

## 1. 核心问题与研究动机

- **研究空白**：生成式图像压缩（GAN 先验、扩散先验）在低码率下能合成视觉合理的重建，但现有评测都止步于各方法自报的"最低工作码率"，**从该工作点到 0 bit 之间的区间几乎无人研究**。
- **核心现象——语义崩塌（Semantic Collapse）**：把代表性生成式编解码器推到其正常码率以下时，它们并非优雅地丢失源特定细节，而是产生**畸形、不可识别的内容**：物体变形、显著实体消失、场景结构变得不合理。
- **理论直觉**：按 rate-distortion-perception 权衡，码率趋零时源特定信息必然消失，但输出**本身不必失去语义有效性**——无条件生成解码器仍可采样出可识别物体与合法场景（完美边缘真实性）。理想行为应是：语义可识别性与自然度保持高位，而源一致性平滑衰减。
- **原因分析（两条）**：
  - **重建目标的梯度方向问题**：以预训练一步扩散编解码器 AEIC-ME 为对象，计算 MSE、LPIPS 与 5 个视觉基础模型（CLIP、DINOv2、Inception-v3、SigLIP2、ConvNeXt-v2）余弦相似度目标关于解码器特征的**逐样本梯度余弦**。MSE 与 LPIPS 彼此很少冲突，但与语义目标**近乎正交**，且**码率越低负对齐越频繁**。极端适配实验（仅 MSE / 仅 LPIPS / 仅 CLIP-COS / 组合微调解码器）显示：MSE 偏向模糊、LPIPS 产生结构性伪影，均严重偏离语义监督。
  - **扩散空间的压缩性质问题**：用 DiffC（reverse-channel coding）在同一协议下零样本对比 Pixel-DiT、VAE-DiT、RAE-DiT（同量级 DDT-XL）。Pixel-DiT 失真指标最好、VAE-DiT 在中码率感知保真占优，而**RAE-DiT 语义表示保持效率最高**，码率下降时能更久地维持连贯实体与布局；像素空间与面向重建的 VAE 扩散空间在极低码率下对语义保持无内在优势。

## 2. 方法论：RAE-CoD

### 2.1 核心思想
在**表示自编码器（RAE）的语义空间**中构建面向压缩的扩散模型，用**压缩表示与源表示的直接对齐**取代重建导向监督，把"突变语义崩塌"替换为"向无条件生成的平滑过渡"。

### 2.2 三大组件（图 6）

- **表示潜空间（Representation Latent Space）**
  - 采用 **DINOv3 编码器 + 预训练 RAEv2 解码器**（均冻结）。
  - 聚合中间层 DINOv3 特征（层 {11,13,15,17,19,21,23} 取 patch token 平均并加入最后一层全局均值广播），空间重排并做通道标准化，得到 **1/16 分辨率的干净扩散目标 x₀ ∈ R^(1024×16×16)**。

- **深度压缩潜码编解码器（Deep Compression Latent Codec）**
  - 熵瓶颈比常规神经编解码器**深得多**以支撑极低码率。
  - 像素编码器（Inception 式深度可分离卷积 + 门控通道混合）与冻结表示编码器在 1/16 分辨率拼接 → **主潜变量 y 在 1/32（256×8×8）**，**超潜变量 z 在 1/128（256×2×2）**。
  - 极端码率下 z 的分解模型会占据大部分比特，故对 z 使用 **4-bit（16 项）向量量化码本**，约 0.000244 bpp。
  - 熵模型：标量量化 + **4 步四叉树划分空间上下文 + 高斯熵模型**，分四组空间掩码依次解码。
  - 潜解码器融合 ŷ 与 ẑ，重建 1/16 分辨率的 **codec 条件 c（1152×16×16，256 个 token）**。

- **条件解耦扩散 Transformer（Codec-Conditioned DDT）**
  - 从预训练 RAEv2 DDT 初始化，把类别条件接口**替换为 codec 条件 c**。
  - 噪声表示 token、时间步 token、投影后的条件 token 拼接，经深 transformer 编码器产生低频自条件 c_low；浅而宽的解码器头（x-prediction 重参数化）用 c_low 调制扩散状态并预测干净表示 x̂₀。
  - 规模：编解码器约 **57.2M** 参数，DDT 约 **875.4M** 参数，RAEv2 解码器冻结。

### 2.3 训练策略与损失

- **总损失**：
  - L = λ_rate·R_y + λ_vq·L_VQ + L_FM + λ_repa·L_REPA + λ_aux·L_aux
  - L_FM 为 x-prediction flow matching（x_t = (1−t)x₀ + tϵ）。
  - 早期 REPA 头（接在编码器第 8 块后）对同一目标做第二次 x₀ 预测，即 L_REPA，同时提供内部引导所需的弱预测。
  - **关键新增项 L_aux**：由于 L_FM 与 L_REPA 都经由随机加噪状态回传、在严苛瓶颈下信号模糊，故对条件 c 加**确定性辅助目标**——辅助 MLP 投影 c 后与干净目标 x₀ 计算余弦距离，强制熵受限的 c 保留语义。
  - 超参：λ_repa = 1，λ_vq = 0.25，λ_aux = 0.5。

- **渐进式训练（走向极低码率）**
  - **Stage I**：对预训练 DDT 施加 **rank-32 LoRA**，λ_rate 从 0.1 起，在 30K 迭代间隔上递增至 {2, 12, 16, 24, 32, 48}（学习率 1e-4），避免骤然施加强码率惩罚破坏预训练先验。
  - **Stage II**：从对应 Stage-I 检查点分支，固定 λ_rate ∈ {12,16,24,32,48}，合并 LoRA 权重，**联合微调全部 DDT 参数与编解码器**，每个工作点 100K 迭代（学习率 1e-5）。
  - 优化：AdamW、有效 batch 128、bfloat16 混合精度、EMA decay 0.9995。

- **推理**：z 替换为 4-bit 码本最近邻，y 按超先验预测均值取整；256 个条件 token 在所有扩散步复用；1024×16×16 高斯初始化，**100 步 shifted Euler**（time shift 8），内部引导 x_base + 1.78·(x_full − x_base) 作用于 t∈[0.1, 1]，**关闭 CFG**；最后由冻结 RAE 解码器还原 RGB。码率公式 R = −log₂p(ŷ) + 16/256² bpp。

- **16-bit 极限点**：丢弃主潜变量，仅依赖 16-bit 超潜变量，已足以偏置生成走向大致场景语义；再用**单步 DiffC 反信道编码**额外传约 4 bit（理论估计）约束采样状态，总计约 20 bit（0.000305 bpp）。
