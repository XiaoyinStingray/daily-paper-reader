# Binary Phase Retrieval of Cosine Transforms via Local Curvature Minimization 

Ronald Ogden, Student Member, IEEE, Shwetadwip Chowdhury, Member, IEEE, 

Takashi Tanaka, Senior Member, IEEE, David Fridovich-Keil, Senior Member, IEEE 

Abstract —Cosine transforms see frequent use in image and video compression due to their ease of computation and high energy compaction. This has sparked interest within the optics community in computing cosine transforms optically for com-pression. When imaging in the Fourier plane to capture a cosine transform, one encounters a phase retrieval problem: optical fields have both magnitude and phase, but cameras only capture the magnitude of the field. Cosine transforms restrict the phase retrieval problem to a binary domain as opposed to the unit circle, but general phase retrieval solutions do not leverage this. In this work, we demonstrate that sign errors in phase retrieval for cosine transforms result in a significant increase in the magnitude of the Hessian of the transform at the error. Motivated by this, we develop an algorithm to solve this binary phase retrieval problem by minimizing the curvature of the reconstructed cosine transform. We demonstrate via computational experiments that given the magnitude of the cosine transform of an image, we can consistently reconstruct the original image within a multiscale structural similarity index of 0.95. We show that the solve time grows approximately linearly with the number of pixels solved. 

Index Terms —Cosine transform, Phase retrieval, Quadratic unconstrained binary optimization, Fourier optics.

However, the beam-flooding method relies on precise alignment to achieve interference sufficiently accurate to perform effective phase retrieval. III. O PTIMIZATION ALGORITHM 

QUBOs are known to be NP-hard problems in general [22]. Solve times for such problems using exact techniques like branch-and-bound can grow exponentially with input size, posing an issue in this case where inputs consist of large arrays. In this section, we introduce Algorithm 1, which exploits the structure of cosine transforms of natural images to achieve effective binary phase retrieval quickly. Algorithm 1 functions by 1) Dividing the array g into blocks, 2) Determining a set of connected, high-energy blocks (measured as the squared Frobenius norm of the block), 3) Solving (37) for each block in this high-energy set individually in parallel, and 4) Resolving inter-block sign discrepancies via a related but far lower-dimensional QUBO. The decomposition of g enables the binary solver to operate on significantly smaller problems in parallel as opposed to attempting to search the intractably large domain of the original problem. By only solving the phase of high-energy blocks, Algorithm 1 devotes its attention to recovering the phase of pixels that will most impact the reconstruction of the original image. The remainder of this section elaborates on the details of Algorithm 1.

C. Solution Time 

The experiment described in Section IV-B was run in the environment summarized in Table I using parallel block processing with 12 workers. For each value of α, we measured the average across all images in the dataset of the amount of time it took to solve for the phase of all individual blocks in parallel (line 8 in Algorithm 1) and the average amount of time it took to resolve inter-block sign discrepancies (line 13 in Algorithm 1). The results are displayed in Fig. 8. The amount of time it takes to solve all individual blocks in parallel grows linearly with the number of bits solved due to the fact that the size of individual blocks is constant. The amount of time it takes to resolve inter-block discrepancies is superlinear with respect to the number of bits solved due to the fact that the size of the feasible space in the inter-block resolution problem grows exponentially with the number of bits solved. However, over the range of α that we tested, the inter-block resolution time was always significantly less than the individual block solution time, resulting in a total solve time that grows approximately linearly in this range. While this algorithm functions well on computationally computed cosine transforms, it does not yet perform well on optically generated cosine transforms. Misalignment, ambient light, vibration and other factors present within a lab envi-ronment can introduce “noise” into the cosine transform of an image, causing it to violate the motivation discussed in Section II-B. In particular, the sharp curvature present along the zero level set of an image of an ideal cosine transform can become fairly smooth when non-ideal factors are introduced. Future work will explore how to make our algorithm robust to such issues. Algorithm 1 functions by decomposing a cosine transform into blocks, solving each block independently and then resolv-ing sign discrepancies between each block. The subproblems are coupled together through the parameter β as well as the inter-block curvature. However, there is no guarantee that Algorithm 1 converges to a global optimum of (19). Another direction for future work would involve employing an optimization technique that synergizes well with the divide-and-conquer nature of Algorithm 1 while guaranteeing opti-mality, such as the alternating direction method of multipliers (ADMM).
